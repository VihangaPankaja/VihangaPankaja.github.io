FastMap and Random Projection

Two ways to reduce dimensions: recursively embed pairwise distances with FastMap, or multiply vectors by a low-dimensional random map with probabilistic distance guarantees.

Big pictureFastMap: distances become coordinatesWorked source matrix: two FastMap dimensionsRandom projection and Johnson–LindenstraussCommon mistakesExam focusPractice questions

Big picture

FastMap starts with distances between objects, not their feature vectors. It chooses two far-apart pivots, uses the law of cosines to place each object along one coordinate, subtracts that coordinate's contribution from every pairwise distance, and repeats. It is a distance-based embedding procedure. PCA instead starts with feature vectors, centers them, and finds linear directions of high variance. FastMap can operate when only pairwise distances are available; PCA requires a coordinate representation.

Random projection takes the opposite route: when vectors are available, multiply them by a suitably sampled lower-dimensional matrix. For a finite set of points, the Johnson–Lindenstrauss result says a low-dimensional map can preserve pairwise distances within a chosen multiplicative error with high probability. It does not promise exact isometry for every draw.

Study route: review dimensionality reduction for selecting versus extracting features and PCA for feature-based linear projection. This page develops distance-only FastMap and random linear projection.

FastMap: distances become coordinates

For pivots a and b, the law of cosines gives the coordinate of y measured from a along the pivot line:

cy=d(a,y)2+d(a,b)2−d(b,y)22d(a,b)

The coordinate is a pseudo-projection: it is computed from distances and need not come from known original coordinates. Once coordinate c is assigned, FastMap removes its contribution from every pair:

d(i)(y,z)=(d(i−1)(y,z))2−(cy−cz)2

Then the next dimension uses the residual distances. In ordinary Euclidean use, residual radicands should be nonnegative apart from small numerical error. A negative value is evidence the supplied distances are not behaving like a Euclidean embedding at that step; do not silently clamp it and call the result a valid ordinary distance.

The slide's pivot heuristic starts at any object, chooses the farthest object from it, then chooses the farthest object from that second point, and uses the last two as pivots. This two-sweep heuristic seeks separated endpoints; it does not prove globally optimal pivots. The source does not prescribe tie-breaking. State a deterministic policy when one is needed; the worked source example fixes its pivots explicitly.

When a pivot distance is zero

Before using the coordinate formula, require a positive pivot separation. If the selected residual pivot distance is zero, do not divide by it. With ordinary metric residual geometry and the farthest-point pivot search, this zero result means all objects coincide in the remaining geometry. Set the remaining output coordinates to zero and stop. This guard is a supplemental clarification from Faloutsos and Lin's original FastMap algorithm, Algorithm 2 step 4.

One zero pair is insufficient to establish that stopping condition. In the worked matrix, O1–O4 has zero residual after the first axis, but O2–O5 still has residual 1.9999>0. Therefore dimension 2 continues. If an arbitrarily chosen pivot pair is zero while another residual pair is positive, choose a separated pair rather than declaring the embedding complete. For nonmetric signed extensions, the ordinary metric inference needs a separate check; a single zero pair is never proof that all residuals vanish.

Cost and assumptions

Supplemental implementation analysis. For a dense input matrix of pairwise distances among M objects, storing the matrix takes O(M2) space. In a direct implementation, one axis computes M coordinates and updates each distinct pair once, so it takes O(M2) time; repeating for k axes takes O(kM2), in addition to the original distance acquisition. The pivot heuristic takes O(M) per farthest scan when all distances are already available. These bounds apply to this dense-matrix implementation. FastMap assumes the distances are meaningful for its intended geometry; the ordinary recurrence behaves as a Euclidean residual update, while the source's signed extension handles non-Euclidean residual values separately.

What the residuals mean

O1 and O4 receive first coordinates cO1=0 and cO4=100, so they are at opposite ends of axis 1. Their original distance 100 is fully explained by that coordinate, leaving residual distance 0. In the residual space they coincide, so their later coordinates can agree. This is different from saying their first coordinates coincide.

FastMap's ordinary recurrence assumes Euclidean-like residual geometry. The slide's non-Euclidean extension overloads the same symbol for a squared residual and its signed result, and its absolute-value expression also appears to contain an extra square. The notation is ambiguous. The following is this guide's clarified interpretation: use a distinct squared-residual symbol, retain its sign, and take the square root of its absolute value:

δi(a,b)=di−1(a,b)2−(xi,a−xi,b)2,di(a,b)=sign(δi(a,b))|δi(a,b)|

This clarified signed quantity is not an ordinary nonnegative metric distance. It keeps a negative residual visible instead of silently clamping it to zero; it is not a verbatim transcription of the overloaded slide notation.

Random projection and Johnson–Lindenstrauss

For a finite set of M points in ℝn , the lecture gives 0<ε<12 and target dimension k=O(ε−2lnM) . A suitable random linear map f into ℝk can preserve every pairwise distance in the finite set within the unsquared bound:

(1−ε)d(x,y)≤d(f(x),f(y))≤(1+ε)d(x,y)

The source writes strict inequalities. The weak form above communicates the same bounded-distortion guarantee while allowing equality at a boundary. The theorem is about existence and probabilistic constructions under suitable sampling and dimension conditions; a chosen random draw can fail, and the guarantee is approximate rather than exact. The slide says “constant probability” and later “high probability”; probability depends on the theorem's construction and constants, which the slide does not specify.

Take R∈ℝk×n and a column input x∈ℝn×1. Then Rx∈ℝk×1: each of the k rows yields one output coordinate. For the standard Gaussian construction, entries are independently sampled from a zero-mean, unit-variance normal and scaled by 1/k (equivalently 𝒩(0,1/k)); related JL constructions use other suitable distributions. The slide instead prints 𝒩(1,0), described as mean 1 and variance 0. Under that stated convention it is degenerate at 1, so it is not the standard Gaussian random projection. The normalized mean-zero Gaussian description here is a supplemental correction, verified against the primary JL construction discussion; it is not what the lecturer printed.

Teaching example: project two 3D vectors by hand

Random projection: matrix shape, row products, and distance

Fixed teaching inputs: R=[10−1011],x=(2,1,0)T,z=(0,1,2)T. This deliberately fixed matrix teaches multiplication and distance checking; it is not sampled from the JL distribution.

1. Orient the projection matrix

For n input features and k output coordinates, let R∈ℝk×n and x∈ℝn×1. Then Rx∈ℝk×1. Row i of R supplies one dot product and therefore one output coordinate. This dimension check prevents accidentally using an n×k matrix in this convention. Next: calculate each row product for both vectors.

2. Compute every row dot product

Teaching example with an arbitrary fixed matrix: R=[10−1011],x=[210],z=[012]. For Rx, row 1 gives 1·2+0·1+(−1)·0=2; row 2 gives 0·2+1·1+1·0=1. Thus Rx=(2,1)T. For Rz, row 1 gives 1·0+0·1+(−1)·2=−2; row 2 gives 0·0+1·1+1·2=3. Thus Rz=(−2,3)T. The fixed matrix illustrates arithmetic only; it is not a successful JL random draw or a counterexample to the existence/probability theorem. Next: compare the before-and-after distances.

3. Compare input and output distances

Before projection, x−z=(2,0,−2), giving the input distance:

‖x−z‖=22+02+(−2)2=8=22

After projection, Rx−Rz=(4,−2), giving the output distance:

‖Rx−Rz‖=42+(−2)2=20=25

This one arbitrary matrix expands this pair; a JL guarantee is probabilistic over a correctly sampled map and applies to a finite set with a suitable k, not to every matrix or every draw. The completed arithmetic is checked against both vector outputs above.

Suggested two-stage workflow

The final slide suggests first using random projection to reduce a very wide representation, then applying SVD to reduce it further. This is a suggested workflow from the lecture, not a claim that the sequence is always best. Validate the distortion and downstream task for the actual data and chosen dimensions.

Common mistakes

  • Treating FastMap as feature PCA: FastMap needs pairwise distances and builds pseudo-coordinates; PCA operates on feature coordinates and variance.
  • Replacing the source matrix or its supplied pivots with a newly guessed example, or treating the farthest-point heuristic as a guaranteed global optimum.
  • Using the slide's printed O5 value as exact, or calling it ordinary rounding of the formula's value. The formula requires 99.995 and all residuals depend on it.
  • Saying O1 and O4 share the first coordinate. They have first coordinates 0 and 100; only their residual distance after that axis is zero.
  • Dividing by a zero pivot separation, or confusing one zero residual pair with all residual distances being zero.
  • Recomputing with rounded display coordinates. Keep full precision internally and round only shown values.
  • Treating a negative Euclidean residual radicand as zero. Keep the source's signed non-Euclidean extension separate from ordinary nonnegative distances.
  • Treating a fixed arbitrary projection matrix's distortion as a refutation of JL, or treating JL as exact preservation for every random draw.
  • Confusing the projection-matrix shape: k rows and n input columns multiplied by an n-entry column vector yields k output coordinates.
  • Calling the slide's mean-one, variance-zero normal claim a standard Gaussian random projection. With variance zero it is degenerate; the mean-zero normalized Gaussian is a supplemental correction.

Exam focus

  • FastMap: choose separated pivots; compute the pseudo-coordinate by the law of cosines; subtract its squared coordinate difference from every squared pair distance; recurse on residuals.
  • The pivot coordinates start at zero and end at the pivot separation. A zero residual says the represented axes account for the full original distance at that stage.
  • FastMap is distance-based; PCA is a feature-based linear variance projection.
  • JL: a finite set of M points, epsilon between zero and one-half, target dimension proportional to epsilon inverse-square times log M, and approximate unsquared pairwise-distance bounds with probability under suitable random-map conditions.
  • Shape check: matrix with k rows and n columns times an n-entry column vector gives a k-entry column vector.
  • A two-stage random-projection-then-SVD pipeline is suggested in the lecture, not a universal optimum.

Practice questions

1. Why can FastMap be applied when original feature vectors are unavailable?

Check your answer

It uses pairwise distances to choose pivots, compute pseudo-coordinates, and update residual distances. It does not need the original coordinates, though the distance input still needs to be meaningful for the intended geometry.

2. In the source example, what are O1 and O4 coordinates after dimension 1, and why can their later coordinates match?

Check your answer

The first coordinates are cO1=0 and cO4=100. Their original distance is 100, so the first axis explains it completely and their residual distance is zero. Thus they coincide in residual space, allowing later coordinates to agree.

3. What is the formula-based O5 first coordinate, and how should the printed slide value be treated?

Check your answer

Using distances 100 to O1, 1 to O4, and pivot distance 100 gives 10000+10000−1200=99.995. The slide prints 99; that is not ordinary rounding. Use the formula-based 99.995 for consistent residual calculations and state the discrepancy.

4. A vector has n input features and R has k rows and n columns. What is the shape of Rx?

Check your answer

k×1: every row of R computes one scalar dot product with x.

5. Does one fixed projection that expands one pair contradict the Johnson–Lindenstrauss lemma?

Check your answer

No. The lemma concerns suitable random-map distributions and enough target dimensions for a finite set, with a stated probability and distortion bound. It does not guarantee every fixed matrix or random draw preserves every pair.

6. Why is the slide’s mean-one, variance-zero normal claim degenerate?

Check your answer

Zero variance means the random variable equals its mean with probability one. Every draw would be 1, so it is not a non-degenerate zero-mean Gaussian projection. The printed notation is 𝒩(1,0) under the slide’s stated convention.
