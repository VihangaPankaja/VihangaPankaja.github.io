Neural Computation and Perceptron Learning

How a weighted neuron becomes a classifier, how the perceptron adjusts its boundary, and why XOR needs a richer representation.

Big picture

An artificial neuron turns input features into a score and then into an output. A perceptron uses a hard threshold to make a two-class decision. Its boundary is a line in two dimensions (a hyperplane in more dimensions), so it can learn a pattern only when one such boundary separates the classes. AND and OR satisfy that condition; XOR does not. A hidden layer can create a new representation in which the XOR cases become separable, but the single-perceptron learning rule does not learn those hidden weights.

From biological inspiration to a computation

The lecture uses the biological neuron as an analogy: dendrites receive signals through synapses; the signals are combined; an output is sent onward. Artificial units simplify this into numbers, connection weights, a bias, and an activation. They do not reproduce biological spatial or temporal dynamics. The useful connection is that many weighted inputs can contribute to one output, and connection strengths can be adjusted from examples. The lecture also uses deepfakes and biased automated decisions to stress that applications can cause harm; learned behavior depends on the examples and design supplied.

Weighted sum, bias, and activation

For a unit, the weighted input is uk=∑j=1mwkjxj. Adding bias gives the pre-activation (the lecture's induced local field) vk=uk+bk, and the unit returns yk=ϕ(vk). Keep pre-activation vk and output yk distinct: the first is the value entering the activation; the second is the value after it. Bias can be represented as an additional constant input x0=1 with weight w0=b. It shifts the affine response and lets a decision boundary move away from the origin.

Supplemental calculation — one ReLU neuron

Take inputs (x1,x2)=(0.4,−0.2), weights (w1,w2)=(2,−1), and bias b=0.5. First calculate the weighted sum, then add bias, then activate:

u=2(0.4)+(−1)(−0.2)=1.0,v=u+b=1.0+0.5=1.5

For ReLU, y=max(v,0)=max(1.5,0)=1.5. The value before activation is v=1.5; the output is y=1.5.

Activation functions

An activation determines how the pre-activation becomes an output. The lecture compares linear and nonlinear choices. A nonlinear activation is essential when stacked layers must express a nonlinear mapping: composing only linear functions still gives a linear function. The classifier below uses the symmetric hard-limit sign rule, not the optional 0/1 step.

For the primary hard-limit perceptron, the exact rule is:

ϕ(v)={+1,v≥0−1,v<0

The optional Heaviside function instead returns 1 at and above zero and 0 below zero. Although both assign the zero boundary to their positive output, their label encodings differ. Do not use a 0/1 target with the primary bipolar perceptron rule.

Perceptron decision boundary and learning rule

With two inputs and the primary sign activation, the net input is s=b+w1x1+w2x2. The decision boundary is the set where s=0; equality belongs to the +1 side. The bias shifts this line, while the weights set its orientation. The same expression defines a hyperplane for more input dimensions.

s=b+w1x1+w2x2,b+w1x1+w2x2=0 on the boundary

For the source AND pattern, inputs are binary, targets are bipolar, and the augmented input is 𝐱a=(1,x1,x2). To keep the parameter order explicit, write θ=(b,w1,w2). At each presentation, compute the prediction; subtract it from the desired output; then update using the augmented input. A correct prediction makes no change.

What convergence does and does not say

The perceptron convergence result is conditional: for the stated step size 0<η<1, if a finite training set is linearly separable, repeated sequential updates with the stated rule reach a separating solution after finitely many corrections from any initial weights (the exact separating weights need not be unique). A complete no-update pass is a practical stopping check for the presented examples. If the set is not linearly separable, this guarantee does not apply; the rule may keep changing weights.

AND, OR, and the XOR limitation

The source's AND and OR truth patterns can each be divided by a straight line in the binary input plane. XOR labels opposite corners alike: the positive cases occupy opposite corners, as do the negative cases. No single line can place both positive corners on one side and both negative corners on the other. That geometry is the single perceptron's representational limit, not a failure to choose a sufficiently clever initial weight vector.

Optional: representation guidance and applications

The optional reading adds design heuristics for useful internal representations. Similar inputs from similar classes should have similar representations; different classes should be farther apart. Similarity may be judged by Euclidean distance or a dot product, often after normalizing vectors to unit length. Important features should be represented across multiple units. Where possible, use prior structure and invariances: local receptive fields, shared weights, training examples, or features invariant to a transformation can reduce what must be learned. These are design principles, not steps in the perceptron update.

The lecture's application survey spans classification and recognition, inspection or control, and forecasting. Examples include speech or image recognition, product inspection, and crop-yield prediction. These are illustrations of task types, not guarantees that a neural network is suitable or accurate for a particular deployment.

Common mistakes

  • Confusing the weighted sum u with the biased pre-activation v=u+b, or with the post-activation output y=ϕ(v).
  • Dropping the bias or forgetting that it is the update on augmented coordinate 1.
  • Using (w1,w2,b) when the worked trace says (b,w1,w2), or mixing binary inputs with bipolar targets.
  • Treating sign(0) as −1. In the primary rule, the tie is +1; this is why the first AND pattern updates from the all-zero state.
  • Reversing d−y to y−d while keeping the same plus update.
  • Stopping after a correct positive example without checking the full training set or a complete no-update pass.
  • Claiming convergence on XOR. The theorem requires linearly separable training examples.
  • Saying the hand-configured XOR example trained a hidden layer. It supplies weights by construction; learning them is a later topic.
  • Treating the optional 0/1 Heaviside threshold as the primary bipolar sign activation.
  • Assuming adding hidden units alone makes a network nonlinear if every activation remains linear.

Exam focus

  • State the neuron computation in order: weighted sum, add bias, apply activation.
  • For the primary perceptron, state +1 when net input is at least zero and −1 otherwise.
