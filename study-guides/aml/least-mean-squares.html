Least Mean Squares and the Delta Rule

LMS adjusts a linear filter by following the instantaneous squared-error gradient.

Big picture

Least Mean Squares (LMS), also called the delta rule, adjusts a linear filter so its response moves toward a desired signal. It generalizes perceptron learning by leaving the hard threshold out of the learning calculation: the update follows the size and direction of a continuous residual. The slides describe filtering and adaptation as two ongoing processes: one computes output and error, and the other adjusts the coefficients.

Linear response and residual

The filter combines the input features with its current coefficients. For the slide's vector notation, the response is:

y(n)=𝐱𝖳(n)𝐰(n)=∑k=1mxk(n)wk(n)

Here, each feature contributes according to its current weight. The desired response is d(n), and the residual is desired minus actual response:

e(n)=d(n)−y(n)

A positive residual means the linear response is below the target; a negative residual means it is above. LMS uses this continuous difference while learning. It does not first turn the response into a class label.

Supplemental extension: include a bias

A linear model can include a bias by appending a constant feature equal to one. This supplemental extension lets the same vector update learn the bias:

𝐱~(n)=[𝐱(n)1],𝐰~(n)=[𝐰(n)b(n)],y(n)=𝐱~𝖳(n)𝐰~(n)=𝐱𝖳(n)𝐰(n)+b(n)

The added coefficient changes like any other weight because its feature is always one. This keeps the bias rule consistent with the source's vector update.

Instantaneous half-squared loss

For the current sample, the slides assign the cost to the instantaneous residual. The factor one-half makes the derivative concise:

ξ(n)=12e2(n)

This is one sample's loss at the current parameters. “Instantaneous” matters: the slide update uses this sample's input and residual directly. It does not first add losses across the dataset or divide their sum by the number of samples.

From the gradient to the delta update

First consider unconstrained optimization of a continuously differentiable scalar cost: each weight vector is mapped to a real-valued cost, and the goal is to find a minimizing vector:

ξ:ℝm→ℝ,ξ(𝐰⋆)≤ξ(𝐰)for all 𝐰

At a differentiable unconstrained optimum, every first partial derivative must vanish. The gradient collects these derivatives:

∇𝐰ξ=[∂ξ∂w1⋮∂ξ∂wm],∇𝐰ξ(𝐰⋆)=0

Zero gradient is a necessary stationary-point condition, not by itself sufficient to establish a minimum: a maximum or saddle point can also have zero gradient.

Steepest descent moves opposite the gradient of the cost. Write the gradient as 𝐠(n)=∇𝐰ξ and use a positive learning rate η. For the current sample, the chain rule gives:

∂ξ∂e=e,∂e∂𝐰=−𝐱,∇𝐰ξ=∂ξ∂e∂e∂𝐰=−𝐱e

Substituting that gradient into steepest descent reverses its sign, yielding the LMS rule:

𝐰(n+1)=𝐰(n)−η∇𝐰ξ=𝐰(n)+η𝐱(n)e(n)

The derivative of 12e2 is e. There is no extra factor of two in the update. The residual convention is d−y; using y−d would require changing the update sign too.

What the input, weights, and learning rate do

Each component follows the same rule, Δwk=ηxke: the residual is shared across the vector, while the feature value controls the change to its matching weight. A feature with value zero leaves its weight unchanged on that sample; a negative feature reverses the update direction for that coefficient. The learning rate η>0 scales every change. The source motivates steepest descent with a first-order Taylor approximation:

ξ(𝐰(n+1))≈ξ(𝐰(n))−η‖∇𝐰ξ‖2

That is a local approximation for a step from the current point. It explains the descent direction; it is not a general convergence guarantee for a sequence of changing samples.

Online updates, batch conventions, and classification

The LMS equation above is online: compute the response and residual for one sample, update the parameters, then use those new parameters on the next sample. A batch objective instead sums or averages losses over several samples before updating. The mean gradient is the sum gradient divided by the sample count, so the learning-rate interpretation changes with that choice.

Keep the learning output separate from a later decision. The perceptron applies a hard threshold while learning and uses a thresholded output; LMS learns from the linear response and its continuous residual. A task may later apply a classification threshold to a trained score, but that decision step is separate.

Two-epoch worked trace

The following Teaching example completes the source rule with a separate bias, two explicitly chosen binary-coordinate inputs, a fixed sample order, and a learning rate. Every response and residual is calculated from the old state for that sample. The vector and bias changes are then applied together before moving to the next sample.

For the first input:

Optional arithmetic: one checked LMS update

Teaching example. Begin with 𝐱=(1,−1), (w1,w2)=(0.2,0.1), b=0, target d=1, and η=0.1. This separate bias is part of the teaching model. The initial response and residual are y=0+0.2(1)+0.1(−1)=0.1 and e=1−0.1=0.9. The source rule gives (Δw1,Δw2,Δb)=(0.1(1)(0.9),0.1(−1)(0.9),0.1(0.9))=(0.09,−0.09,0.09), so the new state is (w1,w2,b)=(0.29,0.01,0.09). Re-evaluating the same input gives ynew=0.09+0.29−0.01=0.37. The residual magnitude falls from 0.9 to |1−0.37|=0.63; the half-squared loss changes from 12(0.9)2=0.405 to 12(0.63)2=0.19845.

Common mistakes

  • Reversing the residual to output minus target while retaining the additive update. With e=d−y, the source's update adds η𝐱e.
  • Applying the classification threshold inside the LMS residual calculation. Training uses the continuous linear response.
  • Updating each coefficient from a partially changed vector. First calculate the response and residual from the old state, then apply the complete update together.
  • Treating the slide's instantaneous sample loss as a batch mean or sum. State the aggregation if a batch objective is introduced.
  • Assuming a small, positive learning rate alone proves convergence. The first-order argument is local, and the slides report that LMS may converge slowly and is sensitive to input variation.

Exam focus

  • LMS is also called the delta rule and generalizes perceptron learning by using a linear output during learning.
  • The residual sign is e(n)=d(n)−y(n) and the instantaneous loss is ξ(n)=12e2(n).
  • Chain rule: ∇𝐰ξ=−𝐱(n)e(n); update: 𝐰(n+1)=𝐰(n)+η𝐱(n)e(n).
  • The LMS slide equation is per-sample and online. Do not silently replace it with a batch sum or mean.
  • Each update has cost linear in the number of parameters. LMS can converge slowly and is sensitive to input variations. A small learning rate does not by itself establish convergence or a fixed epoch count.

The lecture also characterizes LMS as robust, meaning it does not depend on a particular model, especially for a small learning rate. Keep that stated feature distinct from convergence: the update still uses the linear filter above, and robustness does not guarantee convergence for arbitrary inputs or learning rates.

Practice questions

1. For a linear response below its desired value, what is the sign of the LMS residual?

Check your answer

It is positive because e=d−y and d>y. The update adds η𝐱e, scaled coordinate by coordinate by the input.

2. Why does the LMS update not contain an extra factor of two?

Check your answer

The loss is ξ=12e2. Differentiating with respect to e gives e; the factor two from the square cancels the one-half.

3. What parameters must be used to calculate a sample’s output and error?

Check your answer

Use the complete old weight vector (and the old bias if using the labeled bias completion). Calculate the output and residual first; then apply all increments together.

4. State one distinction between online LMS and a batch sum or mean.

Check your answer

Online LMS updates from one current sample at a time. A batch sum or mean aggregates multiple sample losses before an update, and the mean introduces a sample-count normalization absent from the slide equation.

5. Does the two-epoch example show that LMS reaches the exact targets or always converges?

Check your answer

No. It verifies only the displayed arithmetic on the two teaching inputs after two passes. The source lists slow convergence and sensitivity to input variation and gives no universal convergence or stopping guarantee.
