Deep Learning Foundations and Regularization

How neural networks learn representations, form predictions, regularize with dropout, and choose architectures and training settings.

Big picture

Conventional machine learning often asks a person to decide which measurements or patterns to extract before a classifier learns from them. Deep learning moves more of that representation work into a hierarchy of trainable layers. An end-to-end model maps input data to predictions, compares those predictions with targets through a task-appropriate loss, and uses an optimizer to update the layers’ learned weights. This gives the model a flexible way to learn useful patterns, while making data, architecture, regularization, and tuning important parts of the problem.

Computer-vision tasks ask for different outputs

The same image can support different prediction tasks. The lecture contrasts a single cat’s class label with locating that cat, then moves to scenes with several objects. Detection places a box around each object; instance segmentation identifies the pixels belonging to each separate object, so two cats can have different instance masks even though their class is the same.

Task Predicted output Objects in the lecture illustration
Classification A class label, such as cat One object
Classification plus localization A class label and its bounding box One object
Object detection A class label and bounding box for each object Multiple objects, including cats, a dog, and a duck
Instance segmentation A class label and a separate pixel mask for each instance Multiple objects, with their individual outlines

These outputs require different targets and output structures; identifying an object’s class alone does not provide its location or its pixel mask.

The cat example makes the division of labor visible. In a conventional pipeline, a person supplies handcrafted features and a learned classifier uses them. In a deep pipeline, the intermediate representations and classifier are learned together. Handcrafted features can be tedious, costly, and application-specific; learned features can adapt within the training task, but they still need suitable data and training.

From raw input to learned representations

Deep learning is also called representation learning. Each stage transforms one or more input tensors into one or more output tensors, with a trainable nonlinear transformation able to build on earlier representations. The lecture illustrates increasing abstraction with image and text hierarchies:

These are conceptual examples of abstraction, not a promise that every trained network will form separately identifiable “edge,” “motif,” “phrase,” or “story” stages. The central idea is that later representations can combine patterns from earlier ones. This end-to-end flexibility can support supervised or unsupervised learning; the lecture also emphasizes that deep learning typically requires large amounts of training data.

Layers, tensors, predictions, and the training loop

A layer is a data-processing module. Dense, convolutional, recurrent, pooling, flattening, merging, and normalization layers are different examples; each has its own input/output shape and transformation. A trainable layer’s weights and biases are its learned internal state. They begin from an initialization and are adjusted during training; parameter-free operations such as fixed pooling have no learned weights. When layers are connected, they form a network or model.

During a forward pass, the model maps input X to prediction Y′. During training, the loss function compares Y′ with the true target Y. The loss is the quantity selected for minimization; other metrics may still matter when judging a model. Backpropagation supplies gradients through the layers, and the optimizer applies updates to relevant weighted layers. See Multilayer Networks, Gradient Descent, and Training Practice and Backpropagation: Derivation and Layerwise Updates for the detailed optimization and gradient derivations.

TaskCommon loss named in the lectureWhat the output represents
RegressionMean squared errorA numeric prediction
Two-class classificationBinary cross-entropyA binary decision or probability

The optimizer determines how weights are changed based on the loss gradients. The lecture names stochastic gradient descent (SGD), momentum, and variants such as RMSProp, and highlights the learning rate and its schedule. Its comment that RMSProp is “usually a good first choice” is lecture context, not a universal current recommendation. Optimizer behavior depends on the task, model, data, and tuning.

Nonlinear representation and the role of depth

Neural networks build nonlinear mappings from input to output. If every layer were only linear, composing layers would still produce one linear mapping; nonlinear activations are what let compositions form nonlinear decision boundaries and richer transformations. The lecture describes a one-hidden-layer universal approximation result and notes that depth can be useful even though shallow and deep networks share broad representational capacity under suitable conditions.

Supplemental theorem statement. One verified version says that finite single-hidden-layer networks with a continuous sigmoidal nonlinearity can uniformly approximate continuous functions on the unit hypercube, under the theorem’s stated conditions. This is an existence result about approximation capacity. It does not say that gradient-based training will find the approximating parameters, that the representation will generalize, or that the required shallow network will be efficient. It also does not establish that a fixed-width network can approximate every function. Cybenko’s original paper states the compact-domain and activation assumptions.

The lecture presents deeper networks as empirically performing better than shallow networks up to a limit, after which performance plateaus. That is a task-dependent observation, not a rule that more depth always helps. Depth and width change the structure and possible efficiency of a model; capacity alone does not guarantee good generalization. The appropriate choice must be learned and assessed using training and validation data.

Sigmoid and softmax outputs

For a logit zi, sigmoid applies σ(zi)=1/(1+e−zi) independently. Each result lies between zero and one, but several sigmoid outputs need not add to one. They can suit binary classification, or separate non-exclusive yes/no labels. For an exclusive multi-class choice, softmax exponentiates the logits and normalizes them with one shared denominator so the outputs form a probability distribution.

Worked example: compare sigmoid outputs with softmax for the lecture logits (3, 1, −3)

1. Start with the lecture logits

The three classes have logits z1=3,z2=1,z3=−3. Independent sigmoid outputs use σ(z)=11+e−z:

σ(3)=0.952574127,σ(1)=0.731058579,σ(−3)=0.047425873

Their sum is 1.731058579, so independent sigmoids do not normalize an exclusive three-class choice.

2. Exponentiate each logit

Softmax exponentiates each logit while keeping its class identity:

ez1=e3=20.085536923188,ez2=e1=2.718281828459,ez3=e−3=0.049787068368

Each value is finite and strictly positive, including the value for the third class.

3. Add the shared denominator and divide

Sum the three exponentials, then divide each class value by that same sum:

D=20.085536923188+2.718281828459+0.049787068368=22.853605820015
y1=20.08553692318822.853605820015=0.878878242732
y2=2.71828182845922.853605820015=0.118943235911

4. Check the probability vector

Each output is between zero and one, and the values sum to one:

0.878878242732+0.118943235911+0.002178521357=1.000000000000

For an exclusive multiclass target, the normalized vector is directly comparable across classes. Sigmoid outputs remain useful for binary classification and for multiple labels that are not mutually exclusive, where each label is a separate yes/no decision.

Dropout regularization

Dropout randomly removes units during training, along with the connections incident to those units. Each sampled mask therefore trains a slightly different thinned network. The lecture motivates this as reducing overfitting and improving generalization, and uses ensemble learning as an intuition: mini-batches train the same shared model through different subnetworks. At inference, the full network is used rather than a training mask.

The phrase “retained with a fixed dropout rate” makes the lecture’s symbol p ambiguous: it mixes keep and drop language, while later saying that often 20–50% of units are dropped. To keep the two quantities distinct, this guide writes qdrop for the fraction dropped and rkeep=1−qdrop for the fraction retained. Masks are sampled independently as described in the slide; exact mask granularity can depend on the layer and implementation.

1. Separate drop and keep probabilities

Supplemental calculation. Let qdrop=0.25 and rkeep=1−qdrop=0.75. For inverted scaling require 0≤qdrop<1, so the keep fraction is positive. A Bernoulli mask independently keeps or drops each unit in this illustrative elementwise example. The fixed mask below is a teaching realization, not a newly sampled or trained network result.

2. Apply the sampled mask

Starting activations are [2,−1,0,4] and the sampled mask is [1,0,1,1]. Multiply coordinate by coordinate:

[2·1,−1·0,0·1,4·1]=[2,0,0,4]

The second unit is dropped, so its path is removed. The third unit’s original activation is zero; it was kept here, which is different from saying the zero value was dropped.

3. Scale retained coordinates once during training

In the explicitly chosen inverted-dropout convention, divide retained values by rkeep=0.75:

[2,0,0,4]÷0.75=[8/3,0,0,16/3]

Coordinate check: 2/0.75=8/3, 0 for the dropped coordinate, 0/0.75=0 for the retained zero activation, and 4/0.75=16/3.

4. Disable the mask at inference and check the expectation

At inference, use the original activation vector [2,−1,0,4] without another scale factor. For any coordinate a, the training-time inverted value has expectation rkeep(a/rkeep)+(1−rkeep)0=a. This coordinate-wise expectation check does not imply that a nonlinear network’s expected output equals the output at the expected activations.

A separate older convention leaves retained training activations unscaled and multiplies activations by rkeep at inference. Do not combine that inference-time factor with the training-time scaling above.

For inverted dropout, the training mask and scaling preserve each activation’s expectation coordinate by coordinate. This check applies to activations before later nonlinear transformations; it does not mean a nonlinear network’s expected output equals the output at its mean activation. A separate older convention leaves training values unscaled and applies a keep-probability factor at inference; keep the two conventions separate.

Hyperparameter tuning

Training a neural network involves choices beyond the weights learned by the optimizer. The lecture’s list includes model depth and layer width, initial learning rate and its decay schedule, optimizer type, regularization such as an L₂ penalty or dropout rate, batch size, activation functions, and loss function. These settings interact: for example, architecture controls the model’s transformations while the optimizer and learning-rate schedule control how its parameters move.

Grid search checks combinations from specified ranges and steps. Random search samples candidate settings and is often preferred to a grid when only some dimensions strongly affect performance. Bayesian hyperparameter optimization uses prior trial results to choose later candidates; the lecture labels it an active research area. Each is a search strategy, and all can be costly when model training is expensive.

Use training data to fit candidate models and validation data to compare hyperparameter choices. Keep a held-out test set for a final evaluation after choices are settled; repeatedly tuning against that test set leaks information into the selection process. This division helps measure generalization, but it does not guarantee it.

Common mistakes

  • Treating handcrafted feature extraction and the learned classifier as the same stage. In the conventional pipeline, people define the representation; in deep learning, layers learn intermediate representations as part of the model.
  • Treating the image or text hierarchy as a guaranteed semantic explanation of every layer. The arrows are conceptual examples of increasing abstraction.
  • Saying the optimizer compares predictions with targets. The loss function makes that comparison; the optimizer uses gradients to update weights.
  • Feeding the target directly through the model’s forward path. The target is compared with the prediction at the loss.
  • Assuming independent sigmoid outputs sum to one. Softmax provides normalization across mutually exclusive classes.
  • Saying the third softmax probability is zero because the slide rounds it to approximately zero. The exact exponential is positive and the normalized result is about 0.002179.
  • Confusing the dropout fraction with the retained fraction, or masking weights instead of units. Unit dropout removes each dropped unit and its incident connections.
  • Applying inverted scaling during training and then scaling again at inference. The worked example uses no inference scaling.
  • Treating a universal approximation theorem as a training or generalization guarantee, or assuming that depth always improves performance.
  • Selecting hyperparameters on the held-out test set and then treating its score as an untouched final evaluation.

Exam focus

  • Representation learning: deep networks learn successive trainable feature transformations; conventional ML often starts from handcrafted features.
  • Layer anatomy: a layer maps input tensor(s) to output tensor(s), and learned weights/biases are internal state.
  • Training loop: input maps to prediction; compare that prediction with the target at the loss, then use gradients and an optimizer to update weighted layers.
  • Task and loss: MSE for regression, binary cross-entropy for two-class classification, categorical cross-entropy for multi-class classification.
  • Activations: nonlinear activations enable nonlinear compositions; sigmoid outputs are independent, while softmax outputs normalize to one across classes.
  • Depth: universal approximation is conditional and concerns existence/representational capacity; empirical depth gains can plateau and do not guarantee generalization.
  • Dropout: randomly remove units and incident connections during training; track the drop fraction separately from the keep fraction; inference uses the full network under the inverted convention shown.
  • Tuning: know the listed hyperparameters and the distinction between grid, random, and Bayesian search; compare on validation data and reserve the test set.

Practice questions

1. In the cat example, what is learned in the conventional pipeline and what is learned in the deep-learning pipeline?

Check your answer

The conventional pipeline uses human-designed features followed by a learned classifier. The deep-learning pipeline learns low-, mid-, and high-level representations together with the classifier.

2. Why do neural networks need nonlinear activations between linear layers to represent nonlinear decision boundaries?

Check your answer

A composition of linear maps is still linear. A nonlinear activation prevents that collapse and lets stacked layers form nonlinear mappings.

3. For logits (3, 1, −3), why is the third softmax probability positive even though the lecture writes approximately zero?

Check your answer

e−3=0.049787068368 is positive. Dividing by the shared denominator 22.853605820015 gives about 0.002178521357. It is small enough to round to approximately zero in the slide.

4. A dropout example uses a 0.25 drop fraction. What is the keep fraction, and which units remain under mask [1, 0, 1, 1]?

Check your answer

The keep fraction is 1−0.25=0.75. Coordinates 1, 3, and 4 are kept; coordinate 2 is dropped along with its incident connections.

5. What does the universal approximation result establish, and what does it leave open?

Check your answer

Under its domain and activation conditions, it establishes that a suitable one-hidden-layer network exists that can approximate a target continuous function. It does not establish that training finds it, that it generalizes, or that it is computationally efficient.

6. Which data should guide hyperparameter selection, and which should be kept for final evaluation?

Check your answer

Use training data to fit candidates and validation data to compare settings. Keep a held-out test set for a final evaluation after choices are settled.
