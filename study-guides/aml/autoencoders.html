Autoencoders and Learned Representations

Autoencoders compress an input into a code and learn to reconstruct it, including from a corrupted view.

Big pictureEncoder, code, decoder, and objectiveHistorical deep autoencoder trainingDenoising autoencodersSupplemental relationship to PCACommon mistakesExam focusPractice questions

Big picture

An autoencoder is trained to reproduce its input. The encoder compresses an input into a code; the decoder uses that code to reconstruct the input. Training compares the reconstruction with a target derived from the input, so the network learns a representation useful for reconstruction without a separate class label. The narrow code limits capacity, but reconstruction quality alone does not guarantee that the code preserves whichever features a later task values.

Encoder, code, decoder, and objective

For sample i, the feedforward network receives the input and predicts that same vector at its output. The input-to-hidden part is the encoder; the hidden-to-output part is the decoder. The latent code is the representation passed between them. The target is not an extra input to the forward network: it is compared with the prediction after the forward pass.

𝐲(i)=𝐱(i),𝐳(i)=fenc(𝐱(i)),𝐱^(i)=fdec(𝐳(i))

The lecture’s objective averages a squared vector reconstruction error over the N sample vectors. Each norm squares and sums that sample’s coordinate errors; the outer average divides by N. It does not add a second division by the number of input coordinates.

L(𝐱,𝐱^)=1N∑i=1N‖𝐱i−𝐱^i‖22

3. Sum within each sample to get squared vector norms

The squared Euclidean norm is the sum of that sample vector’s squared coordinate errors.

‖𝐱1−𝐱^1‖22=1+0.25+4=5.25,‖𝐱2−𝐱^2‖22=0.25+0+1=1.25

4. Average the two sample norms and check independently

There are N=2 sample vectors, so divide the sum of their norms by 2. An independent check adds all six squared coordinate errors first, then divides by the number of samples. This is not the pixelwise mean, which would divide by six coordinates.

In the source’s basic example, the widths narrow from 784 input values through 100 hidden units to a 20-unit code, then expand symmetrically through 100 to 784 reconstructed values. Since 20 is below 784, this is an undercomplete bottleneck. It constrains how much information can pass through the code and encourages compression useful for the training objective. It does not guarantee universally informative features: what is retained depends on the data, model, and reconstruction objective.

Historical deep autoencoder training

The deeper example extends the encoder and decoder with more hidden layers. The source diagram uses a 30-unit code and mirrored widths. Its accompanying training description is a historical layerwise method: pretrain a stack of restricted Boltzmann machines (RBMs), passing the learned feature activations of one as the training data for the next. Then unfold the pretrained stack into an encoder and mirrored decoder and fine-tune the whole autoencoder by backpropagating reconstruction error.

Historical layerwise pretraining and unfolding

Fixed architecture from the lectureLayer sizes are visible in every stage: 2000→1000→500→30→500→1000→2000.Pretraining passes activations forward; unfolding mirrors the encoder widths on the decoder side.

1. Pretrain the first RBM

Train the first restricted Boltzmann machine with 2000 visible input dimensions and 1000 feature-detector units. Its learned feature activations form the data representation passed to the next layer.

2000⟶1000

2. Use those activations to train the second RBM

Use the first RBM’s activations as the next RBM’s training data. The second RBM maps 1000 input dimensions to 500 feature-detector units.

1000⟶500

3. Pass activations to the third RBM

Again pass the learned activations forward as data. The third RBM maps the 500-dimensional representation to the 30-unit central code.

500⟶30

4. Unfold the mirror and fine-tune reconstruction

Unroll the pretrained stack into an encoder followed by its mirrored decoder. Then fine-tune the complete autoencoder by backpropagating reconstruction error.

2000→1000→500→30→500→1000→2000

This is the historical procedure attributed on the slide to Hinton and Salakhutdinov (2006), not a requirement for modern autoencoder training.

The pictured method is attributed to Hinton and Salakhutdinov (2006), whose paper describes low-dimensional codes trained to reconstruct high-dimensional inputs and an initialization strategy for deep autoencoders (paper record). Treat this as historical context rather than a required modern workflow. For the general gradient method behind fine-tuning, see backpropagation.

Denoising autoencoders

A denoising autoencoder first applies stochastic corruption to the input. The corrupted vector is what the encoder sees, while the decoder is trained to reconstruct the original clean vector. This target distinction is essential: comparing the prediction with the corrupted vector would teach the network to reproduce the noise rather than undo it.

𝐡(i)=fenc(𝐱~(i)),𝐱^(i)=fdec(𝐡(i)),L=1N∑i=1N‖𝐱(i)−𝐱^(i)‖22

The lecture motivates corruption as a way to encourage representations that remain stable under input corruption and capture useful structure in the input distribution. It emphasizes that denoising is a training criterion for learning higher-level features, not the primary goal by itself.

Trace one clearly labeled corruption and target pair

Supplemental teaching scenario; illustrative values, not learned output. Let a clean four-value input be 𝐱=(1,1,1,1). One possible corruption masks the second and fourth coordinates, giving the encoder 𝐱~=(1,0,1,0). The target remains the original clean vector 𝐱=(1,1,1,1). A model prediction would be compared with that clean target; no prediction or trained result is assumed here.

Supplemental relationship to PCA

This supplemental comparison concerns a restricted linear autoencoder. Under the assumptions of centered data, a linear encoder and decoder, an undercomplete code of dimension k, squared reconstruction loss, and optimization to a globally best reconstruction of rank at most k, a leading k-dimensional PCA subspace yields an optimal reconstruction. If the eigenvalues tie across the retention cutoff, several principal subspaces can be equally optimal; if the data rank is below k, unused directions are not determined by the data. This is a statement about the reconstruction subspace, not an assertion that every autoencoder is PCA.

Even when the optimal subspace agrees, latent coordinates need not equal the principal-component coordinates. An invertible change of basis in the code can be offset by the decoder while leaving the reconstructed vector and its loss unchanged. The primary Bourlard–Kamp paper analyzes linear auto-association through low-rank approximation and singular value decomposition (1988 paper record). For PCA’s full centering, projection, and component calculations, continue to PCA; the broader representation-learning context is in deep-learning foundations.

Common mistakes

  • Treating the target as another forward-pass input. The network predicts first; the clean target enters when computing loss.
  • Confusing encoder and decoder. The encoder maps the input toward the code; the decoder maps the code back toward an input-sized reconstruction.
  • Claiming the bottleneck guarantees that the most useful task features are retained. It constrains capacity for the reconstruction objective but does not define usefulness for every downstream task.
  • Dividing the source loss by N times the number of pixels. The displayed objective averages sample-level squared vector norms over N samples only.
  • Using the corrupted input as a denoising target. Feed the corrupted view to the encoder and compare the output with the original clean input.
  • Treating the historical RBM pretraining procedure as mandatory for all current autoencoders.
  • Saying every autoencoder is equivalent to PCA or that its latent coordinates must be PCA scores. The optional connection requires linearity, centered data, an undercomplete code, squared reconstruction loss, and a globally optimal rank-k reconstruction; it concerns the reconstruction subspace.

Exam focus

  • Autoencoder: a feedforward network trained to predict its input at the output.
  • Encoder maps input to a latent code; decoder maps code to reconstruction.
  • Basic widths: 784 → 100 → 20 → 100 → 784. The 20-unit code is undercomplete relative to the 784-value input.
  • Reconstruction objective: mean over N sample vectors of their squared Euclidean reconstruction norms.
  • Historical deep widths: 2000 → 1000 → 500 → 30 → 500 → 1000 → 2000. RBM feature activations become the next RBM’s data; unfold the mirrored layers and fine-tune by reconstruction backpropagation.
  • Denoising: corrupt the encoder input, keep the clean input as the reconstruction target.
  • PCA connection is supplemental and conditional; the optimal reconstruction subspace may match PCA while latent basis coordinates remain non-unique.

Practice questions

1. What does the encoder produce, and what does the decoder produce?

Check your answer

The encoder maps the input to a latent code. The decoder maps that code to a reconstruction with the original input dimensions.

2. For a 784 → 100 → 20 → 100 → 784 network, why is the code undercomplete?

Check your answer

The 20-value code has fewer coordinates than the 784-value input. That limits representational capacity for reconstruction; it does not guarantee task-optimal features.

3. The batch has N=8 vectors, each with 784 coordinates. What divisor appears in the source reconstruction objective?

Check your answer

Divide the sum of the eight squared vector norms by N=8. The source objective does not additionally divide by 784.

4. In the historical deep procedure, what becomes the input data for the next RBM?

Check your answer

The learned feature activations of the preceding RBM. After layerwise pretraining, the mirrored stack is unfolded and the full autoencoder is fine-tuned with backpropagated reconstruction error.

5. In a denoising autoencoder, which vector is fed to the encoder and which is the target?

Check your answer

The corrupted input 𝐱~ is fed to the encoder. The decoder output is compared with the original clean 𝐱 target.

6. Under what conditions is the autoencoder–PCA relationship stated here?

Check your answer

Centered data, a linear encoder and decoder, an undercomplete dimension k, squared reconstruction loss, and optimization to a globally best reconstruction of rank at most k. A leading PCA subspace gives an optimal reconstruction, but a tie at the retained/discarded boundary can make that subspace non-unique; data rank below the code dimension also leaves unused directions undetermined. An arbitrary latent basis need not equal PCA coordinates.
