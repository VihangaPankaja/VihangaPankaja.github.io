Q-Learning and Temporal-Difference Updates

Learn how Q-values are updated from sampled transitions, how terminal and stochastic cases change the target, and when convergence claims apply.

Big picture

Q-learning learns the long-run value of taking an action in a state. It does this from experience: take an action, observe its immediate reward and next state, then revise only that state–action estimate. The update looks ahead using the best estimated next action, so delayed reward can spread backward one transition at a time.

Begin with Reinforcement Learning: MDPs, Values, and Exploration for state, action, reward, and discounted return. The key distinction here is between a deterministic replacement rule and a stochastic incremental rule.

The target: reward now plus the best estimated future

At a nonterminal state, the optimal state value is the largest optimal action value among its available actions:

V*(s)=maxa∈A(s)Q(s,a)

For a deterministic transition, the action value is its immediate reward plus the discounted optimal value of the resulting state:

Q(s,a)=r(s,a)+γV*(s′)

This relationship motivates the recursive next-action maximum. Let s be the current state, a the action just taken, r the observed immediate reward, and s′ the observed next state. The learner keeps an estimate Q^(s,a) of the action value. For a nonterminal transition, the one-step target is:

T=r+γmaxa′∈A(s′)Q^(s′,a′)

The reward is the feedback for this transition. The discount γ controls how much later value counts; for a continuing discounted task here, 0≤γ<1. The maximum is over candidate actions available at the observed next state s′, not actions at the old state s.

The target uses one sampled transition even when the environment is stochastic. Across repeated samples, the expected target reflects the expected reward and next-state outcomes. The next-state maximum is an off-policy choice: it evaluates the best next action even if the behavior policy actually chooses another action to explore.

Deterministic worlds: replace the sampled entry

When a state–action pair always produces the same reward and next state, start each estimate at zero and replace the experienced entry with its target. This is a direct assignment: no learning-rate blend is applied.

Q^(s,a)←r+γmaxa′∈A(s′)Q^(s′,a′)

After updating, the learner continues from s′ and repeats. Entries for state–action pairs not sampled on this step remain unchanged.

Worked example: update s1 after moving right to s2

Givens. The sampled transition is s1 → s2 using right; reward r=0 and γ=0.9. At s2, the three candidate action values are 63,81,100.

  1. Compare only the next-state candidates: max{63,81,100}=100.
  2. Form the target: 0+0.9(100)=90.
  3. Directly assign Q^(s1,right)←90. No α is introduced in the deterministic rule.
  4. Other table entries are untouched by this update.

Check: the immediate reward contributes 0; the next-state maximum contributes 90. Replacing an old estimate by 90 follows the deterministic rule.

Under these assumptions: zero initialization, deterministic transitions, and nonnegative rewards yield monotone estimates bounded by the true action values. This property does not extend automatically to negative rewards, stochastic blends, or arbitrary initial estimates.

Stochastic worlds: blend old knowledge with one sample

If the same state and action can produce different rewards or next states, a single observation should not erase all earlier experience. In this case, Q and V describe expected values and the update uses an incremental blend. At visit n, the observed sample supplies the target; only the sampled entry changes.

Q^n(s,a)=(1−αn)Q^n−1(s,a)+αn[r+γmaxa′∈A(s′)Q^n−1(s′,a′)]

Equivalently, the update moves the old estimate toward the sampled target by the learning rate αn:

Q^n(s,a)=Q^n−1(s,a)+αn[Tn−Q^n−1(s,a)]

Here, the error is target minus old estimate. When 0<αn<1, the result lies between the old estimate and this sample’s target. The sample is not the full expectation; repeated experience supplies information about the expected return.

Visit-count convention and first learning rate

The visit-based rate is αn=11+visitsn(s,a); the visit count may include or exclude the current sample, so state the convention.

How the visit-count index changes the first rate
ConventionCount on first updateFirst α
Previous visits, before current sample01/(1+0)=1
Visits including current sample11/(1+1)=1/2

For any stated calculation, declare the convention and increment the count consistently. The formula alone does not settle the first rate.

Terminal transitions: stop the bootstrap

For a true terminal transition, there is no future decision after s′. Its continuation value is zero, so use the reward alone as the target. A terminal state has no candidate actions for the maximum. This is different from a nonterminal state that happens to have zero-valued actions.

T={r,d=1r+γmaxa′∈A(s′)Q^(s′,a′),d=0

When d=1, T=r. Do not multiply a terminal reward by γ or add a nonexistent next-action value. When d=0, use the ordinary one-step target. State explicitly whether the observed transition ended the episode.

Two episodes: watch reward move backward

1. Episode 1 — advance from S0

The sampled behavior action is advance: S0 → S1, reward 0. At S1, candidate next actions are finish and loop; both current Q estimates are 0.

Target: 0+0.9max(0,0)=0. Old Q(S0,advance)=0; error = target − old = 0−0=0; with α=0.5, new value = 0+0.5(0)=0.

Only Q(S0,advance) is sampled and eligible to change; it remains 0. Other entries stay Q(S1,finish)=0 and Q(S1,loop)=0.

2. Episode 1 — finish at S1

The sampled behavior action is finish: S1 → terminal T, reward 10. T has no actions, so there are no next-state candidates and no bootstrap.

Target = 10. Old Q(S1,finish)=0; error = 10−0=10; new value = 0+0.5(10)=5.

Q(S1,loop) remains 0 and Q(S0,advance) remains 0. End of episode 1: (0,5,0) for (advance, finish, loop).

3. Episode 2 — advance using the old next-state values

The sampled behavior action is again advance: S0 → S1, reward 0. Before this update, Q(S1,finish)=5 and Q(S1,loop)=0. The behavior action taken after arriving at S1 is finish, but the target maximization does not depend on that choice: it compares every available next action.

Target = 0+0.9max(5,0)=4.5. Old Q(S0,advance)=0; error = 4.5−0=4.5; new value = 0+0.5(4.5)=2.25.

Only Q(S0,advance) changes. Q(S1,finish)=5 and Q(S1,loop)=0 are unchanged in this transition.

4. Episode 2 — finish at S1 and check the greedy actions

The sampled behavior action is finish: S1 → terminal T, reward 10. Since T is terminal, its candidate-action set is empty and the target is 10, with no γ multiplier and no bootstrap.

Old Q(S1,finish)=5; error = 10−5=5; new value = 5+0.5(5)=7.5. Q(S1,loop) stays 0 and Q(S0,advance) stays 2.25.

Final greedy check: at S1, finish wins because 7.5>0; at S0, advance is the only action and has value 2.25. Stop here: these two illustrative episodes show one-step propagation, not convergence.

Convergence: conditions matter

Convergence is conditional, not a promise for every implementation or learning-rate schedule. The classical 1992 theorem is for a finite, discrete Markov domain with bounded rewards and discounted dynamics, where 0≤γ<1. Every state–action pair must be sampled infinitely often. For the visits to each pair, a sufficient learning-rate condition is:

0<αni(s,a)<1,∑i=1∞αni(s,a)=∞,∑i=1∞αni(s,a)2<∞

Here, ni(s,a) is the time of the ith visit to that pair. These conditions let learning keep correcting estimates while reducing the noise of individual samples. Function approximation and arbitrary schedules are not covered by that tabular guarantee. 1992 Q-learning theorem and sufficient conditions.

The visit-based rate αn=11+visitsn(s,a) needs an explicit count convention. A particular implementation must still meet the theorem’s visitation and step-size conditions; this rate does not by itself guarantee convergence.

Reinforcement-learning algorithm families

Three algorithm families differ in the information they need and when they update.

Comparing reinforcement-learning algorithm families
FamilyEnvironment modelLearning signal and timingDistinguishing point
Dynamic programmingRequires a complete, accurate modelUses Bellman equations/relationshipsStrong mathematical foundation
Monte CarloNo model requiredLearns from complete episodes or experiencesWaits for episode outcomes
Temporal differenceNo model requiredIncremental updates from experience; Q-learning is an exampleFully incremental; more complex to analyze

Q-learning is one temporal-difference method. The families share the reinforcement-learning goal, but differ in model use and the timing of their learning signal.

Common mistakes

  • Using direct assignment in a stochastic world: replacement discards earlier samples; the incremental blend retains a weighted old estimate.
  • Calling reward the whole target: reward is immediate feedback; a nonterminal target also includes discounted next-state value.
  • Maximizing at the wrong state: compare the candidate values at the observed next state, not the old state.
  • Confusing behavior with target: behavior chooses the sampled action and can explore; the Q-learning target uses the best candidate value regardless of which next action behavior takes.
  • Bootstrapping beyond an episode end: terminal transitions have the reward-only target and T has no actions.
  • Assuming any visit schedule converges: convergence needs coverage and appropriate step sizes; arbitrary schedules or function approximation do not inherit the tabular theorem automatically.
  • Assuming an unvisited action starts optimistically: these examples initialize listed entries at zero. With zero initialization, an unvisited action can exceed a visited action whose estimate is negative; zero is not evidence of a positive prior reward.

Exam focus

  • Deterministic rule: directly replace the sampled Q entry by reward plus discounted next-state maximum.
  • Stochastic rule: move the old estimate toward a sampled target using α; only the sampled state–action entry changes.
  • Target components: observed reward, discount gamma, and the maximum over next-state candidate actions.
  • Behavior may explore; target maximization is greedy and off-policy.
  • Terminal target: reward only, with no bootstrap.
  • Visit-rate convention: state whether the count is before or includes the current visit.
  • Convergence: finite tabular setting, bounded rewards, repeated coverage, discounted dynamics, suitable per-pair rates; not arbitrary schedules or function approximation.
  • Families: dynamic programming (model + Bellman), Monte Carlo (complete episodes), temporal difference (incremental; includes Q-learning).

Practice questions

1. A deterministic transition has reward 3, discount 0.8, and next-state Q values 2 and 7. What does the direct-assignment rule write to the sampled entry?

Check your answer

The next-state maximum is 7, so the target is 3+0.8(7)=8.6. Directly assign 8.6 to the sampled Q(s,a); do not add a learning rate to this deterministic rule.

2. In the stochastic blend, the old estimate is 4, the learning rate is 0.25, and the sampled target is 8. What is the new estimate?

Check your answer

Error=8−4=4. New estimate=4+0.25(4)=5, equivalently 0.75(4)+0.25(8)=5. Only the sampled entry changes.

3. Behavior chooses a non-greedy next action with Q=2, while another available next action has Q=9. Which value enters the Q-learning target?

Check your answer

The target uses max(2,9)=9, regardless of the behavior choice. Behavior determines which action is sampled; the target maximization evaluates the best next action.

4. A sampled transition gives reward 6 and ends the episode. What is its target?

Check your answer

Target=6. The transition is terminal, so there is no next action to maximize over, no bootstrap, and no extra discount on the terminal reward.

5. If the visit count is the number of completed visits before the current sample, what rate does the displayed formula give on the first visit? What if the current visit is already included?

Check your answer

Before-current convention: visits=0⟹α=1. Including-current convention: visits=1⟹α=1/2. State the convention because the formula does not specify it.

6. Match each family: complete model and Bellman relations; complete episode returns; or incremental transition updates without a model.

Check your answer

Dynamic programming uses the complete model and Bellman relations. Monte Carlo learns from complete episodes. Temporal-difference methods update incrementally from experience without requiring a model; Q-learning is one example.
