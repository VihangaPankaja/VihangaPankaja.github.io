Integrated Gradients, SHAP, and Grad-CAM

Big picture

An attribution method asks how parts of an input or model representation relate to a chosen output. Before reading a number or heatmap, identify which scalar output is being explained and, for a path-based method, which baseline is the reference. Those choices define what the result means. Integrated Gradients follows a straight path from baseline to input and accumulates gradients; SHAP averages feature contributions across coalitions; Grad-CAM combines class-score gradients with convolutional feature maps to localize class-specific regions.

These methods answer different questions. Input attributions refer to input features. Layer Conductance refers to units in a selected hidden layer. Neuron Conductance then breaks one selected unit's conductance down by input feature. SHAP gives coalition-based contributions under a chosen value function. Grad-CAM produces a coarse spatial map for an image or spectrogram. None of these values is, by itself, a causal effect.

1. Choose the scalar output and reference

For a model with several outputs, an explanation is conditional on the output selected for differentiation. A classifier might return class scores or probabilities; a method needs one scalar target, such as the probability assigned to a named class. Do not assume the predicted class is the target unless it was selected.

A baseline is the reference input used to ask what changes between the reference and the actual input. A zero baseline is a convenient numeric reference, but it is meaningful only if zero represents a sensible comparison for the feature encoding. For one-hot columns and count features, a zero reference may mean “absent”; for another encoding or model, another reference may be more appropriate. Changing the baseline changes the question and can change the attributions.

2. Integrated Gradients follows a straight path

Let F be the chosen scalar output, x′ the baseline, and x the input. Integrated Gradients (IG) evaluates the gradient along the straight line from x′ to x. Each feature's accumulated gradient is multiplied by how far that feature moved away from its baseline. The formal equation below is the standard presentation of IG in Sundararajan, Taly, and Yan (2017).

x(α)=x′+α(x−x′),0≤α≤1
IGi(x;x′)=(xi−xi′)∫01∂F(x′+α(x−x′))∂xidα

State the target and endpoints

Supplemental calculation. Let F(x1,x2)=x12+3x2. Use baseline b=(1,0) and input x=(3,2). The target is this scalar function. The input displacement is x−b=(2,2).

The exact polynomial integral makes each attribution step visible.

Interpolate and differentiate

The straight path is x(α)=b+α(x−b)=(1+2α,2α). Substitute it into the gradient: ∇F=(2x1,3), so along the path ∇F(x(α))=(2+4α,3). The first gradient changes with α; the second remains 3.

Integrate each feature gradient

Feature 1: ∫01(2+4α)dα=[2α+2α2]01=4. Feature 2: ∫013dα=3.

These are the path-averaged gradient contributions before accounting for how far each feature moved.

Scale by input displacement

IG1=(3−1)·4=8 and IG2=(2−0)·3=6. Thus IG(x;b)=(8,6) and the attribution sum is 8+6=14.

Check completeness

F(b)=12+3(0)=1 and F(x)=32+3(2)=15, so the output difference is ΔF=15−1=14. With the named residual convention R=∑iIGi−ΔF, R=14−14=0. The sum matches the output change.

Completeness applies to the exact path integral under its differentiability conditions. A numerical implementation approximates the integral, so its reported convergence delta can be nonzero.

Why a mean is not the whole distribution

The sibsp histogram has a large mass at zero and a sparse tail of negative attributions extending to about −2.8. With a zero baseline, an input feature that is itself zero has zero input displacement and therefore zero IG for that feature. A small signed mean can therefore coexist with a few substantially negative cases. Positive and negative case values can also cancel when averaged.

The six-bin summary plots each bin's mean attribution against its mean feature value, with marker size representing the number of examples. Its visible pattern is more negative attribution at larger sibsp values, with fewer examples there. Read this as a distributional contrast, not as an exact lookup table or a causal relationship.

3. Follow attribution through hidden units

Input IG attributes a selected output directly to input features. Layer Conductance instead reports attribution flow to the outputs of a selected hidden layer; it extends path-based attribution to hidden neurons (Dhamdhere, Sundararajan, and Yan, 2018). Here it examines all 12 outputs of the first sigmoid layer, using the same zero baseline and selected survival probability. It is a layer-level view of that output.

4. SHAP averages marginal contributions over coalitions

SHAP treats features as players in a cooperative game. For each feature, its Shapley value averages the change in a chosen coalition value when that feature joins, across possible feature orders, following the additive feature attribution framing of Lundberg and Lee (2017). In a prediction explanation, the coalition value function determines how the model output is evaluated when some features are absent. That missing-feature convention (often involving background data), the expected-value reference, and the scalar target must be stated before interpreting numerical contributions.

SHAP can explain how features contribute to a specific prediction; a visual explanation can rank pixel regions for an image classification. This coalition idea differs from IG's gradient accumulation along a continuous input path. The methods can both produce per-feature contributions, but the reference and attribution calculation are different.

Givens: synthetic coalition values for features A and B; equal weight on both feature orders.

v(∅)=0, v({A})=2

v({B})=1, v({A,B})=5

Declare the toy coalition values

Supplemental synthetic example, not a Titanic result. Let the scalar game values be v(∅)=0, v({A})=2, v({B})=1, and v({A,B})=5. For two features there are two orders in which each feature can join.

Average feature A marginal contribution

If A joins first, its change is v({A})−v(∅)=2−0=2. If A joins second, its change is v({A,B})−v({B})=5−1=4. Average them: ϕA=12(2+4)=3.

Average feature B marginal contribution

If B joins first, its change is v({B})−v(∅)=1−0=1. If B joins second, its change is v({A,B})−v({A})=5−2=3. Average them: ϕB=12(1+3)=2.

Check the additive total and state the assumption

ϕA+ϕB=3+2=5=v({A,B})−v(∅). The contributions add to the full-coalition value relative to the empty coalition.

This arithmetic depends on the supplied coalition values. A real explanation needs an explicit rule for what the model receives when a feature is missing and which output is decomposed; these toy values are not model measurements.

5. Grad-CAM localizes a selected class in a spatial feature map

Grad-CAM is for CNN-based image or spectrogram tasks. It sends gradients from a selected class score back to a convolutional feature layer. For each channel, it averages the class-score gradients over spatial positions to get a channel weight; it combines that weight with the channel's feature map and applies ReLU to retain positive evidence for the chosen class. This formal calculation follows Selvaraju et al. (2017). The result is a class-specific, usually coarse spatial localization map, not an exact pixel attribution.

Applications include highlighting frequency bands in a speech spectrogram for emotion recognition or image regions for a “cat” prediction. The target class matters: another class can produce another map. The map can show where the model's convolutional representation provides positive evidence for that target, but it does not prove those regions caused the real-world outcome or that the explanation is complete.

All entries are nonnegative, so applying ReLU leaves the toy map [1121] unchanged. No normalization is applied. The cells are feature-map locations in this toy example, not pixel coordinates; changing the selected class changes the gradient weights and may change the map.

Common mistakes

  • Leaving the target implicit: an attribution is conditional on a selected scalar output. Name the class and score being explained.
  • Treating a baseline as neutral by default: a zero vector encodes a particular reference. Check whether it makes sense for the model's inputs.
  • Mixing up signed and absolute summaries: a signed mean can cancel; mean absolute attribution removes direction. Always name the statistic.
  • Reading a mean as every case: distributions can contain a large zero mass and a sparse tail, as in the saved sibsp plot.
  • Calling attribution correlation or causation: the values describe a method's decomposition of a model output relative to its reference, not a measured association statistic or intervention effect.
  • Confusing layer and neuron conductance: Layer Conductance assigns output attribution to layer units; Neuron Conductance decomposes one selected unit's conductance over input features.
  • Assigning semantic meaning to neuron indices: a large or small mean at an index does not name what the unit represents.
  • Treating SHAP values as assumption-free: coalition values depend on the output and how absent features are represented.
  • Reading Grad-CAM as exact pixels or attention: it is a class-specific coarse map from CNN feature maps and gradients; it is neither a pixel-level decomposition nor proof of causation.
  • Claiming completeness from rounded batch means: check matching per-example attributions and output differences; rounded means alone may not support that check.

Exam focus

  • Start an explanation with the selected scalar output. For IG and conductance, also state the baseline and selected layer/neuron where applicable.
  • IG = input displacement × path-integrated feature gradient; its completeness target is the output difference from baseline.
  • A baseline is part of the question. In the recorded Titanic example, the default zero baseline is used; target=1 selects the survival probability from the softmax output.
  • Signed means and mean absolute values answer different questions. Inspect case distributions when values are heterogeneous or sparse.
  • Layer Conductance attributes to selected hidden-layer outputs; Neuron Conductance breaks one selected neuron's conductance down by input feature.
  • SHAP averages marginal feature contributions over coalitions under an explicit value function/missing-feature convention.
  • Grad-CAM averages selected-class gradients per convolutional channel, weights feature maps, sums them, and applies ReLU to form a coarse spatial map.
  • Attribution is model-relative evidence for a selected output, not a causal effect.
