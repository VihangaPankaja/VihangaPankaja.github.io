RNNs, LSTMs, and GRUs

Big picture

An ordinary feed-forward network treats each example as a fixed-size object. Ordered data such as words, audio snippets, video frames, DNA, and skeletal motion also depend on what came before and may vary in length. A recurrent neural network (RNN) reads one step at a time and carries a hidden state forward. LSTM and GRU cells add gates that control how information is retained, written, and exposed.

Recurrent state and shared parameters

At each time step, the hidden state combines the current input with the previous hidden state. It acts as a learned summary that can influence later outputs. The same recurrent cell and weights are reused at every time step; unrolling draws those repeated applications as separate boxes so the computation is easier to follow.

ht=fH(W1Hxt+WHHht−1),yt=f0(WH0ht)

The learned matrices W1H, WHH, and WH0 connect input to hidden state, previous hidden state to current hidden state, and hidden state to output, respectively. The hidden activation is fH; the output activation is f0. Hidden activations can include ReLU or tanh. In the single-unit scalar analogue below, wx, wh, and wy represent those same three connections, and fy denotes the scalar output activation. These connection-based aliases avoid the slide prose's alternate w1,w2,w3 names.

ht=fH(whht−1+wxxt),yt=fy(wyht)

Match the input and output pattern to the task

The input/output shape determines where a recurrent model reads and emits values. One-to-many captioning starts from an image representation and generates words. Many-to-one sentiment analysis reads all words before returning one label. Many-to-many tasks can emit along the input or encode one sequence before generating another.

Pattern What the sequence model receives and returns Slide example
One-to-one One input → one output A conventional fixed-size mapping
One-to-many One input → an output sequence Image caption: “A person riding a motorbike on dirt road”
Many-to-one An input sequence → one output “Awesome movie. Highly recommended.” → positive sentiment
Many-to-many An input sequence → an output sequence “I have many students” → “Habeo multos alumni”

The machine-translation slide shows “Echt dicke Kiste” becoming hidden states h1,h2,h3, then two outputs “Awesome sauce” at y1,y2. Different input and output lengths illustrate sequence-to-sequence encoding and generation.

Bidirectional context

A bidirectional RNN runs a forward recurrence using the previous forward state and a backward recurrence using the next backward state. It concatenates the two states at each position before producing that position’s output. The resulting prediction can use past and future sequence context, which suits tasks where the full sequence is available.

h→t=σ(W→(hh)h→t−1+W→(hx)xt),h←t=σ(W←(hh)h←t+1+W←(hx)xt),yt=f([h→t;h←t])

The displayed equations use sigmoid, as written on the slide. The two bank sentences shown there are “That bank is my favourite for, business” and “That bank is my favourite for, fishing”; the highlighted final words show how right context can distinguish the intended sense.

Backpropagation through time and the vanilla-RNN limitation

Training an RNN uses backpropagation through time (BPTT): the unrolled sequence makes the recurrent dependencies through earlier steps explicit for gradient computation. The lecture says vanilla RNNs are more sensitive to vanishing gradients than CNNs and notes that the hidden state may lose information as a sequence is processed, making long dependencies difficult to retain. This is a tendency and limitation, not a claim that every gradient always vanishes.

Supplemental explanation. A gradient through many repeated nonlinear transitions contains products of derivatives and recurrent weights. For the logistic sigmoid, σ′(u)≤14; equality holds at u=0. Repeated factors can shrink a gradient. Other factors and paths matter, so this bound alone does not prove that every complete gradient vanishes.

LSTM cell and hidden state

An LSTM maintains both a cell state Ct, which carries information along the sequence, and a hidden state ht, which is the exposed recurrent output. In the slide’s diagram the initial values are C0=h0=0. The forget, input, and output gates plus the candidate are computed from the concatenated previous hidden state and current input.

ft=σ(Wf·[ht−1,xt]+bf),it=σ(Wi·[ht−1,xt]+bi),ot=σ(Wo·[ht−1,xt]+bo)
C~t=tanh(WC·[ht−1,xt]+bC)
Ct=ft⊙Ct−1+it⊙C~t,ht=ot⊙tanh(Ct)

Read the computation in dependency order: compute ft,it,ot and the candidate; form Ct from retained old cell contents plus the gated candidate; then compute ht from the new cell. The symbol ⊙ denotes the Hadamard (elementwise) product, so gate and state vectors are multiplied coordinate by coordinate. The slide describes the input gate as protecting the current step from irrelevant inputs, the forget gate as limiting information passed from one cell to the next, and the output gate as controlling what information is exposed as the hidden state. These are qualitative gate roles, not fixed literal decisions.

1. Evaluate gates and candidate at x1=1

Concatenate in the stated order [h0,x1]=[0,1]. Each gate has zero weights and zero bias, so f1=i1=o1=σ(0)=0.5. The candidate weights [0,1] give tanh(1).

C~1=tanh(0·0+1·1+0)=tanh(1)=0.7615941559557649

2. Update C1 and h1

Use C0=h0=0. Keep full precision for the state passed to the next step.

C1=0.5·0+0.5·0.7615941559557649=0.3807970779778824
h1=0.5tanh(0.3807970779778824)=0.18169974219452623

3. Evaluate gates and candidate at x2=0

Carry the full-precision h1 from the preceding step. The zero gate weights still make all gates 0.5. Candidate weights [0,1] yield tanh(x2)=0.

(f2,i2,o2)=(0.5,0.5,0.5),C~2=tanh(0)=0

4. Update C2 and h2

The old cell is retained by one half and the candidate contributes zero.

C2=0.5·0.3807970779778824+0.5·0=0.1903985389889412
h2=0.5tanh(0.1903985389889412)=0.09406533405666029

5. Evaluate gates and candidate at x3=−1

Carry the full-precision h2 from the preceding step. The gate input order is [h2,x3]. Gates remain 0.5; the candidate preactivation is −1.

(f3,i3,o3)=(0.5,0.5,0.5),C~3=tanh(−1)=−0.7615941559557649

6. Update C3, h3, and verify

Combine half the previous cell with half the negative candidate, then expose half of tanh(C3) through the output gate.

C3=0.5·0.1903985389889412+0.5·(−0.7615941559557649)=−0.2855978084834118
h3=0.5tanh(−0.2855978084834118)=−0.13903901172803199

Checks: every gate used [ht−1,xt] in that order; Ct used Ct−1; ht used the newly updated Ct. These are forward calculations only; no weights are updated.

The lecture describes the gated memory cell as mitigating both vanishing and exploding gradients. It says the cell path can help preserve backpropagated error over long spans and claims learning over >1000 time steps. These are the lecture’s stated motivations and capabilities; gates do not guarantee stable gradients for every trained LSTM.

GRU gate topology

A gated recurrent unit (GRU) uses a reset gate and an update gate. The ID28 diagram shows the two gates and the reset path into candidate construction. For a precise convention, the supplemental equations below follow the original GRU definition by Cho et al. (2014). Here zt weights the retained previous state, and 1−zt weights the new candidate.

rt=σ(Wrxt+Urht−1),zt=σ(Wzxt+Uzht−1)
h~t=tanh(Whxt+Uh(rt⊙ht−1))
ht=zt⊙ht−1+(1−zt)⊙h~t

The reset gate scales the previous state before it contributes to the candidate. The update gate controls how much of the previous state carries forward. In the diagram, the candidate receives xt and rt⊙ht−1 only. The parameter table shows fewer parameters for its GRU layers than for its LSTM layers; counts depend on implementation and bias convention.

Sequence outputs, final states, and model comparison

The worksheet’s sequence-reversal task takes a length-six sequence over ten symbols and targets the reversed order. It one-hot encodes symbols, defines 20,000 training and 200 test examples, and configures training for up to 100 epochs with a 10% validation split and early stopping on validation loss (patience 20).

Its model definitions compare an MLP with two recurrent layers (SimpleRNN, GRU, or LSTM) and a time-distributed 10-way output. In the recurrent model, returning all per-step hidden outputs lets the next time-distributed layer predict one output at every sequence position. In encoder-decoder use, the transferred final hidden state and, for an LSTM, final cell state can instead summarize the encoded input.

The notebook’s MLP takes the fixed (6, 10) sequence array through dense widths 32 and 16, then a 10-class softmax. Its recurrent alternatives use two 16-unit SimpleRNN, GRU, or LSTM layers, each configured to return the full sequence, then a time-distributed 10-class softmax. The worksheet compiles these models with categorical cross-entropy and Adam.

Each panel below isolates the state-sharing choice shown in the lecture. The first two are the final hidden state hT and all hidden states. The final two include the LSTM cell state: final hT plus CT, or all ht outputs plus final CT.

In Keras terms, return_sequences=True returns hidden outputs for every time step. return_state=True additionally returns the final state; an LSTM has both final hidden and final cell states, while SimpleRNN and GRU have a hidden state. The four source diagrams distinguish final hT, all hidden states (h1,…,hT), final hT plus CT, and all hidden states plus final CT.

The slides report two-layer output shapes of (None, 6, 16) for recurrent layers and (None, 6, 10) for the time-distributed output. They report per-layer counts SimpleRNN 432/528/170, LSTM 1,728/2,112/170, and GRU 1,344/1,632/170. These are reported slide figures for the illustrated implementation, not universal counts: framework conventions, especially recurrent biases, affect parameter totals.

Encoder-decoder and visual question answering examples

For translation, the slides describe an encoder RNN that turns the input sentence into a hidden representation, then a decoder RNN that uses that representation to produce a translated sentence. The input and output sequences can differ in length and representation, with information passed through a context representation.

The visual-question-answering figure combines two paths: a CNN encodes the image of a dancing person, while an RNN encodes the question “Is this person dancing ?”. A fully connected network returns probabilities over the slide’s 1,000-answer space. The architecture lets the final classifier use both image and question representations.

Common mistakes

  • Treating the copies in an unrolled RNN as separately parameterized cells. They share the same recurrent parameters.
  • Confusing the previous state ht−1 with the newly computed ht, or the previous LSTM cell Ct−1 with Ct.
  • Reading the LSTM equations in slide bullet order instead of dependency order: gates and candidate first, then cell, then hidden output.
  • Saying the LSTM hidden state and cell state are interchangeable. They have different roles and both may be passed to a decoder.
  • Claiming a bidirectional output uses only past context. The backward pass supplies future context too.
  • Treating all sequence tasks as many-to-many aligned at each input step. Translation can consume one sequence then generate a different-length output.
  • Calling the slide accuracy percentages worksheet results or universally comparable measurements.
  • Treating reported parameter counts as architecture constants; implementation conventions affect them.
  • Claiming the sigmoid derivative bound σ′(u)≤14 proves all complete gradients always vanish. The recurrent path contains other factors and routes.

Exam focus

  • RNN state: ht depends on xt and ht−1; parameters are shared through time.
  • BPTT trains through the unrolled temporal dependencies; vanilla RNNs are susceptible to vanishing gradients and losing long-range information.
  • LSTM states: cell Ct and hidden ht. Compute gates and candidate from [ht−1,xt], then Ct=ft⊙Ct−1+it⊙C~t, then ht=ot⊙tanh(Ct).
  • GRU: reset gate affects candidate construction; update gate zt controls retention of prior state in the supplemental convention.
  • return_sequences controls all time-step hidden outputs; return_state exposes final state(s).
  • Encoder-decoder sharing options: final hT; all ht; final hT and CT; all ht plus final CT.
  • Parameter counts and accuracy values in these slides are implementation/example-specific reported values.

Practice questions

1. Which values enter the RNN transition at time t, and what is shared?

Check your answer

The current input xt and previous hidden state ht−1 enter the transition. The same recurrent cell parameters are reused at each time step.

2. For the supplemental scalar RNN, with h0=0, (x1,x2,x3)=(1,2,0), wx=1, wh=0.5, b=0, what are the states?

Check your answer

h1=ReLU(1+0)=1; h2=ReLU(2+0.5)=2.5; h3=ReLU(0+1.25)=1.25. The same coefficients are used each time.

3. What are the two LSTM states, and which one is directly exposed through its output gate?

Check your answer

Ct is the cell state that carries information along the cell path. ht is the hidden state; the output gate controls it through ht=ot⊙tanh(Ct).

4. In what order should an LSTM forward step be calculated?

Check your answer

Compute ft,it,ot,C~t from [ht−1,xt]. Then calculate Ct=ft⊙Ct−1+it⊙C~t. Finally calculate ht=ot⊙tanh(Ct).

5. In the supplemental GRU convention, what do the reset gate rt and update gate zt control?

Check your answer

The reset gate rt scales the previous state in the candidate calculation h~t=tanh(Whxt+Uh(rt⊙ht−1)). The update gate zt weights the retained previous state in ht=zt⊙ht−1+(1−zt)⊙h~t.

6. What differs between return_sequences and return_state?

Check your answer

return_sequences returns hidden outputs at every time step. return_state additionally returns the final state; an LSTM has final hT and CT.

7. In the visual-question-answering architecture, what does each input branch encode, and what does the classifier return?

Check your answer

The CNN encodes the image, and the RNN encodes the question. The fully connected network combines their representations and returns probabilities over the answer choices.
