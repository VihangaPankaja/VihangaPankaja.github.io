Neural Machine Translation, Attention, and Transformers

Neural machine translation learns one sequence-to-sequence model, then uses attention to connect target predictions to source information. The Transformer replaces recurrence with masked and unmasked attention, while subword units help keep rare words representable.

Big picture

Machine translation must produce a target sequence that preserves the source meaning. Classical phrase-based systems combine separate translation, language-model, and search components. Neural machine translation (NMT) instead trains one model end to end: an encoder reads the source, and a decoder generates the target token by token. The first recurrent design squeezed the whole source into one fixed-size context. Attention gave the decoder access to source states while it generated. The Transformer then removed recurrence by using attention throughout its encoder and decoder. Subword tokenization addresses a separate vocabulary problem: rare or unseen whole words can still be represented as smaller pieces.

This topic builds on classical machine translation and sequence models. It ends with BPE, which the next topic uses when discussing decoding.

Recurrent encoder–decoder: source to target

The encoder reads source words in order and compresses them into a fixed-length context vector c. The decoder is a conditional language model: it predicts each next target word using c and the target history generated so far. For the lecture's schematic example, source A B C D is translated into X Y Z EOS, where EOS marks that generation is finished. Words enter as embeddings, dense vectors in which distributionally similar words are geometrically close. This lets learned patterns generalize across related words instead of treating each word as an unrelated symbol.

Worked example: follow the source and target dependencies

Given: source tokens A B C D; decoder inputs <eos>, X, Y, Z; predicted targets X, Y, Z, <eos>.

  1. The recurrent encoder consumes A, then B, C, and D in source order. Its final fixed-length representation is the context c.
  2. The decoder receives c and the initial <eos> input to predict X. In this figure, that input marks the boundary before the target sentence starts.
  3. To predict Y, it uses c and the preceding target token X. To predict Z, it uses c and the prefix X Y.
  4. With Z as the next input and the previous target history in its recurrent state, it predicts <eos>; that output marker ends generation.
  5. Check: decoder inputs are shifted one step behind their predictions. Source order determines the encoder input; target history conditions each decoder step. The diagram's feedback arrow means prior target tokens are available, not that the source is read again.

Fixed-vector bottleneck and attention

In the plain recurrent encoder–decoder, the entire source sentence must pass through one fixed-length vector c. Information from early words must survive many recurrent updates, and once generation begins the decoder cannot return to separate source states. The lecture reports Cho et al. (2014) observing BLEU degradation for sentences beyond roughly 30 tokens. That is a reported result for that setting, not a universal length threshold for NMT.

Attention changes the information path: the source states remain available, and each target step forms a context from the source states that matter for that step. This does not remove the fixed-vector bottleneck from the basic model retroactively; it describes a different conditioning pathway.

Global and local attention

Luong et al. (2015) contrast two alignment scopes. Global attention scores all encoder states for the current decoder state and takes their weighted average. Local attention first predicts a source position pt, then scores a window around that position and averages only states in that window. In both cases, the alignment weights say how much each eligible source state contributes to the context ct; the context then informs the current target prediction.

Worked example: distinguish local and global context

Given: a current target decoder state ht and an ordered sequence of encoder states.

  1. For global attention, compare ht with every source state. The resulting alignment vector has one weight for each source position; combine all states using those weights to obtain ct.
  2. For local attention, first predict the aligned position pt. Select the source window around pt, score states inside that window, and combine only those states into ct.
  3. In either case, the weights are associated with source positions, and the weighted sum is the context. A new target step can have a different alignment and context.
  4. Check: the key distinction is the set of source states eligible for weighting: every state for global, a predicted window for local. The lecture diagrams provide no numeric alignment weights, so none are assumed here.

Scaled dot-product attention

The Transformer projects vectors into queries (Q), keys (K), and values (V). A query is compared with keys to produce compatibility scores; softmax converts each query row into weights; those weights combine the value vectors. In self-attention, Q, K, and V come from the same sequence. In encoder–decoder cross-attention, Q comes from decoder states, while K and V come from encoder outputs.

For query length Lq, key/value length Lk, key width dk, and value width dv, the shapes are Q: Lq×dk, K: Lk×dk, V: Lk×dv. Scores and normalized weights have shape Lq×Lk; the result has shape Lq×dv. Each row corresponds to one query position. Its weights span key positions, and that row's weighted sum is taken over the corresponding rows of V.

Attention(Q,K,V)=softmax(QKTdk)V

The scale by dk keeps dot products from growing just because key vectors have more components. In decoder masked self-attention, scores for future target positions are set to negative infinity before softmax. Their normalized weight is therefore zero, so a position cannot use a later target token it is meant to predict. This is the causal future mask used during target generation.

Supplemental calculation: one query attends to two values

This Supplemental calculation makes the score → softmax → weighted-value dependencies explicit; its numbers are instructional, not lecture weights.

Givens: scalar query q=1; keys k1=0, k2=ln(3); values v1=2, v2=10; key dimension dk=1.

  1. Scores. The scale is 1=1. Thus qk1dk=1·01=0 and qk2dk=1·ln(3)1=ln(3). The score row is (0,ln(3)).
  2. Exponentials. Softmax uses exp(0)=1 and exp(ln(3))=3. Their denominator is 1+3=4.
  3. Weights. Divide each exponential by 4: α1=14 and α2=34. Check normalization: 14+34=1.
  4. Weighted values. The first contribution is 14·2=12; the second is 34·10=152.
  5. Context. Add the contributions: 12+152=8. Because the weights are nonnegative and sum to one, 8 lies between the input values 2 and 10. This is a convex-average check.

For a supplemental causal-mask check, suppose key 2 is a forbidden future target position. Replace its score ln(3) with −∞ before softmax. The exponentials become 1 and 0; the weights become 1 and 0; the context is 1·2+0·10=2. The future value contributes nothing.

Multi-head attention and positional information

A single attention distribution can express one set of pairwise relationships. Multi-head attention runs H attention operations on learned lower-dimensional projections, concatenates their outputs, then applies an output projection. With model width dmodel split evenly across H heads, each head's projected width is dmodel/H; the concatenated width returns to dmodel before the output projection. The matrices below show how each head uses its own Q, K, and V projections.

Unmasked self-attention without positional information is permutation-equivariant: permuting input positions reorders the output positions in the same way. It does not make the per-token output tensor invariant to reordering, and it does not encode token order by itself. This statement does not apply to causally masked decoder self-attention, whose position-indexed mask imposes a left-to-right constraint. The lecture adds positional encodings to token embeddings so the model receives position information. The sinusoidal formulas use position pos, model width dmodel, and pair index i; 2i selects an even dimension and 2i+1 the following odd dimension.

PE(pos,2i)=sin(pos100002i/dmodel)PE(pos,2i+1)=cos(pos100002i/dmodel)

Givens: first pair index i=0; positions pos=0 and pos=1.

  1. For i=0, the denominator is 100000/dmodel=1, for any positive model width.
  2. At position 0, the even component is sin(0/1)=0; the following odd component is cos(0/1)=1. The pair is (0,1).
  3. At position 1, the even component is sin(1)≈0.8415; the odd component is cos(1)≈0.5403 (angles in radians).
  4. Add each position vector to the embedding at that position. Even the first dimension pair differs between these two positions.
  5. Check: the calculation uses the same dimension pair at both positions; only pos changes.

Transformer encoder and decoder blocks

The encoder block consists of multi-head self-attention followed by a position-wise feed-forward network. The decoder block orders masked self-attention first, encoder cross-attention second, then the feed-forward network. Cross-attention receives decoder queries and encoder keys and values, connecting the target stream to the encoded source. Each side stacks N blocks; the original 2017 paper used six encoder blocks and six decoder blocks.

The original Transformer motivation was to remove recurrence's sequential computation and shorten paths between distant positions, enabling more parallel computation. A shorter path between two positions does not make the full attention computation constant-time; attention still computes interactions across positions.

Worked example: trace one decoder block in order

Given: source encoder outputs; a target prefix whose next token is being predicted.

  1. Add positional encodings to the target-prefix embeddings and pass them through masked self-attention. Future target positions receive −∞ scores before softmax.
  2. Pass those decoder states as Q to cross-attention. Use encoder outputs as K and V; the decoder can retrieve source information relevant to its target state.
  3. Pass the cross-attention result through the position-wise feed-forward network.
  4. Repeat this ordered decoder block through the stack. At the top, the representation is used to score the next token, including EOS.
  5. Check: decoder order is masked self-attention → cross-attention → feed-forward. The encoder's corresponding order is self-attention → feed-forward, and encoder outputs feed cross-attention as K and V.

Byte-pair encoding builds subword pieces

A softmax over a large whole-word vocabulary is expensive, and a fixed word list can leave rare words out of vocabulary. Byte-pair encoding (BPE) starts from character symbols and repeatedly merges adjacent pairs according to a learned merge list, stopping after a fixed number of merges. Frequent words may become single tokens, while rarer words can remain sequences of pieces. This supports open-vocabulary representation, but learned subword boundaries are not guaranteed to be morpheme boundaries. The literal </w> symbol marks a word ending in this example. The table shows every word state after each printed merge. Common mistakes

  • Treating the recurrent fixed-context model and attention as one unchanged path. The first has a single context vector; attention forms a context from source states for each target step.
  • Calling the roughly 30-token observation a universal cutoff. It is a particular reported result, not a general law.
  • Confusing global attention's all-source scope with local attention's predicted window.
  • Swapping cross-attention roles: decoder states provide Q; encoder outputs provide K and V.
  • Applying a future mask after softmax. Future scores must be removed before normalization so their weights become zero.
  • Saying position-free self-attention gives an identical output tensor under permutation. It is permutation-equivariant: outputs reorder with inputs, and order is not encoded by attention alone.
  • Treating the block diagram as including residual and normalization layers. The lecture's shown order covers attention and feed-forward components only.
  • Reading BPE pieces as guaranteed morphemes, or inferring pair frequencies from the displayed merge sequence. Neither is justified by these states.

Exam focus

  • Basic recurrent NMT: encoder reads the source into fixed-size c; decoder predicts each next target token from c and the target prefix, ending with EOS.
  • Attention: global scores all source states; local predicts pt and scores a surrounding window. Both form a weighted context.
  • Scaled dot-product: scores are QKTdk; row-wise softmax gives key-position weights; multiplying by V forms one output row per query.
  • Roles: self-attention draws Q/K/V from one sequence; encoder–decoder cross-attention draws Q from decoder states and K/V from encoder outputs. Future target positions are masked before softmax.
  • Multi-head: independently project, attend, concatenate, and output-project. Positional encoding supplies order information; the sinusoidal even/odd components use sine/cosine.
  • Blocks: encoder self-attention → feed-forward; decoder masked self-attention → cross-attention → feed-forward. Stack N per side; six per side in the original paper.
  • BPE: start with characters and word-end markers, apply a fixed merge sequence, and reuse it. Open-vocabulary pieces need not be morphemes.

Practice questions

1. In the basic recurrent encoder–decoder, what does the decoder use to predict the next target token?

Check your answer

The fixed source context c and the target history generated so far. It emits one token at a time and eventually predicts EOS.

2. A local-attention model predicts pt. Which source states are eligible for its context, and how does that differ from global attention?

Check your answer

Local attention scores states in a window around pt; global attention scores all source states. In either case, the weights combine eligible source states into a context vector.

3. If Q has shape 5×8, K has shape 7×8, and V has shape 7×12, what are the score and attention-output shapes? What does one row mean?

Check your answer

QKT has shape 5×7. After row-wise softmax, multiplying by V gives 5×12. Each of the five rows belongs to one query position; its seven weights refer to the seven key positions, and its output is a weighted sum of the seven value rows.

4. In decoder cross-attention, where do Q, K, and V come from? When must the causal mask be applied?

Check your answer

Cross-attention Q comes from decoder states; K and V come from encoder outputs. For masked decoder self-attention, set future-position scores to negative infinity before softmax, making their weights zero.

5. Without positional information, what does permutation-equivariance say about unmasked self-attention outputs?

Check your answer

If input positions are permuted, the output positions are permuted in the same way. The per-token output tensor is not generally invariant, and attention alone does not encode sequence order.

6. Apply the first two supplied BPE merges to newest. What symbols remain, and what can you infer about whether the final piece is a morpheme?

Check your answer

Starting with n e w e s t </w>, merge (e,s) → es to get n e w es t </w>, then merge (es,t) → est to get n e w est </w>. This merge trace alone does not establish that est is a morpheme.
