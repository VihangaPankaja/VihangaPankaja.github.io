Convolutional Neural Networks

Learn how local filters, shared weights, feature maps, pooling, and skip connections organize image-processing networks.

Big picture

A convolutional neural network (CNN) builds image features from small neighborhoods. Each learned filter checks the same pattern at many locations, producing a feature map. Pooling then shrinks the spatial maps, and later layers combine the extracted features for a task such as room classification. This connects to the broader idea of layered representation learning in Deep learning foundations.

Local receptive fields and shared filters

A fully connected unit can receive every input value. A CNN unit instead sees a local receptive field: a small neighboring patch. The lecture’s receptive-field illustration shows one unit seeing the top-left 5×5 patch, while the next unit sees a patch shifted one column right. On an image, this makes nearby pixels interact first, so early stages can respond to local patterns such as edges. The lecture illustrates a progression from pixels and edges toward textures, motifs, parts, and objects.

A filter (or kernel) contains the weights applied to one local patch plus a bias. As the filter slides, the same weights and bias are reused at each location. This is weight sharing: one detector checks for the same learned pattern throughout the image. A shared filter can respond to that pattern at different positions, which is the intuition behind the lecture’s spatial-translation point. One filter creates one two-dimensional feature map, whose cells record responses at different positions. Multiple filters run in parallel and create multiple maps.

Supplemental channel interpretation. For an input with multiple channels, a filter uses weights across the input channels at each spatial offset and produces one output feature map; a bank of filters gives the output its channel depth. Each output channel is one spatial feature map; stacking these maps forms the layer’s output tensor. The lecture’s arithmetic example is single-channel.

In the source’s 28×28 single-channel example, a 5×5 filter with valid padding and stride 1 makes a 24×24 map. With 20 filters, the layer has 20×24×24=11,520 output activations. The shared parameter count is 20×(5×5+1)=520 weights and biases. These count different things: 11,520 responses are produced, while 520 learned parameters are reused to produce them.

Pooling reduces spatial size

Pooling combines values in a neighborhood into a smaller spatial map. It can reduce the representation’s size and make the exact location of a detected feature less important than its presence nearby. The lecture lists max, average, and L2 pooling, and cites smaller maps, fewer parameters, and reduced overfitting as motivations. Max pooling selects the largest neighborhood value. Average pooling reports the average (the slide notes it may be distance-weighted). L2 pooling takes the square root of the sum of squared values in the pool.

MaxPool(R)=maxx∈Rx,L2Pool(R)=∑x∈Rx2

The source’s 4×4 input is divided into four non-overlapping 2×2 windows with stride 2. The full maxima and 2×2 result below complete the source example.

Stacked CNN classification architecture

The lecture’s example extracts features with two convolutional layers, then uses max pooling to reduce feature-map size (typically by a factor of two). A fully connected layer and softmax layer follow for classification. The pictured output categories are living room, bedroom, kitchen, bathroom, and outdoor. The diagram expresses this order without adding unshown layer sizes.

As layers are stacked, later units combine responses from earlier maps. A deeper unit therefore depends on a larger region of the original image through the sequence of local connections. The exact learned filters are determined by training; the lecture cautions that their real learned patterns need not look like the simple lines or circles used as intuition.

Residual identity path

A residual block adds the block input to the output of a learned branch. In the source drawing, the learned branch contains two weight layers with a ReLU between them; the identity path carries x around both learned transforms and joins the branch at addition, before the final ReLU. F(x)+x is shorthand for that source topology, not a new performance guarantee. Direct addition requires compatible tensor shapes.

The lecture presents skip connections as a way to mitigate vanishing-gradient problems and says they allow training networks with over 1,000 layers. It lists ResNet variants with 18, 34, 50, 101, 152, and 200 layers, and names ResNeXt and DenseNet as related models. These are lecture statements and examples; they are not accuracy comparisons.

Common mistakes

  • Flipping the kernel when following this lecture’s worked operation: the displayed values use unflipped cross-correlation.
  • Counting every feature-map response as a separate learned parameter: shared weights are reused at every spatial location.
  • Confusing output activations with parameters: 11,520 responses and 520 shared weights/biases describe different quantities.
  • Forgetting that stride and padding change the output size; the 24×24 result assumes valid padding and stride 1.
  • Treating pooling as a learned convolution filter: the listed pooling operations summarize a local window.
  • Drawing the residual identity path into only the second weight layer: the source path bypasses both learned transforms and joins before the final ReLU.

Practice questions

1. What does one convolutional filter share as it moves across an image, and what does one filter produce?

Check your answer

The same kernel weights and bias are reused at every spatial position. Applying one filter produces one feature map whose cells are the responses at the different valid positions.

2. A 28×28 input uses 20 filters of size 5×5, valid padding, and stride 1. How many output activations and shared parameters are there?

Check your answer

Each spatial map is (28−5)/1+1=24 by 24. There are 20×24×24=11,520 activations. Each filter has 25 weights plus one bias, so there are 20×(25+1)=520 shared parameters. The first number counts outputs; the second counts learned values.

3. For the source 4×4 pooling input, list the four 2×2 window maxima in row-major order.

Check your answer

The windows are top-left max(1,3,4,2)=4, top-right max(5,3,3,1)=5, bottom-left max(3,1,0,1)=3, and bottom-right max(1,3,0,4)=4. Thus the result is [4534].

4. In the source residual block, where does x travel, and where does it rejoin the learned branch?

Check your answer

The identity path carries x around both weight layers. It joins the transformed branch at the addition node, after the second weight layer and before the final ReLU.
