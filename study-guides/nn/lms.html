Widrow-Hoff derivation and LMS calculations

Big picture

Widrow–Hoff learning turns ADALINE’s continuous linear response into a concrete optimization problem. Squared target error forms a quadratic surface over the weights and bias. Its expected gradient points uphill, so steepest descent moves in the opposite direction. LMS uses one observed pattern to estimate that gradient and update the parameters. The handout's loss has no one-half, which is why its update carries a factor of two.

Keep the symbols straight

The Lesson 3 and Widrow–Hoff pages use different letters for the same roles. In this page, p always means the feature vector, x the augmented parameter vector, z the augmented input, a the linear output, and e=t−a the residual. The matrix equation therefore reads a=xTz.

Role Lesson 3 Widrow–Hoff handout
Feature vector x p
Parameters w,b augmented x=[w;b]
Linear output and residual y, e=t−y a=xTz, e=t−a
Learning rate η α

In the handout, the augmented input is z=[p;1]. Its parameter vector is also called x, so the notation map matters: Lesson 3's feature vector x is the handout's p, while the handout's x means all adjustable weights and the bias together.

Augment the bias and write the objective

For one neuron with weight vector w and bias b, append a constant 1 to every input and append the bias to the parameter vector. This converts the separate bias operation into the same dot product used for the weights.

𝐱=[𝐰b],𝐳=[𝐩1],a=𝐱T𝐳=𝐰T𝐩+b

For Q equally weighted training pairs, the empirical mean-square error averages the squared residual over the examples. The handout's expected form uses the same idea without the one-half used by Lesson 3.

MSE=1Q∑q=1Q(tq−aq)2,F(𝐱)=E[(t−a)2]

The source labels the training pairs by q but uses k in the summation body. The guide consistently uses q; only the dummy index name changes.

Expand the loss into a quadratic

Define the target second moment c, target/input cross-correlation h, and augmented-input correlation matrix R. Expanding the squared error makes the curvature and the role of each data statistic visible.

c=E[t2],𝐡=E[t𝐳],𝐑=E[𝐳𝐳T]
F(𝐱)=E[(t−𝐱T𝐳)2]=c−2𝐱T𝐡+𝐱T𝐑𝐱

The entries of R are average products between input coordinates; its diagonal entries are average squared coordinate values. The vector h says how each coordinate co-varies with the associated target. Both include the constant bias coordinate because it is included in z.

From squared error to the Widrow–Hoff update

Givens: linear output a=xTz; target t; error e=t−a; objective F(x)=E[e2] with no one-half. The adjustable vector includes the bias, and the augmented input ends in 1.

1. Start with the expected squared error

For an augmented parameter vector x and input z, the linear output is a=xTz. The target residual is e=t−a. The handout minimizes the unhalved objective F(x)=E[e2].

Why this matters: differentiating the unhalved square leaves a factor of 2 in the update.

2. Expand the square before taking expectation

Rule: (t−xTz)2=t2−2txTz+(xTz)2.

Substitute into the objective: F(x)=E[t2−2txTz+xTzzTx]. Since the parameter vector is fixed while taking expectation, it can be factored outside: F(x)=E[t2]−2xTE[tz]+xTE[zzT]x.

3. Name the data statistics

Set c=E[t2], h=E[tz], and R=E[zzT]. The cross-correlation vector h connects each augmented input coordinate to its target. The correlation matrix R records pairwise products of augmented input coordinates.

Result: F(x)=c−2xTh+xTRx.

4. Read the gradient and curvature

Match the quadratic convention F(x)=½xTAx+dTx+c with A=2R and d=−2h. Because R is symmetric, ∇F(x)=2Rx−2h and the Hessian is ∇2F(x)=2R.

Check: vTRv=E[(vTz)2]≥0 for every vector v, so R is positive semidefinite and the objective has no negative-curvature direction.

5. Find the stationary parameters when the inverse exists

Set the gradient to zero: 2Rx−2h=0. If R is invertible, x*=R⁻¹h. Positive definiteness gives a unique minimizer.

If R is singular, do not write R⁻¹h. For a genuine squared-error objective, a minimizer still exists because h lies in the range of R; multiple parameter vectors can give the same minimum.

Why the range claim holds: if v is in the nullspace of R, then E[(vTz)2]=0, so vTz=0 almost surely and vTh=E[t(vTz)]=0. Thus h is orthogonal to the nullspace, which for symmetric R is its range.

6. Replace the expected gradient with one sample

At iteration k, use the instantaneous squared error e2(k) as a gradient estimate. Since ∂e/∂wj=−pj and ∂e/∂b=−1, the gradient coordinates are −2e(k)pj(k) and −2e(k). Together, ∇e2(k)=−2e(k)z(k).

Steepest descent subtracts this gradient, giving x(k+1)=x(k)+2αke(k)z(k). The positive sign follows from the target-minus-output error definition.

Quadratic geometry and the stationary solution

A symmetric quadratic has gradient Ax+d and Hessian A. Here A=2R and d=−2h, so the curvature is twice the input correlation matrix. For any direction v, vTRv=E[(vTz)2]≥0; the surface is convex, though it may be flat along some directions.

F(𝐱)=12𝐱T𝐀𝐱+𝐝T𝐱+c,𝐀=2𝐑,𝐝=−2𝐡
∇F(𝐱)=2𝐑𝐱−2𝐡,∇2F(𝐱)=2𝐑

When R is positive definite, the stationary point is the unique global minimum. If R is singular, the inverse expression is invalid. A finite least-squares problem still has at least one minimizer; deficient input directions can make that minimizer non-unique.

𝐑𝐱=𝐡,𝐱*=𝐑−1𝐡only when 𝐑 is invertible

From steepest descent to the LMS sample update

Exact steepest descent follows the expected gradient. Widrow and Hoff replace it with the gradient of the current sample's squared error. With e(k)=t(k)−a(k) and z(k)=[p(k);1], differentiating the unhalved loss gives the negative vector −2e(k)z(k). Subtracting it yields an additive correction proportional to the residual.

∇e2(k)=−2e(k)𝐳(k),𝐱(k+1)=𝐱(k)+2αke(k)𝐳(k)
𝐰(k+1)=𝐰(k)+2αke(k)𝐩(k),b(k+1)=b(k)+2αke(k)

The error is target minus output, so a positive residual increases the response in the direction of the presented input. The factor two belongs to this handout's no-half squared-error convention.

Factor two and learning-rate bounds

Lesson 3 uses E=½e2, producing the update w←w+ηep, b←b+ηe. The Widrow–Hoff reading uses F=e2, producing w←w+2αep, b←b+2αe. The directions agree; the factor can be absorbed into the learning-rate symbol, but the rate bound must use the same convention.

Lesson 3: E=12e2,Δ𝐰=ηe𝐩;Widrow–Hoff: F=e2,Δ𝐰=2αe𝐩

For the exact expected quadratic objective, deterministic steepest descent with this parameterization converges for a fixed positive step below the reciprocal of the largest eigenvalue of R. Equivalently, the general Hessian bound is α<2/λmax(A) and A=2R. This is a bound for the expected quadratic gradient dynamics; stochastic per-pattern updates do not guarantee monotone error after every sample, and practical behavior also depends on the input sequence and assumptions.

0<α<2λmax(𝐀)=1λmax(𝐑)

Lesson 3 presents the equivalent no-factor-two update bound 0<η<2/λmax(R) and the factor-two version 0<α<1/λmax(R). These are paired expressions, not interchangeable constants. Its separate input-count rule is an engineering heuristic and belongs with the ADALINE learning-rate example.

Quadratic definitions and theorem checks

The final handout page collects standard tests for positive definiteness. These matter because positive-definite curvature gives an invertible correlation matrix and a unique optimum, while zero eigenvalues indicate flat parameter directions.

How eigenvalues classify a symmetric quadratic

A stationary point of a symmetric quadratic solves Ax=−d. When the Hessian is singular, this requires the linear term to lie in its range. If that condition fails, there is no stationary point, even when the Hessian has both positive and negative eigenvalues.

Hessian eigenvalues Shape at a stationary point If the zero-curvature case has no stationary point
All positive One strict (strong) minimum —
All negative One strict (strong) maximum —
Positive and negative, no zero eigenvalue One saddle point —
Positive, negative and zero eigenvalues Saddle stationary points if the stationary equation is consistent; they may be non-unique No stationary point when the linear term is outside the Hessian's range
All nonnegative, at least one zero Weak minimum No stationary point is possible
All nonpositive, at least one zero Weak maximum No stationary point is possible

Teaching check: F(x)=(x12−x22)/2+x3 has Hessian eigenvalues 1, −1 and 0. Its gradient is ∇F=(x1,−x2,1)T, whose third component can never be zero. It therefore has no stationary point. Removing the linear x3 term instead gives a family of saddle stationary points along the third coordinate.

For the ADALINE objective, the Hessian is 2R and R is positive semidefinite, so the negative-eigenvalue and saddle cases cannot occur. Positive definiteness gives a unique minimum; singular positive semidefiniteness gives flat directions and the consistent least-squares minimum discussed above.

Theorem 3.4.1: entries of a positive-definite matrix

For a symmetric positive-definite matrix A=[aij]:

(i) 𝐀−1 exists;(ii) aii>0 (i=1,…,n);(iii) maxi≠j|aij|≤maxi|aii|;(iv) aij2<aiiajj (i≠j).

All four statements are valid. In particular, (iv) follows from positivity of each 2×2 principal minor. It also implies (iii), since |aij|<aiiajj≤maxrarr. The source states a weak inequality in (iii), which remains true.

Leading principal submatrices and definiteness tests

The leading principal submatrix Ak consists of the first k rows and first k columns. The source uses the following criteria for symmetric matrices:

𝐀≻0⟺det(𝐀k)>0 for every k=1,…,n⟺all eigenvalues of 𝐀 are positive
𝐀⪰0⟺all eigenvalues of 𝐀 are nonnegative

The last equivalence is the positive-semidefinite criterion; the handout's phrase “semi positive definite” is standardized here to the usual “positive semidefinite.”

When a singular quadratic still has a minimum

The handout first describes arbitrary positive-semidefinite quadratics: a linear term outside the range of the Hessian can prevent a stationary point. Its following ADALINE objective is more constrained. Here h=E[tz] is orthogonal to every null direction of R=E[zzT], so the normal equation Rx=h is consistent and at least one least-squares minimum exists. Singularity means the ordinary inverse formula is unavailable and the minimizing parameters may not be unique; it does not mean this finite squared-error fitting task has no minimum.

Common mistakes

  • Do not threshold a before calculating the LMS residual. A class label may be produced afterward, but training uses e=t−a.
  • Do not reverse the residual sign without reversing the update direction.
  • Do not pair Lesson 3's half-squared loss update with Widrow–Hoff's factor-two rate bound.
  • Do not omit the appended constant when forming the augmented correlation matrix; that would leave bias out of the optimization.
  • Do not use R⁻¹h when R is singular.
  • Do not treat the expected quadratic rate bound as a guarantee that every stochastic sample update lowers the dataset error.

Exam focus

  • Write x=[w;b], z=[p;1], and a=xTz before expanding the objective.
  • Remember c=E[t2], h=E[tz], R=E[zzT], and F=c−2xTh+xTRx.
  • The gradient is 2Rx−2h and Hessian is 2R.
  • For invertible R, the optimum is R⁻¹h; singular R requires solving the consistent normal equations without an ordinary inverse.
  • The no-half Widrow–Hoff rule is Δw=2αep, Δb=2αe.
  • With row-per-neuron weights, the multiple-output update is W←W+2αepT.

Practice questions

Why is the bias input appended as 1?

Check your answer

It makes the bias another weight in the dot product: [w;b]T[p;1]=wTp+b.

For the unhalved loss, why does the weight update contain 2?

Check your answer

Differentiating (t−wTp−b)2 gives the weight gradient −2ep. Gradient descent subtracts that gradient, producing +2αep.

What does singular R imply for the ordinary inverse solution?

Check your answer

R⁻¹h cannot be used. In an actual squared-error problem, solve Rx=h; solutions exist, but may not be unique because some input directions are redundant.

Does the rate bound promise that full-set MSE falls after every online presentation?

Check your answer

No. It describes the expected quadratic gradient dynamics under the stated assumptions. A stochastic sample update can temporarily increase error on the full dataset.
