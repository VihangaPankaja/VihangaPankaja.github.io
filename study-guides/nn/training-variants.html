Backpropagation variations and deeper networks

Compare update history, batch corrections, adaptive rates, activation gains, and a full two-hidden-layer backpropagation pass.

Big picture

Backpropagation can be changed along three different axes: carry update history (momentum), combine corrections from several patterns (batch updating), or adapt each weight’s step size (delta-bar-delta). Activation choices change a neuron’s range and gradient. A second hidden layer adds another representation stage and another chain-rule step.

These are variations on the Lecture 4 backpropagation rules. Review the main backpropagation derivation first if the meaning of the delta terms is unfamiliar. The perceptron topic is a separate single-layer threshold-learning procedure; it is not repeated here.

Carry update history or combine patterns?

Momentum adds a fraction of the previous parameter change to the current correction. The lecture writes the update with a plus-delta error convention:

Δwjk(t+1)=αδkzj+μΔwjk(t),Δvij(t+1)=αδjxi+μΔvij(t),0<μ<1

The hidden-to-output and input-to-hidden weights use their respective delta and input values. Momentum can build movement when corrections point in a consistent direction and soften the effect of an isolated noisy example; it does not guarantee faster convergence. The source gives no bias rule. Treating a bias as a weight on constant input 1 yields the same form with that input set to 1; that is a derivation, not a printed lecture equation.

Teaching example: momentum over three presentations

Momentum: three presentations of one pattern

Givens x=1,t=2,w=b=0,Δw(0)=Δb(0)=0,α=0.1,μ=0.5 Same pre-step values are used for each paired weight and bias update.

Start from a fresh state

Teaching example. Use one linear unit, y=wx+b, the repeated pattern x=1,t=2, and E=12(t−y)2. Start with w=b=0, previous changes Δw(0)=Δb(0)=0, α=0.1, and μ=0.5. With this loss, the lecture’s plus-delta signal is δ=t−y. The bias is treated as a weight on constant input 1.

Presentation 1: no history yet

Rule: Δw(t+1)=αδx+μΔw(t), with the same constant-input rule for b. Here y=0 and δ=2−0=2; so each change is 0.1·2·1+0.5·0=0.2. The new state is (w,b)=(0.2,0.2), giving y=0.4.

Presentation 2: carry the last change

Recompute first: y=0.2·1+0.2=0.4, δ=2−0.4=1.6. The current correction is 0.1·1.6·1=0.16 and the carried part is 0.5·0.2=0.10, so Δw=Δb=0.16+0.10=0.26. Add these simultaneously: (w,b)=(0.46,0.46), so y=0.92. The carried term is the previous update, not another pattern’s correction.

Presentation 3: update and check

Now y=0.46+0.46=0.92 and δ=2−0.92=1.08. The current correction is 0.1·1.08=0.108, and the carried part is 0.5·0.26=0.13; therefore Δw=Δb=0.108+0.13=0.238. This produces w=b=0.698 and y=1.396. The output moves closer to 2. Without momentum, the three changes would be 0.2, 0.16, 0.108; their smaller later values show the history term’s effect here.

Batch updating instead collects pattern corrections before applying one update. The source permits either the sum or the average:

Δwbatch=∑r=1PΔw(r),Δwavg=1P∑r=1PΔw(r)

Each pattern’s correction in a batch must be computed from the same unchanged pre-update parameter state. Applying one correction immediately and then computing the next is sequential online learning, not this batch calculation. A sum and a mean have different scales unless the learning-rate convention accounts for the factor of P.

Teaching example: fixed-state batch sum and mean

Batch sum and batch mean from a fixed starting point

Givens w=b=0,α=0.1,P=2 Patterns: (1,1) and (2,2); both corrections are evaluated before any update.

Set one shared pre-update state

Teaching example. Use y=wx+b, E=12(t−y)2, initial w=b=0, and α=0.1. For each pattern, calculate the correction at this same initial state. Do not apply the first pattern before calculating the second.

Pattern 1 correction

For (x,t)=(1,1), y=0 and δ=t−y=1. Δw=αδx=0.1·1·1=0.1; the constant-input bias correction is Δb=αδ=0.1. Keep the state at (0,0) while processing the next pattern.

Pattern 2 correction from the same state

For (x,t)=(2,2), still using w=b=0, y=0 and δ=2. Δw=0.1·2·2=0.4, while Δb=0.1·2=0.2. These are the second pattern’s contributions, not sequential-online updates.

Combine and apply once

Sum convention: Δw=0.1+0.4=0.5 and Δb=0.1+0.2=0.3. Mean convention: divide by P=2, so Δw=0.5/2=0.25 and Δb=0.3/2=0.15. Applying either chosen convention once gives the corresponding new parameters. The mean state has half the change in this example; the learning-rate scale must be interpreted with the selected convention.

Delta-bar-delta adapts each weight’s rate

DBD gives each weight its own rate αi(t). It smooths the current raw loss gradient gi(t)=∂E(t)∂wi and adjusts the rate according to whether the previous smoothed gradient and current raw gradient have the same sign:

δ¯i(t)=(1−θ)gi(t)+θδ¯i(t−1),0<θ<1
Δαi(t)={κ,δ¯i(t−1)gi(t)>0−ϕαi(t−1),δ¯i(t−1)gi(t)<00,otherwise,αi(t)=αi(t−1)+Δαi(t)
wi(t+1)=wi(t)−αi(t)gi(t)

Here κ>0 adds a fixed amount after a same-sign comparison. With 0<ϕ<1, an opposite-sign comparison leaves (1−ϕ)αi(t−1). A zero product leaves the rate unchanged. Initialize both the rate and smoothed gradient; with a zero initial smoothed gradient, the first comparison is neutral. The new rate is used for that step’s weight update.

DBD is a per-weight adaptive-rate heuristic, with sensitive parameters and no convergence guarantee on highly non-convex surfaces. The lecture’s suggestion that it “paves the way” for Rprop, RMSprop, and Adam is not established here; the methods should not be treated as equivalent. Jacobs’ original paper describes the adaptive-rate heuristic (Jacobs, 1988).

Teaching example: all three DBD sign cases

Delta-bar-delta: smooth, compare signs, adapt, update

Givens w(0)=0,α(0)=0.1,δ¯(0)=0;θ=0.5,κ=0.02,ϕ=0.25 Chosen teaching gradients: 2, 1, −3. Branch test: barδ(t−1) × g(t).

Step 1: the zero-product case

Teaching example with chosen gradients g(1)=2,g(2)=1,g(3)=−3; initialize w(0)=0, α(0)=0.1, δ¯(0)=0, and choose θ=0.5,κ=0.02,ϕ=0.25. Smooth using δ¯(1)=0.5g(1)+0.5δ¯(0); substituting gives 0.5·2+0.5·0=1. The branch compares the previous smoothed value with the current raw gradient: δ¯(0)g(1)=0·2=0. Therefore Δα(1)=0, α(1)=0.1, and w(1)=0−0.1·2=−0.2.

Step 2: same-sign product increases the rate

First smooth: δ¯(2)=0.5·1+0.5·1=1. Compare lagged smoothed and current raw values: δ¯(1)g(2)=1·1=+1, so Δα(2)=κ=0.02 and the new rate is α(2)=0.12. Use that adapted rate in the weight rule: w(2)=−0.2−0.12·1=−0.32.

Step 3: opposite signs reduce the rate

Smooth: δ¯(3)=0.5·(−3)+0.5·1, which gives −1. The sign test is δ¯(2)g(3)=1·(−3)=−3. Thus Δα(3)=−ϕα(2); substituting gives −0.25·0.12=−0.03, leaving α(3)=0.09. Then w(3)=−0.32+0.27=−0.05. The rate used here is the newly adapted one.

Check the order and what the example shows

The rates are 0.10,0.12,0.09; zero leaves the rate unchanged, a positive lagged-product adds κ, and a negative product removes the fraction ϕ of the old rate. The weight follows w(t+1)=w(t)−α(t)g(t). This deliberately uses raw loss-gradient sign convention; it is not the lecture’s plus-delta backprop convention.

Activation and gain variants

The scaled-and-shifted logistic builds a required output interval [a,b] into the activation. For y=f(x), its derivative can be computed directly from the output:

f(x)=a+(b−a)11+e−x,f′(x)=(y−a)(b−y)b−a

The derivative peaks at (b−a)/4 at the interval midpoint and approaches zero at either bound. The familiar special cases are y(1−y) for [0,1] and (1−y2)/2 for the bipolar interval [−1,1].

Teaching example: check a scaled sigmoid and fixed gain

Scaled interval and fixed-gain sigmoid checks

Givens Scaled sigmoid: [a,b]=[−2,3],x=0; fixed gain comparison: x=0,σ=1or2

Scale and shift the output range

Teaching example: choose target interval [a,b]=[−2,3] and x=0. The logistic value is σ(0)=0.5, so f(0)=a+(b−a)σ(0); substituting gives −2+5·0.5=0.5, inside the required range [−2,3].

Check the derivative from the output

Use f′(x)=((y−a)(b−y))/(b−a). At y=0.5, f′(0)=(2.5·2.5)/5, so f′(0)=1.25. The maximum (b−a)/4=5/4=1.25 occurs at the midpoint (a+b)/2=0.5, so the check matches.

Fixed gain changes steepness

For f(x)=1/(1+e(−σx)), the derivative is f′(x)=σf(x)(1−f(x)). At x=0, f=0.5; with gain σ=2, the slope is 2·0.5·0.5=0.5, versus 0.25 at gain 1. This local factor explains the lecture’s approximate ηwσ2 update scaling argument; it is not a universal network-wide scaling law, especially in saturated regions.

A fixed gain σ>0 changes logistic steepness: f(x)=11+e−σx, with f′(x)=σf(x)(1−f(x)). Large gain sharpens the transition; small gain flattens it toward 0.5. The lecture’s approximate ηwσ2 weight-step scaling follows from a local gain factor in the activation derivative and a gain-scaled delta. It is a local explanation for this sigmoid setup, not a general law for arbitrary networks or saturated units.

The lecture also makes the gain trainable per neuron. For net input zj=∑iwjixi+bj and activation aj=(1+e−σjzj)−1, it defines:

δj=∂E∂ajσjaj(1−aj),∂E∂wji=δjxi,∂E∂σj=zjδjσj
Δwji=−ηwδjxi,Δσj=−ησzjδjσj

These are negative-loss-gradient updates. The source does not list a bias step; using constant input 1 derives Δbj=−ηwδj. Keep σj>0, for example with exponential reparameterization or clipping, because the gain gradient contains 1/σj near zero. The source recommends a smaller gain learning rate; the chain rule supports the update, not a promise of faster convergence.

Two hidden layers add a representation stage

The lecture’s intuition is staged: the first hidden layer partitions input space into regions, the second represents clusters within those regions, and the output classifies when those clusters are separable. A one-hidden-layer approximation theorem is an existence statement under assumptions and sufficient width; it does not promise that training will find the representation or that it will be efficient. For example, Cybenko’s result concerns uniform approximation of continuous functions on the unit hypercube by finite combinations of a continuous sigmoidal function (1989 paper); Hornik, Stinchcombe, and White give their own squashing-function and sufficient-unit conditions (1989 paper).

The source also states a boundary-sample count of order min(n,p)M, but does not define “boundary sample” or give the result’s assumptions or reference. Do not use it as a general theorem.

For first hidden-layer outputs zj, second-layer outputs uh, and output yk, the source’s forward equations are:

zin,j=v0j+∑ixivij,zj=f(zin,j);uin,h=u0h+∑jzjujh,uh=f(uin,h);yin,k=w0k+∑huhwhk,yk=f(yin,k)

The backward equations and updates keep the lecturer’s (tk−yk) delta with additive weight changes:

δk=(tk−yk)f′(yin,k),δh=f′(uin,h)∑kδkwhk,δj=f′(zin,j)∑hδhujh
Δwhk=αδkuh,Δujh=αδhzj,Δvij=αδjxi

Biases appear in all three forward equations, but the PDF omits their corrections. The standard constant-input completion is Δw0k=αδk,Δu0h=αδh,Δv0j=αδj; the worked example labels these derived updates. For each epoch, compute every delta using the same pre-update weights, then apply all parameter changes together.

Epoch 1 forward pass

Common mistakes

  • Momentum carries the last update; batch updating combines corrections from multiple patterns.
  • In a batch, calculate all pattern contributions at fixed pre-update weights. Do not turn them into sequential online steps.
  • DBD tests δ¯i(t−1)gi(t), then updates the rate, then updates the weight with that new rate. A zero product is its own case.
  • DBD uses minus raw loss gradient. The lecture’s backprop uses plus with (t−y). Do not merge their signs.
  • The bipolar sigmoid derivative includes the factor 1/2. The scaled-interval formula is different.
  • A Gaussian RBF derivative here is a vector gradient. Avoid reading it as a scalar slope.
  • The lecture’s universal-approximation sentence needs domain, activation, and width assumptions; representation does not imply easy training.
  • Bias corrections below are constant-input derivations because the lecture leaves them out.

Exam focus

  1. Identify whether a method carries update history (momentum), combines pattern corrections (batch), or changes each weight’s learning rate (DBD).
  2. For DBD, write the smoothing equation, compare the lagged smoothed gradient with the current raw gradient, select positive/negative/zero branch, update αi(t), then apply wi(t+1)=wi(t)−αi(t)gi(t).
  3. From a scaled sigmoid’s output y, use ((y−a)(b−y))/(b−a); at midpoint the slope is (b−a)/4.
  4. In two-hidden-layer backprop, move forward through zj→uh→yk, then backpropagate output-to-hidden-to-first-hidden. Preserve the old weights until all deltas are computed.
  5. Label the sign convention and distinguish lecture-listed updates from derived bias steps.

Practice questions

Why is a momentum term not the same as a batch update?

Check your answer

Momentum carries a fraction of the previous parameter change. Batch updating combines corrections from several patterns, typically calculated at one fixed pre-update state.

A DBD comparison product is zero. What happens to the rate, and which rate is used for the weight update?

Check your answer

The rate change is zero, so it remains at its previous value. The weight uses the resulting current rate αi(t).

In the two-hidden-layer example, why are the epoch-2 deltas recomputed?

Check your answer

All forward activations and downstream weights changed after epoch 1. Epoch 2 must use the new state; reusing old deltas would not be the stated backpropagation procedure.
