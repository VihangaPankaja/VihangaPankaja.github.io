Backpropagation variations and deeper networks

Compare momentum, batch learning, adaptive rates and gain changes by what each one actually changes.

Choose the change before choosing a formula

  • Momentum remembers: part of the previous parameter change is carried into this one.
  • Batch combines: several patterns contribute corrections from one fixed parameter state.
  • Delta-bar-delta adapts: each weight gets its own learning rate based on gradient signs.

These variations build on backpropagation. First identify which part changes: update history, pattern aggregation, per-weight rate, activation or network depth.

Carry update history or combine patterns?

These changes address different parts of learning; momentum and batch updating are not synonyms.
MethodWhat it retains or combinesWhat to calculate from
Online updateOne current patternThe state left by the previous pattern.
MomentumThe previous parameter changeCurrent correction + a fraction of the previous change.
BatchSeveral pattern correctionsOne frozen parameter state for all patterns in the batch.
Delta-bar-deltaA rate and smoothed gradient per weightThe sign comparison, then the newly adapted rate.

Momentum adds a fraction of the previous parameter change to the current correction:

Δwjk(t+1)=αδkzj+μΔwjk(t),Δvij(t+1)=αδjxi+μΔvij(t),0<μ<1

Consistent corrections can build movement; one noisy correction has less influence. Momentum does not guarantee faster convergence.

The printed rule covers weights. A bias follows the same form if treated as a weight on input 1; that is a derived completion.

Teaching example: momentum over three presentations

Momentum: three presentations of one pattern

Givens x=1,t=2,w=b=0,Δw(0)=Δb(0)=0,α=0.1,μ=0.5 Same pre-step values are used for each paired weight and bias update.

Start from a fresh state

Teaching example. Use one linear unit, y=wx+b, the repeated pattern x=1,t=2, and E=12(t−y)2.

Start with w=b=0, previous changes Δw(0)=Δb(0)=0, α=0.1, and μ=0.5.

With this loss, the lecture’s plus-delta signal is δ=t−y. The bias is treated as a weight on constant input 1.

Presentation 1: no history yet

Rule: Δw(t+1)=αδx+μΔw(t), with the same constant-input rule for b.

Here y=0 and δ=2−0=2; so each change is 0.1·2·1+0.5·0=0.2.

The new state is (w,b)=(0.2,0.2), giving y=0.4.

Presentation 2: carry the last change

Recompute first: y=0.2·1+0.2=0.4, δ=2−0.4=1.6.

The current correction is 0.1·1.6·1=0.16 and the carried part is 0.5·0.2=0.10, so Δw=Δb=0.16+0.10=0.26.

Add these simultaneously: (w,b)=(0.46,0.46), so y=0.92. The carried term is the previous update, not another pattern’s correction.

Presentation 3: update and check

Now y=0.46+0.46=0.92 and δ=2−0.92=1.08.

The current correction is 0.1·1.08=0.108, and the carried part is 0.5·0.26=0.13; therefore Δw=Δb=0.108+0.13=0.238. This produces w=b=0.698 and y=1.396.

Without momentum, restart from w=b=0. The three corrections are 0.2, 0.16 and 0.128, ending at w=b=0.488 and y=0.976. The momentum run ends at y=1.396. Each run must use its own changing residual.

Batch updating instead collects pattern corrections before applying one update. The source permits either the sum or the average:

Δwbatch=∑r=1PΔw(r),Δwavg=1P∑r=1PΔw(r)

Freeze the parameters while calculating all batch corrections, then apply their sum or mean. Updating after each pattern is online learning. A sum is P times its mean, so the rate scale must match.

Teaching example: fixed-state batch sum and mean

Batch sum and batch mean from a fixed starting point

Givens w=b=0,α=0.1,P=2 Patterns: (1,1) and (2,2); both corrections are evaluated before any update.

Set one shared pre-update state

Teaching example. Use y=wx+b, E=12(t−y)2, initial w=b=0, and α=0.1. For each pattern, calculate the correction at this same initial state. Do not apply the first pattern before calculating the second.

Pattern 1 correction

For (x,t)=(1,1), y=0 and δ=t−y=1. Δw=αδx=0.1·1·1=0.1; the constant-input bias correction is Δb=αδ=0.1.

Keep the state at (0,0) while processing the next pattern.

Pattern 2 correction from the same state

For (x,t)=(2,2), still using w=b=0, y=0 and δ=2. Δw=0.1·2·2=0.4, while Δb=0.1·2=0.2.

These are the second pattern’s contributions, not sequential-online updates.

Combine and apply once

Sum convention: Δw=0.1+0.4=0.5 and Δb=0.1+0.2=0.3.

Mean convention: divide by P=2, so Δw=0.5/2=0.25 and Δb=0.3/2=0.15. Applying either chosen convention once gives the corresponding new parameters.

The mean state has half the change in this example; the learning-rate scale must be interpreted with the selected convention.

Update choice What contributes to the next step? What stays fixed while calculating?
Momentum Current pattern correction plus a fraction of the last update The previous update is carried forward
Batch Corrections from several patterns, combined by sum or mean Weights stay at the common pre-update values

Delta-bar-delta adapts each weight’s rate

Delta-bar-delta gives each weight a separate learning rate. Compare the previous smoothed gradient with the current raw gradient, then choose a rate change:

δ¯i(t)=(1−θ)gi(t)+θδ¯i(t−1),0<θ<1
Δαi(t)={κ,δ¯i(t−1)gi(t)>0−ϕαi(t−1),δ¯i(t−1)gi(t)<00,otherwise,αi(t)=αi(t−1)+Δαi(t)
wi(t+1)=wi(t)−αi(t)gi(t)

Same sign: add κ. Opposite signs: multiply by 1−ϕ. Zero product: keep the rate. Use this newly chosen rate for the current weight update. A zero initial smoothed gradient makes the first comparison neutral.

Delta-bar-delta is a per-weight heuristic, not a convergence guarantee. It is not interchangeable with Rprop, RMSprop or Adam. Jacobs’ original paper describes the adaptive-rate method.

Teaching example: all three DBD sign cases

Delta-bar-delta: smooth, compare signs, adapt, update

Givens w(0)=0,α(0)=0.1,δ¯(0)=0;θ=0.5,κ=0.02,ϕ=0.25 Chosen teaching gradients: 2, 1, −3. Branch test: barδ(t−1) × g(t).

Step 1: the zero-product case

Teaching example with chosen gradients g(1)=2,g(2)=1,g(3)=−3; initialize w(0)=0, α(0)=0.1, δ¯(0)=0, and choose θ=0.5,κ=0.02,ϕ=0.25.

Smooth using δ¯(1)=0.5g(1)+0.5δ¯(0); substituting gives 0.5·2+0.5·0=1.

The branch compares the previous smoothed value with the current raw gradient: δ¯(0)g(1)=0·2=0.

Therefore Δα(1)=0, α(1)=0.1, and w(1)=0−0.1·2=−0.2.

Step 2: same-sign product increases the rate

First smooth: δ¯(2)=0.5·1+0.5·1=1.

Compare lagged smoothed and current raw values: δ¯(1)g(2)=1·1=+1, so Δα(2)=κ=0.02 and the new rate is α(2)=0.12.

Use that adapted rate in the weight rule: w(2)=−0.2−0.12·1=−0.32.

Step 3: opposite signs reduce the rate

Smooth: δ¯(3)=0.5·(−3)+0.5·1, which gives −1.

The sign test is δ¯(2)g(3)=1·(−3)=−3.

Thus Δα(3)=−ϕα(2); substituting gives −0.25·0.12=−0.03, leaving α(3)=0.09. Then w(3)=−0.32+0.27=−0.05.

The rate used here is the newly adapted one.

Check the order and what the example shows

The rates are 0.10,0.12,0.09; zero leaves the rate unchanged, a positive lagged-product adds κ, and a negative product removes the fraction ϕ of the old rate.

The weight follows w(t+1)=w(t)−α(t)g(t). This deliberately uses raw loss-gradient sign convention; it is not the lecture’s plus-delta backprop convention.

Activation and gain variants

At the same midpoint, doubling gain doubles the weight correction. It does not quadruple it.
At x=1, w=b=0, t=1ActivationWeight correction
Gain σ=1a=0.5ηw/8
Gain σ=2a=0.5ηw/4

The scaled-and-shifted logistic builds a required output interval [a,b] into the activation. For y=f(x), its derivative can be computed directly from the output:

f(x)=a+(b−a)11+e−x,f′(x)=(y−a)(b−y)b−a

The scaled logistic has its largest derivative, (b−a)/4, at the interval midpoint. Its slope tends to zero near either bound. On [0,1] the derivative is y(1−y); on [−1,1] it is (1−y²)/2.

Teaching example: check a scaled sigmoid and fixed gain

Scaled interval and fixed-gain sigmoid checks

Givens Scaled sigmoid: [a,b]=[−2,3],x=0; fixed gain comparison: x=0,σ=1or2

Scale and shift the output range

Teaching example: choose target interval [a,b]=[−2,3] and x=0.

The logistic value is σ(0)=0.5, so f(0)=a+(b−a)σ(0); substituting gives −2+5·0.5=0.5, inside the required range [−2,3].

Check the derivative from the output

Use f′(x)=((y−a)(b−y))/(b−a).

At y=0.5, f′(0)=(2.5·2.5)/5, so f′(0)=1.25.

The maximum (b−a)/4=5/4=1.25 occurs at the midpoint (a+b)/2=0.5, so the check matches.

Fixed gain changes steepness

For f(x)=1/(1+e−σx), the derivative is f′(x)=σf(x)(1−f(x)).

At x=0, f=0.5; with gain σ=2, the slope is 2·0.5·0.5=0.5, versus 0.25 at gain 1.

This local factor explains the lecture’s approximate ηwσ2 update scaling argument; it is not a universal network-wide scaling law, especially in saturated regions.

A fixed gain σ>0 changes logistic steepness: f(x)=11+e−σx, with f′(x)=σf(x)(1−f(x)).

Increasing σ sharpens the sigmoid. The exact weight correction has one explicit gain factor:

Δw = −ηw (∂E/∂a) σ a(1−a)x

The lecture’s σ² statement applies to the effective parameter q=σw with σ fixed, not directly to Δw. Activation and residual changes also affect the step.

The lecture also makes the gain trainable per neuron. For net input zj=∑iwjixi+bj and activation aj=(1+e−σjzj)−1, it defines:

δj=∂E∂ajσjaj(1−aj),∂E∂wji=δjxi,∂E∂σj=zjδjσj
Δwji=−ηwδjxi,Δσj=−ησzjδjσj

These are negative-loss-gradient updates. The source does not list a bias step; using constant input 1 derives Δbj=−ηwδj.

Keep the gain σⱼ positive. The source recommends a smaller gain learning rate. Its derivative contains 1/σⱼ, so the printed form needs care near zero.

Two hidden layers add a representation stage

The lecture’s intuition is staged: the first hidden layer partitions input space into regions, the second represents clusters within those regions, and the output classifies when those clusters are separable.

A one-hidden-layer approximation theorem is an existence statement under assumptions and sufficient width; it does not promise that training will find the representation or that it will be efficient.

For example, Cybenko’s result concerns uniform approximation of continuous functions on the unit hypercube by finite combinations of a continuous sigmoidal function (1989 paper); Hornik, Stinchcombe, and White give their own squashing-function and sufficient-unit conditions (1989 paper).

The source also states a boundary-sample count of order min(n,p)M, but does not define “boundary sample” or give the result’s assumptions or reference. Do not use it as a general theorem.

The forward pass now has two hidden activation stages, zⱼ and uₕ, before output yₖ:

zin,j=v0j+∑ixivij,zj=f(zin,j);uin,h=u0h+∑jzjujh,uh=f(uin,h);yin,k=w0k+∑huhwhk,yk=f(yin,k)

Send deltas backward through both hidden layers. Keep the target-minus-output convention and add the corresponding weight changes:

δk=(tk−yk)f′(yin,k),δh=f′(uin,h)∑kδkwhk,δj=f′(zin,j)∑hδhujh
Δwhk=αδkuh,Δujh=αδhzj,Δvij=αδjxi

The source omits bias corrections. Treating biases as weights on input 1 gives Δw₀ₖ=αδₖ, Δu₀ₕ=αδₕ and Δv₀ⱼ=αδⱼ. The trace labels these derived steps. Calculate every delta with old weights before updating.

Common mistakes

  • Momentum carries the last update; batch updating combines corrections from multiple patterns.
  • In a batch, calculate all pattern contributions at fixed pre-update weights. Do not turn them into sequential online steps.
  • DBD tests δ¯i(t−1)gi(t), then updates the rate, then updates the weight with that new rate. A zero product is its own case.
  • DBD uses minus raw loss gradient. The lecture’s backprop uses plus with (t−y). Do not merge their signs.
  • The bipolar sigmoid derivative includes the factor 1/2. The scaled-interval formula is different.
  • A Gaussian RBF derivative here is a vector gradient. Avoid reading it as a scalar slope.
  • The lecture’s universal-approximation sentence needs domain, activation, and width assumptions; representation does not imply easy training.
  • Bias corrections below are constant-input derivations because the lecture leaves them out.

Practice questions

Why is a momentum term not the same as a batch update?

Check your answer

Momentum carries a fraction of the previous parameter change. Batch updating combines corrections from several patterns, typically calculated at one fixed pre-update state.

A DBD comparison product is zero. What happens to the rate, and which rate is used for the weight update?

Check your answer

The rate change is zero, so it remains at its previous value. The weight uses the resulting current rate αi(t).

In the two-hidden-layer example, why are the epoch-2 deltas recomputed?

Check your answer

All forward activations and downstream weights changed after epoch 1. Epoch 2 must use the new state; reusing old deltas would not be the stated backpropagation procedure.
