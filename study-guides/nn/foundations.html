Neurons, activations and network foundations

Big picture

A neural network turns input signals into an output through connected neurons. Each connection scales a signal with a weight; each neuron adds its weighted signals and bias, then applies an activation function (also called a transfer function here). During learning, a training algorithm changes the weights and biases so the outputs better match the task. This page builds that foundation before the later pages work through particular learning rules.

A neuron turns signals into an output

Think of a neuron as a small calculator. Each input contributes according to its weight: a positive weight reinforces that input’s effect, a negative weight reverses its direction, and a weight near zero contributes little. The neuron first forms its net input and only then turns it into an output with an activation.

yin=∑i=1nwixi
yin=b+∑i=1nwixi,y=f(yin)=f(𝐰T𝐱+b)

The bias b is an adjustable offset. It can also be viewed as a constant input of 1 with its own weight. In a layer, each neuron can have its own weights and bias. Under this page’s additive-bias convention, the net input is weighted sum plus b; the sign of a threshold symbol depends on how that alternate formula is written.

The notation table uses xi for a unit’s input activation, yj for a unit’s output activation, wij for the directed weight from unit i to unit j, and W for a weight matrix. In the single-neuron examples, xi and wi are the corresponding scalar inputs and weights. The lecture also uses α for learning rate, θ for threshold, s for an input training vector, t for a target output vector, b for bias, and f for activation.

Source example — weighted sum −2.5 and step output 0

Compute one neuron output

Inputs: x1=1,x2=2,x3=−1
Weights: w1=0.5,w2=−1,w3=2
Bias: b=1
Activation: y=1 when yin≥0; otherwise y=0
The givens stay visible while the net input and decision are worked out.

1. Form each weighted contribution

Rule: multiply each input by its corresponding weight. Substitute: w1x1=(0.5)(1)=0.5, w2x2=(−1)(2)=−2, and w3x3=(2)(−1)=−2. Intermediate state: the three contributions are 0.5,−2,−2; next, add them and the given bias.

2. Add the weighted contributions and bias

Rule: yin=b+∑i=13wixi. Substitute: yin=1+0.5−2−2=−2.5. Intermediate state: net input yin=−2.5; next, apply the selected step activation.

3. Compare with the step boundary

Rule: the lecture step gives 1 when yin≥0 and 0 when yin<0. Substitute: −2.5<0. The condition for output 1 is false, so the output is 0.

4. Read the result and check it

Result: y=0. Independent check: the weighted part is 0.5−2−2=−3.5; adding b=1 gives −2.5, still below the inclusive zero boundary. This is a forward calculation; Lesson 1 gives no training update rule or epoch values.

What the bias changes

For the lecture’s sigmoid example, the full argument is x+b. A sigmoid reaches its midpoint when that argument is zero, so the midpoint is at x=−b. This is why a positive additive bias shifts the curve left and a negative one shifts it right.

Source example — sigmoid bias midpoints 0, −2 and +2

Track the sigmoid midpoint as bias changes

Neuron convention: y=f(x+b)
Sigmoid: f(u)=1/(1+e−u)
Midpoint condition: y=0.5 occurs when the sigmoid argument u=0
Cases: b=0,b=2,b=−2.

1. No bias: midpoint at 0

Rule: y=f(x+b) and a sigmoid has midpoint f(0)=0.5. Substitute: b=0, so y=1/(1+e−x); set its argument to zero: x=0. The curve midpoint is 0; next add a positive bias.

2. Positive bias: midpoint at −2

Rule: substitute the bias into the complete sigmoid argument. Substitute: b=2 gives y=1/(1+e−(x+2)); set the argument to zero, x+2=0, hence x=−2. The midpoint moves two units left; next use a negative bias.

3. Negative bias: midpoint at +2

Rule: substitute the bias into the complete sigmoid argument. Substitute: b=−2 gives y=1/(1+e−(x−2)); set the argument to zero, x−2=0, hence x=2. The midpoint moves two units right.

4. Check the three cases

Result: for b=0,2,−2, the midpoints are x=0,−2,2. Independent check: every case satisfies x+b=0; at that point the sigmoid is 1/(1+e0)=0.5. The full argument x+b determines the shift.

From one neuron to a network

Architecture is the arrangement of neurons into layers and the pattern of their connections. The input layer receives data, hidden layers process it into intermediate features, and the output layer produces the prediction or decision. The lecture’s Figure 2 and Figure 3 are separate illustrations with different hidden-layer sizes: one has three hidden units; the other has four and shows bias terms at both hidden and output layers.

With one trainable weight layer directly from input to output and no hidden layer, the source describes the network as suitable for simple linearly separable problems in the introductory threshold-classifier setting. A multilayer network can build intermediate representations and model nonlinear decision boundaries. Approximation results are conditional: for example, Cybenko’s result concerns continuous functions on a compact domain and a single hidden layer with a continuous sigmoidal nonlinearity and sufficient units; it is an existence result, not a guarantee that training finds useful parameters (primary paper, 1989).

A hidden layer adds expressive power when nonlinear activations are used. If every layer applies only a linear transformation, stacking those layers still produces one linear transformation; depth alone does not create a nonlinear relationship.

Activations shape the response

An activation maps the net input to the neuron’s output. It can gate a response, constrain its range, and—when nonlinear—let a network represent nonlinear relationships. The lecture calls these “transfer functions” in its MATLAB table. The exact boundary cases matter: the two hard-limit functions return their nonnegative-side value at zero, and the saturating linear functions include their endpoints in the middle interval.

Saturating linear (satlin) 0 if n<0; a=n if 0≤n≤1; 1 if n>1 Middle interval includes 0 and 1
Symmetric saturating linear (satlins) −1 if n<−1; a=n if −1≤n≤1; 1 if n>1 Middle interval includes −1 and 1

A sigmoid output lies between 0 and 1, so it is on a probability scale; calibration is a separate property that must be checked. Modern neural networks can be poorly calibrated, and temperature scaling is one studied post-training correction (Guo et al., 2017). Also, the step function is not differentiable at zero and has zero derivative away from zero, so Lesson 1’s list should not be read as saying that an ordinary gradient backpropagation procedure can directly train every listed activation.

Learning overview

Learning changes weights (and, where used, biases) to improve the network’s responses. In supervised learning, examples come with target outputs; in unsupervised learning, only inputs are given and the model seeks structure such as groupings or patterns. The lecture’s high-level supervised workflow is:

  1. Propagate an input forward and produce a prediction.
  2. Compare the prediction with its target using a loss function.
  3. Use backpropagation and the chain rule to calculate how the loss depends on parameters.
  4. Use an optimizer such as gradient descent to update the weights and biases.
  5. Repeat over training examples.

Backpropagation calculates parameter gradients; gradient descent uses those gradients for an update. They are related stages, not two names for the same operation.

Lesson 1 introduces the learning rate α qualitatively: too large a value may make learning unstable, while too small a value may make it slow. It does not supply an update equation, numeric rate, initialized parameters, or training example. The following pages develop those procedures from the course material: threshold logic and perceptron learning, ADALINE, LMS, and MADALINE, and backpropagation.

Threshold and bias use different conventions

The threshold θ describes the level at which a neuron becomes active. To compare it with the additive-bias form, state the net-input convention. Supplemental explanation: with threshold net input 𝐰T𝐱−θ, the same quantity can be written 𝐰T𝐱+b by setting b=−θ. The symbol changes sign because the two formulas place the parameter differently. The lecture does not give this conversion formula, so keep the chosen convention visible in any calculation.

Strengths, limits, and model families

Neural networks learn from examples, model complex relationships, support pattern recognition and prediction, and can learn useful feature combinations. They may generalize beyond training examples, though generalization is not guaranteed. Their limits include data and computation needs, hard-to-interpret internal decisions, sensitivity to architecture and training choices, and overfitting when model complexity is high relative to the data.

The lecture names CNNs for image-related tasks, RNNs for sequential or time-dependent data, and Transformers for language and sequence processing. It also lists computer vision and medical imaging, speech recognition, language tasks, forecasting, recommendations, anomaly and fraud detection, fault diagnosis, and document classification. These are an overview here; their internal algorithms are outside Lesson 1.

Common mistakes

  • Confusing net input with output: yin is the weighted sum plus bias; y is the result after applying f.
  • Reversing the bias shift: for f(x+b), positive b moves the curve left because the midpoint solves x+b=0.
  • Counting the input layer as trainable: “single-layer” here refers to one trainable weight layer from input to output.
  • Treating a forward pass as training: a forward pass computes a response; training also compares it with a target and updates parameters.
  • Treating backpropagation as the optimizer: backpropagation supplies gradients; gradient descent uses them to update parameters.
  • Assuming every method is supervised: unsupervised learning has inputs without target outputs.
  • Assuming a 0–1 sigmoid output is automatically calibrated: the range alone does not establish calibration; assess it for the trained model.
  • Assuming a step activation is differentiable: its zero boundary needs special treatment and its ordinary derivative is zero elsewhere.

Exam focus

  • State the three network characteristics: architecture, learning algorithm (training algorithm), and activation function.
  • Compute yin=b+∑iwixi, then apply the named activation with its exact boundary rule.
  • For f(x+b), solve x+b=0 to find the sigmoid midpoint; positive b shifts left and negative b shifts right.
  • Distinguish supervised targets from unsupervised structure discovery.
  • Separate the forward pass, loss calculation, backpropagation gradients, and optimizer update.
  • Remember that hidden layers gain nonlinear expressive power through nonlinear activations; stacking linear layers alone remains linear.

Practice questions

A neuron has inputs 𝐱=(1,2,−1), weights 𝐰=(0.5,−1,2), and bias b=1. What is its net input and step output?

Check your answer

The net input is 1+0.5−2−2=−2.5. Since −2.5<0, the lecture’s step rule returns 0.

What output does hardlim return when its net input is exactly zero? What does hardlims return?

Check your answer

At zero, hardlim returns 1 and hardlims returns +1; both use the nonnegative branch.

For a neuron using the lecture convention y=f(x+b) with b=2, where is the sigmoid midpoint and in which direction is the curve shifted?

Check your answer

The midpoint solves x+2=0, so x=−2. The positive bias shifts the curve two units left.

In the lecture’s training overview, what does backpropagation do, and what does gradient descent do?

Check your answer

Backpropagation applies the chain rule to calculate loss gradients for parameters. Gradient descent uses those gradients to update parameters.
