Threshold logic and perceptron learning

How fixed thresholds implement logic, and how a perceptron learns a linear decision boundary.

Big picture

A threshold neuron turns a weighted input total into a class decision. The McCulloch–Pitts (M–P) model shows how fixed thresholds and inhibitory connections implement logic. A perceptron adds adjustable weights and a bias, so it can learn a linear decision boundary from examples. Lesson 2 moves from fixed logic to a trainable binary classifier; its final AND training example changes to bipolar labels, so that second convention is kept distinct below.

From fixed M–P logic to a trainable perceptron

An M–P unit receives binary inputs through directed connections; in the model, a signal takes one time step to cross one connection. Excitatory inputs into a unit have a common positive weight w; an inhibitory input has weight −p, with p>0. It fires when the net input reaches threshold θ, so equality fires. Its weights and threshold are fixed: it implements a chosen rule but does not learn it.

f(yin)={1,yin≥θ0,yin<θ

If k equally weighted excitatory inputs are the minimum needed to fire, the threshold must include the k-input total but exceed the (k−1)-input total:

kw≥θ>(k−1)w

For the source’s absolute-inhibition condition, assume n unit-valued excitatory inputs of weight w and one active inhibitory input of weight −p. Even with all excitation active, that inhibited total must remain below threshold:

θ>nw−p

Thus in M–P ANDNOT, x1 contributes excitation and x2 blocks firing whenever x2=1. It is not a learned negative correction.

For two binary inputs in row order 00, 01, 10, 11, the lecture’s M–P AND gives 0,0,0,1 with w=1 and θ=2; OR gives 0,1,1,1 with w=1 and θ=1. Its ANDNOT expression is x1 AND NOT x2, with x1 excitatory, x2 inhibitory, and θ=1; the outputs are 0,0,1,0. This preserves the complement on x2.

Perceptron: weighted sum, bias, and binary decision

The perceptron keeps threshold logic but learns adjustable weights. Each input xᵢ is scaled by wi, the terms are added, and bias b shifts the boundary. Under the source convention, the bias is added:

yin=∑i=1nwixi+b
y={1,yin≥00,yin<0

For this binary activation, a net input of exactly zero is class 1. This is equivalent to an M–P threshold θ=−b. In two dimensions the boundary is the set where the net input is zero; one side is class 1 and the other class 0.

w1x1+w2x2+b=0

Using the lecture’s binary inputs (00, 01, 10, 11), perceptron AND has w=(1,1), b=−1.5 and outputs 0,0,0,1; OR has w=(1,1), b=−0.5 and outputs 0,1,1,1. NOT uses w=−1, b=0.5 and outputs 1 for x=0 and 0 for x=1.

Binary perceptron update

With binary target t and actual output y, a correct pattern has t−y=0 and changes nothing. On a mistake, the source updates each weight and the bias by the same signed output error (the input xᵢ scales only its weight update):

winew=wiold+η(t−y)xi
bnew=bold+η(t−y)

Here η is the learning rate. Each new state is used for the next pattern. The short Teaching example expands the substitution once; the longer source training trace below uses a different, bipolar rule.

Teaching example: one binary perceptron correction

This is a Teaching example to make the binary update concrete; it is separate from the lecture’s bipolar AND trace. Start with input (x1,x2)=(1,0), target t=0, weights (w1,w2)=(0.4,−0.2), bias b=−0.1, and learning rate η=0.5.

The net input is 0.4(1)+(−0.2)(0)−0.1=0.3, so the binary activation gives y=1 because 0.3≥0. This is a mistake: t−y=0−1=−1.

Apply the binary formulas:

  • w1(new)=0.4+0.5(−1)(1)=−0.1
  • w2(new)=−0.2+0.5(−1)(0)=−0.2
  • b(new)=−0.1+0.5(−1)=−0.6

Recheck the same pattern: (−0.1)(1)+(−0.2)(0)−0.6=−0.7<0, hence y=0=t. The correction moves this example to the requested class.

Bipolar training is a separate convention

The lecture’s worked AND training problem uses inputs and targets in {−1,+1}. Its output is +1 only when yin>0; at yin=0 the output is −1. It updates only a misclassified pattern, using wi(new)=wi(old)+ηtxᵢ and b(new)=b(old)+ηt. These are the exact rules used in the full trace, with η=1. They are not the binary η(t−y) rule above.

Epoch 1 · pattern 1: (−1,−1), target −1

State before: (w1,w2,b)=(0,0,0). Substitute: yin=0(−1)+0(−1)+0=0. Bipolar rule: output −1 when yin≤0, so y=−1. It matches t=−1; make no update and keep (0,0,0). Next, process (−1,+1) with the same state.

State before: (0,0,0). yin=0(−1)+0(+1)+0=0, so the bipolar output is −1 because zero belongs to −1. Correct; no update. State remains (0,0,0). Next, process (+1,−1).

Epoch 1 · pattern 3: (+1,−1), target −1

State before: (0,0,0). yin=0(+1)+0(−1)+0=0, hence y=−1. Correct; no update. State remains (0,0,0). Next, process the positive pattern (+1,+1).

Epoch 1 · pattern 4: (+1,+1), target +1

State before: (0,0,0). yin=0(+1)+0(+1)+0=0, hence y=−1. This is a mistake. Use the source’s mistake-only bipolar rule wi(new)=wi(old)+ηtxᵢ and b(new)=b(old)+ηt, with η=1 and t=+1:

  • w1=0+1(+1)(+1)=1
  • w2=0+1(+1)(+1)=1
  • b=0+1(+1)=1

End of epoch state: (1,1,1). The next epoch starts at the first input, using this updated state.

Epoch 2 · pattern 1: (−1,−1), target −1

State before: (1,1,1). yin=1(−1)+1(−1)+1=−1, so y=−1. Correct; no update. Keep (1,1,1). Next, process (−1,+1).

Epoch 2 · pattern 2: (−1,+1), target −1

State before: (1,1,1). yin=1(−1)+1(+1)+1=1, so y=+1. This is a mistake. Apply η=1, t=−1:

  • w1=1+1(−1)(−1)=2
  • w2=1+1(−1)(+1)=0
  • b=1+1(−1)=0

New state: (2,0,0). Use it immediately on the next pattern in this same epoch.

Epoch 2 · pattern 3: (+1,−1), target −1

State before: (2,0,0). yin=2(+1)+0(−1)+0=2, so y=+1. This is a mistake. Apply η=1, t=−1:

  • w1=2+1(−1)(+1)=1
  • w2=0+1(−1)(−1)=1

New state: (1,1,−1). The final pattern in this epoch uses this state.

Epoch 2 · pattern 4: (+1,+1), target +1

State before: (1,1,−1). yin=1(+1)+1(+1)−1=1, so y=+1. Correct; no update. Epoch 2 ends at (1,1,−1). Now make a full convergence pass over all four patterns in source order.

Epoch 3 · convergence check 1: (−1,−1), target −1

Fixed state: (1,1,−1). Substitute: yin=1(−1)+1(−1)−1=−3, so y=−1. Correct; no update. Keep (1,1,−1) and continue the full check with (−1,+1).

Epoch 3 · convergence check 2: (−1,+1), target −1

Fixed state: (1,1,−1). yin=1(−1)+1(+1)−1=−1, so y=−1. Correct; no update. Keep the state and continue with (+1,−1).

Epoch 3 · convergence check 3: (+1,−1), target −1

Fixed state: (1,1,−1). yin=1(+1)+1(−1)−1=−1, so y=−1. Correct; no update. Keep the state and check the final positive pattern.

Epoch 3 · convergence check 4: (+1,+1), target +1

Fixed state: (1,1,−1). yin=1(+1)+1(+1)−1=1, so y=+1. Correct; no update. All four predictions are (−1,−1,−1,+1), exactly the target sequence. Thus the full epoch is a no-update convergence check and the final parameters remain (w1,w2,b)=(1,1,−1). Independent boundary check: yin=0 gives x1+x2=1; the four bipolar corners have net values −3, −1, −1, +1, so only (+1,+1) receives +1.

Learned boundary and linear separability

After the three-epoch trace, (w1,w2,b)=(1,1,−1), so yin=x1+x2−1. Setting it to zero gives x1+x2=1. The source’s plotted coordinates are bipolar: x1 and x2 each range over −1 and +1. At the four corners the net inputs are −3, −1, −1, and +1, so only (+1,+1) is class +1. Points on the line would be class −1 under this bipolar activation.

A single perceptron can separate classes only when one line (2-D), plane (3-D), or hyperplane (higher dimensions) divides them: the classes are then linearly separable. AND, OR, and NAND are linearly separable. XOR has positive outputs at (0,1) and (1,0), with negative outputs at (0,0) and (1,1); its alternating corners cannot be separated by one line. This single-layer limitation motivates multilayer networks.

Applications and what the models contribute

The lecture presents these as illustrations of weighted decisions. For email spam, let x1 indicate suspicious words, x2 many links, and x3 an unknown sender; each is 1 when present and 0 otherwise. With weights 0.8, 0.6, 0.7 and b=−1.0, the supplied case (1,1,1) gives yin=0.8+0.6+0.7−1.0=1.1>0, so it is class 1 (spam). This one example does not establish a trained or validated spam filter.

For the three-signal threshold alarm (high temperature, low oxygen, abnormal heart rate), each input has excitatory weight 1 and θ=2. It fires for at least two active signals:

y={1,x1+x2+x3≥20,otherwise

This is a threshold-logic example, not a clinical rule. M–P neurons and simple perceptrons remain useful for understanding logic, weights, bias, activation, and boundaries—the ideas later network models build on.

Common mistakes

  • Dropping the NOT from ANDNOT: x2 is inhibitory, so (1,1) must output 0.
  • Changing the equality case: binary output gives y=1 at yin=0; the bipolar training rule gives y=−1 there.
  • Mixing output codes: binary {0,1} uses η(t−y); the source’s bipolar {−1,+1} trace uses mistake-only ηt updates.
  • Updating a correct pattern or postponing an update: a mistake changes the state immediately, including for the next pattern in the same epoch.
  • Calling XOR linearly separable, or mistaking the source plot’s ±1 coordinates for binary 0/1 values.
  • Reading the boundary as a region: the line itself has yin=0; the activation rule decides its class.

Exam focus

  • M–P: fixed weights; fires when yin≥θ; active inhibition is absolute.
  • Minimum of k excitatory inputs: kw≥θ>(k−1)w. For the stated one-inhibitor setup, absolute inhibition requires θ>nw−p.
  • Perceptron net: yin=Σwixᵢ+b; binary zero goes to 1; threshold equivalent is θ=−b.
  • Binary update: wi←wi+η(t−y)xᵢ and b←b+η(t−y).
  • Source bipolar rule: +1 iff yin>0; mistake-only wi←wi+ηtxᵢ and b←b+ηt.
  • Boundary: w1x1+w2x2+b=0. One perceptron cannot implement XOR.
