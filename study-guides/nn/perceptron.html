Threshold logic and perceptron learning

A mistake moves the boundary

  • M–P unit: fixed weights and threshold implement a chosen logic gate.
  • Perceptron: weights and bias change when a training example is misclassified.
  • Two course rules: binary uses η(t−y); the bipolar AND trace uses ηt on mistakes. They also treat zero differently.

An M–P unit has fixed weights and threshold. It fires when net input ≥ θ, including equality.

  • Inputs are binary; each excitatory link has weight w>0.
  • An inhibitory link has weight −p.
  • A signal takes one time step per connection in this model.
f(yin)={1,yin≥θ0,yin<θ

If k equally weighted excitatory inputs are the minimum needed to fire, the threshold must include the k-input total but exceed the (k−1)-input total:

kw≥θ>(k−1)w

For the source’s absolute-inhibition condition, assume n unit-valued excitatory inputs of weight w and one active inhibitory input of weight −p. Even with all excitation active, that inhibited total must remain below threshold:

θ>nw−p

Thus in M–P ANDNOT, x1 contributes excitation and x2 blocks firing whenever x2=1. It is not a learned negative correction.

Use row order 00, 01, 10, 11 for all three gates below.

Perceptron: weighted sum, bias, and binary decision

A perceptron learns its weights and additive bias. Compute the weighted sum plus b, then apply the binary threshold:

yin=∑i=1nwixi+b
y={1,yin≥00,yin<0

Binary zero case: net input 0 gives class 1. The line wᵀx+b=0 is the decision boundary; b=−θ converts from the subtracted-threshold form.

w1x1+w2x2+b=0

Binary AND uses w=(1,1), b=−1.5; OR uses w=(1,1), b=−0.5. NOT uses w=−1, b=0.5. Verify each by substituting the binary inputs.

Binary perceptron update

Binary error is t−y. A correct classification gives zero and changes nothing. On a mistake, the input scales its weight correction; the bias correction has no input multiplier:

winew=wiold+η(t−y)xi
bnew=bold+η(t−y)

Use the updated state for the next pattern. The full AND trace below switches to the lecture’s bipolar convention.

Teaching example: one binary perceptron correction

This is a Teaching example to make the binary update concrete; it is separate from the lecture’s bipolar AND trace. Start with input (x1,x2)=(1,0), target t=0, weights (w1,w2)=(0.4,−0.2), bias b=−0.1, and learning rate η=0.5.

The net input is 0.4(1)+(−0.2)(0)−0.1=0.3, so the binary activation gives y=1 because 0.3≥0. This is a mistake: t−y=0−1=−1.

Apply the binary formulas:

  • w1(new)=0.4+0.5(−1)(1)=−0.1
  • w2(new)=−0.2+0.5(−1)(0)=−0.2
  • b(new)=−0.1+0.5(−1)=−0.6

Recheck the same pattern: (−0.1)(1)+(−0.2)(0)−0.6=−0.7<0, hence y=0=t. The correction moves this example to the requested class.

Bipolar training is a separate convention

The AND trace uses bipolar inputs and targets {−1,+1}, with η=1. Its zero case gives −1.

  • Output +1 only when net input > 0.
  • On a mistake: wᵢ ← wᵢ + ηtxᵢ and b ← b + ηt.
  • On a correct pattern: leave the state unchanged.

Keep this rule separate from binary η(t−y).

Epoch 3 · convergence check 1: (−1,−1), target −1

Fixed state: (1,1,−1). Substitute: yin=1(−1)+1(−1)−1=−3, so y=−1. Correct; no update. Keep (1,1,−1) and continue the full check with (−1,+1).

Epoch 3 · convergence check 2: (−1,+1), target −1

Fixed state: (1,1,−1). yin=1(−1)+1(+1)−1=−1, so y=−1. Correct; no update. Keep the state and continue with (+1,−1).

Epoch 3 · convergence check 3: (+1,−1), target −1

Fixed state: (1,1,−1). yin=1(+1)+1(−1)−1=−1, so y=−1. Correct; no update. Keep the state and check the final positive pattern.

Epoch 3 · convergence check 4: (+1,+1), target +1

Fixed state: (1,1,−1). yin=1(+1)+1(+1)−1=1, so y=+1. Correct; no update. All four predictions are (−1,−1,−1,+1), exactly the target sequence. Thus the full epoch is a no-update convergence check and the final parameters remain (w1,w2,b)=(1,1,−1).

Independent boundary check: yin=0 gives x1+x2=1; the four bipolar corners have net values −3, −1, −1, +1, so only (+1,+1) receives +1.

Learned boundary and linear separability

The trace finishes at (w₁,w₂,b)=(1,1,−1). Its boundary is x₁+x₂=1. For bipolar corners (−1,−1), (−1,+1), (+1,−1), (+1,+1), the nets are −3, −1, −1, +1. Only (+1,+1) is positive.

A single perceptron needs a line, plane or hyperplane that separates the classes. AND, OR and NAND meet this condition. XOR alternates labels around the four corners, so no single line separates it.

Applications and what the models contribute

Spam illustration: x₁=suspicious words, x₂=many links, x₃=unknown sender. Each input is 0 or 1.

With weights 0.8, 0.6, 0.7 and b=−1.0, the supplied case (1,1,1) gives yin=0.8+0.6+0.7−1.0=1.1>0, so it is class 1 (spam). This one example does not establish a trained or validated spam filter.

For the three-signal threshold alarm (high temperature, low oxygen, abnormal heart rate), each input has excitatory weight 1 and θ=2. It fires for at least two active signals:

y={1,x1+x2+x3≥20,otherwise

The alarm is a threshold-logic illustration, not a clinical rule. The useful ideas are weighted inputs, a threshold and an output decision.

Common mistakes

  • Dropping the NOT from ANDNOT: x2 is inhibitory, so (1,1) must output 0.
  • Changing the equality case: binary output gives y=1 at yin=0; the bipolar training rule gives y=−1 there.
  • Mixing output codes: binary {0,1} uses η(t−y); the source’s bipolar {−1,+1} trace uses mistake-only ηt updates.
  • Updating a correct pattern or postponing an update: a mistake changes the state immediately, including for the next pattern in the same epoch.
  • Calling XOR linearly separable, or mistaking the source plot’s ±1 coordinates for binary 0/1 values.
  • Reading the boundary as a region: the line itself has yin=0; the activation rule decides its class.
