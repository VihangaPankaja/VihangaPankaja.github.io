ADALINE and MADALINE learning

How ADALINE learns from linear error and how early MADALINE rules choose hidden-unit updates.

Big picture

ADALINE shows why the value used to learn a classifier can differ from the value used to report its class. It computes a continuous weighted sum, measures the target’s distance from that linear response, and nudges weights and bias to reduce squared error. A threshold may still turn the final response into a class, but that threshold is outside the ADALINE training error. MADALINE combines thresholded ADALINE units so the overall decision can be nonlinear; MR-I and MR-II are early ways to decide which hidden units to adjust.

ADALINE (Adaptive Linear Neuron) is associated with Bernard Widrow and Ted Hoff. MADALINE means Many ADALINE. The key thread through this lesson is the changing training state: first a linear error corrects one neuron, then hidden-unit rules handle the credit-assignment problem in a small network.

ADALINE learns before thresholding

For input features x and corresponding weights w, the net input adds the bias b to the weighted sum. The training activation is linear, so the response used to calculate error is the net input itself. A separate quantizer may then produce a bipolar class label.

z=∑i=1nwixi+b,y=f(z)=z,e=t−y

This ordering is the main distinction from perceptron learning. The perceptron compares a hard-threshold output with its target. ADALINE compares its unthresholded real-valued response with the target, so even a correctly classified sample can still produce a nonzero training error.

Half-squared error and the delta update

The lesson defines the single-pattern loss with a factor of one half. For a training set, it sums that half-squared error across patterns. The factor one half cancels the 2 produced by differentiating a square, leaving the additive update below. Keep the sign convention target minus linear output throughout.

E=12(t−y)2,Etotal=12∑p(t(p)−y(p))2
Δwi=η(t−y)xi=ηexi,Δb=η(t−y)=ηe

At each presentation: compute z and y, find e, then add ηex to the weights and ηe to the bias. Repeat over the examples and passes until the total error is acceptably small. Initialize with small random values or zeros, as the lesson allows. The next viewer starts from zero so every update can be checked directly.

The dataset error falls across these two passes; individual online errors need not decrease after every single presentation.

Choosing the learning rate

The learning rate η controls the size of each correction. A rate that is too large can overshoot, oscillate, or diverge; a rate that is too small makes progress slow. The lesson relates a theoretical mean-stability bound to the largest eigenvalue of the input correlation matrix

R=1P∑p=1Px(p)(x(p))T,0<η<2λmax(R)

The displayed bound matches the update without a factor of 2, w←w+ηex. When a text places that factor of 2 in the gradient update, the stated bound is 0<η<1λmax. These constants must stay paired with their update convention. They describe the lesson’s stability guidance; they do not promise that every individual online sample error falls monotonically.

Since computing R and its eigenvalues may be inconvenient, the lesson also gives practical guidance: begin small (for example η=0.1 or less) and reduce η if training error becomes unstable. For a single neuron with n inputs, it gives the heuristic 0.1≤nη≤1. For the source’s n=100 input-pixel example:

0.1100≤η≤1100⟹0.001≤η≤0.01

Thus η=0.005 is one suggested value inside the interval. This is a practical heuristic, not a theorem. The separate “start small” suggestion and the n-scaled interval answer different questions and should not be conflated.

What one ADALINE can and cannot represent

Adjustable weights and bias let one ADALINE learn a linear decision boundary by directly minimizing a squared-error objective. Its simple update also makes the model useful for understanding adaptive systems and signal processing. But thresholding the output does not bend the boundary: one ADALINE remains a single-layer linear classifier and cannot directly solve a nonlinearly separable problem such as XOR.

MADALINE adds hidden decisions

A MADALINE combines multiple ADALINE units. In the Lesson 3 example, two hidden units each compute a weighted sum and pass it through a bipolar threshold, then an output unit combines their signals. Several hidden linear boundaries can therefore form a nonlinear overall decision. That extra representational power makes hidden-layer training harder: when the output is wrong, the algorithm must choose which hidden unit to change.

For the course’s MR-I example, every unit uses the inclusive bipolar threshold:

f(u)={+1,u≥0−1,u<0

The output unit is fixed as a bipolar OR combiner with v1=v2=by=12. Its net is yin=by+z1v1+z2v2, followed by the same threshold. Only when both hidden outputs are −1 is yin=−12 and the network returns −1; any +1 hidden output makes yin ≥ ½ and the result +1.

MR-I: change hidden units under a fixed OR output

MR-I leaves the output-unit weights fixed and changes only weights and biases feeding hidden ADALINEs. If the output already matches the target, it makes no update. When the target is +1 but the output is −1, it chooses the hidden net closest to zero, because that unit is the easiest to push across the threshold. It moves that unit’s linear net toward +1 using the delta-style residual 1−zin,j.

bjnew=bjold+α(1−zin,j),wijnew=wijold+α(1−zin,j)xi

When the target is −1 but the output is +1, MR-I adjusts all hidden units that currently output +1, moving each linear net toward −1:

bjnew=bjold+α(−1−zin,j),wijnew=wijold+α(−1−zin,j)xi

The lesson’s negative-target step says “positive” nets, but its activation rule assigns +1 to every net at or above zero. To keep the rule consistent, update every hidden unit currently outputting +1, including a unit exactly at zero. The second example makes this boundary case explicit.

Teaching example — added values: x=(1,1), target t=+1, α=0.1. Start Z₁ with (w11,w21,b1)=(0.2,0,−0.3) and Z₂ with (w12,w22,b2)=(0,0.1,−0.5). Rule: zin1=b1+x1w11+x2w21,zin2=b2+x1w12+x2w22. 2. Select the hidden unit closest to zero

Rule: for t=+1, MR-I updates only the hidden unit whose linear net is closest to zero. Compare: |zin1|=0.1<|zin2|=0.4; select Z₁. The target-directed residual is 1−zin1=1−(−0.1)=1.1. Substitute the update: Δb1=0.1(1.1)=0.11; because x=(1,1), Δw11=Δw21=0.11
New parameters: (w11,w21,b1)=(0.31,0.11,−0.19); Z₂ is unchanged. The new Z₁ net is 0.23, so its bipolar output changes to +1.

3. Recompute the fixed OR combiner and check

Rule: keep the output parameters fixed and recompute from the hidden bipolar outputs. Substitute: (z1,z2)=(+1,−1),yin=0.5+0.5−0.5=0.5. Since the boundary is inclusive, y=+1. MR-I teaching example: target −1 also updates a zero-net unit

MR-I target −1: update every hidden output currently +1

Teaching example — added values: x = (1, −1), fixed v1=v2=by=12, α = 0.1. Initial hidden weights and biases are listed in step 1. Use the course threshold net ≥ 0 → +1.

1. The zero-boundary unit is active

Teaching example — added values: x=(1,−1), target t=−1, α=0.1. Start Z₁ at (w11,w21,b1)=(0.1,0.1,0) and Z₂ at (w12,w22,b2)=(0.2,0,0). Substitute: zin1=0.1−0.1=0,zin2=0.2. With the stated z=+1 when zin≥0, both units output +1. The fixed combiner gives yin=0.5+0.5+0.5=1.5, so y=+1 and the negative target is missed.

2. Move every currently +1 hidden unit toward −1

Rule: the target-directed residual for each active hidden unit is −1−zinj. Apply MR-I’s update to every unit that currently outputs +1; the inclusive threshold means this includes Z₁ at exactly zero. For Z₁, residual −1 gives Δb1=−0.1,Δw1=(−0.1,0.1), so new parameters are (0,0.2,−0.1) and new net is −0.3. For Z₂, residual −1−0.2=−1.2 gives Δb2=−0.12,Δw2=(−0.12,0.12); new parameters are (0.08,0.12,−0.12) and new net is −0.16.

3. Recompute the output and verify the target

Rule: threshold both updated hidden nets, then evaluate the unchanged combiner. State: both nets are negative, so (z1,z2)=(−1,−1). Substitute: yin=0.5−0.5−0.5=−0.5; therefore y=−1, matching t. Both initially active units were updated, including the one at zero.

MR-II: test a hidden-output flip

MR-II is described as more general than the MR-I case: it does not require a fixed OR output combiner and allows weights throughout the network to be adjusted. For an incorrect response, it considers hidden units with nets near zero (the lesson gives [−0.25,0.25] as an example), starting with the closest. It flips one hidden output, recomputes the network response, and keeps the trial only when the error improves. If accepted, it delta-adjusts that unit toward its newly assigned output.

The lesson provides this trial-flip heuristic, not a complete formula for every architecture or a universal error measure. The viewer below therefore states its small network, weights, biases, and target-match error test explicitly. It shows one rejected trial and a separate accepted trial.

+1↔−1

1. Evaluate this fully specified MR-II trial network

Teaching example — added architecture and values: x=(1,−1), target t=+1, α=0.1; Z₁ has weights/bias (0.1,0,−0.15), Z₂ has (0,−0.1,−0.02). Output weights/bias are v₁=0.1, v₂=−0.4, bᵧ=0. Both hidden nets are in the example interval [−0.25,0.25].

2. Try the nearest unit and reject the flip

Decision: |−0.05|<|0.08|, so try Z₁ first. Trial: flip its output −1→+1 while holding all weights fixed. The output net becomes 0+0.1(+1)−0.4(+1)=−0.3; thresholding still gives −1. Intermediate state: target mismatch remains, so reject this trial and restore Z₁ output to −1. No delta update follows a rejected trial.

3. Try Z₂ and accept the improved network response

Trial: next flip Z₂ output +1→−1, with Z₁ restored to −1. Substitute: yin=0+0.1(−1)−0.4(−1)=0.3; the network output becomes +1, matching t. Decision: accept the trial because the classification error changes from one mismatch to zero. This trial result is local to the explicit combiner values above.

4. Delta-adjust the accepted unit and check its state

Rule: use the accepted hidden output −1 as the target in the linear delta adjustment. Z₂’s pre-adjustment net was 0.08, so e2=−1−0.08=−1.08,Δw2=αe2x=(−0.108,0.108),Δb2=−0.108
New parameters: (w12,w22,b2)=(−0.108,0.008,−0.128); the recomputed hidden net is −0.108+0.008(−1)−0.128=−0.244, which still thresholds to −1. Final check: output net stays 0.3 and y=+1=t. Common mistakes

  • Training on a thresholded output: ADALINE’s error uses y = z before the optional class quantizer.
  • Reversing the error: the source uses e = t − y. The additive update depends on this sign.
  • Dropping the half-loss convention: Lesson 3 uses E = ½e² and the ηex update. Do not silently add the factor of 2 from a different squared-error convention.
  • Mixing a rate bound with the wrong update: pair 2/λmax(R) with w←w+ηex, or 1/λmax(R) with a factor-two update.
  • Reading MR-I “positive” as strictly greater than zero: the course activation includes zero in the +1 class; its negative-target update must cover that case.
  • Changing the MR-I output combiner: its v1=v2=by=12 weights stay fixed; the hidden layer carries the correction.
  • Treating the MR-II example as universal: the lesson gives a near-zero trial heuristic. The example’s network and mismatch test are teaching choices, not a rule for every architecture.

Exam focus

  • Write the order: weighted sum plus bias → linear response → target-minus-response error → additive weight and bias updates → optional class threshold.
  • State the half-squared loss and derive or apply Δwi=ηexi and Δb=ηe.
  • Explain why a correct class can still have nonzero ADALINE training error.
  • Rearrange 0.1≤nη≤1; for n=100, η lies from 0.001 to 0.01, with 0.005 as the source’s example choice.
  • For MR-I, name what is fixed, then distinguish the positive-target nearest-net case from the negative-target all-active-units case.
  • Apply the inclusive threshold consistently: net 0 produces +1 and is active for the MR-I negative-target update.
  • For MR-II, describe candidate selection, flip, output recomputation, accept/reject, and delta adjustment after acceptance. Do not present the heuristic as a full architecture-independent formula.

Why can an ADALINE output be classified correctly while its training error is still nonzero?

Check your answer

The class threshold discards the response magnitude. Training compares the continuous linear response with the target, so a response on the correct side of the boundary may still differ from the target.

With MR-I’s fixed combiner, what output results for hidden outputs (−1,+1)?

Check your answer

The output net is ½ + (−1)(½) + (+1)(½) = ½, so the inclusive threshold returns +1.

Under the stated MR-I threshold, does a hidden net of exactly zero count as +1 for the negative-target branch?

Check your answer

Yes. The course defines +1 for net ≥ 0, so zero is currently outputting +1 and belongs to the set of units to adjust toward −1.

In the MR-II viewer, why is the first flipped unit restored?

Check your answer

Its trial changes the output net from −0.5 to −0.3, which still thresholds to −1 and still misses target +1. The trial therefore does not improve the stated mismatch error.
