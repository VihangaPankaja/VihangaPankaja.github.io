ADALINE and MADALINE learning

ADALINE learns from its linear response. MADALINE must also decide which hidden units to change.

Learn from the value before the threshold

  • Training error: target minus linear output, even when the reported class is correct.
  • Loss here: ½e² gives Δw = ηex and Δb = ηe.
  • Hidden units: MR-I uses a fixed OR output; MR-II tests whether a hidden-output flip improves the result.

ADALINE means Adaptive Linear Neuron and is associated with Widrow and Hoff. MADALINE means Many ADALINE.

ADALINE learns before thresholding

Compute z=wᵀx+b. ADALINE uses this continuous value as its training output. A separate threshold may turn it into a class label.

z=∑i=1nwixi+b,y=f(z)=z,e=t−y

A perceptron learns from its thresholded decision. ADALINE learns from its unthresholded response. A correct ADALINE class can still have nonzero training error.

What drives the training error?Thresholded class outputLinear response before thresholding
What does the update measure?Whether the hard decision is wrongHow far the linear response is from the target
What is the final decision?Thresholded outputLinear response, optionally thresholded for classification

Half-squared error and the delta update

This lesson uses E=½e². Differentiating cancels the factor ½, so the correction is ηex. Keep e=target−linear output throughout.

E=12(t−y)2,Etotal=12∑p(t(p)−y(p))2
Δwi=η(t−y)xi=ηexi,Δb=η(t−y)=ηe

For each pattern: compute the linear response, find e, then add ηex to weights and ηe to bias. Repeat over the data. The lesson permits zero or small random initialization; the trace starts at zero.

Teaching example: two patterns over two online epochs

ADALINE: two online epochs with the Lesson 3 update

Teaching example — added values: two inputs, initial weights w = (0, 0) and bias b = 0, learning rate η=0.1. Pattern order is fixed: A: x = (1, 1), t = 1; then B: x = (1, −1), t = −1.

Training uses y = wᵀx + b before thresholding. The source total error is E=12∑p(t(p)−y(p))2.

1. Epoch 1, pattern A: update from the linear output

Given for this presentation: x = (1, 1), t = 1; current w = (0, 0), b = 0.

Rule: y=wTx+b,e=t−y,Δw=ηex,Δb=ηe

Substitute: y=0,e=1−0=1,η=0.1, so Δw=0.1(1)(1,1)=(0.1,0.1),Δb=0.1

State after update: w=(0.1,0.1),b=0.1
Next presentation uses these new parameters.

2. Epoch 1, pattern B: use its own pre-update response

Given: x = (1, −1), t = −1; current w=(0.1,0.1),b=0.1.

Rule: calculate the linear response before any class threshold.

Substitute: y=0.1(1)+0.1(−1)+0.1=0.1,e=−1−0.1=−1.1.

Then Δw=0.1(−1.1)(1,−1)=(−0.11,0.11),Δb=−0.11
State after update: w=(−0.01,0.21),b=−0.01
Next check both training patterns with this completed epoch state.

3. End of epoch 1: check the complete training set

Rule: evaluate both linear outputs using the same final epoch parameters, then compute the source total error E=12∑p(t(p)−y(p))2. Substitute: for pattern A, yA=−0.01+0.21−0.01=0.19; for B, yB=−0.01−0.21−0.01=−0.23.

Therefore E=12[(1−0.19)2+(−1+0.23)2]=0.6245. Both thresholded classes are already correct, but the continuous responses still have nonzero training error, so continue.

4. Epoch 2, pattern A: update the closer-than-target response

Given: x = (1, 1), t = 1; current w=(−0.01,0.21),b=−0.01.

Rule: e=t−y.

Substitute: y=−0.01+0.21−0.01=0.19,e=1−0.19=0.81; then Δw=0.1(0.81)(1,1)=(0.081,0.081),Δb=0.081

State after update: w=(0.071,0.291),b=0.071
Next present pattern B.

5. Epoch 2, pattern B: complete the second pass

Given: x = (1, −1), t = −1; current w=(0.071,0.291),b=0.071. Substitute: y=0.071−0.291+0.071=−0.149,e=−1−(−0.149)=−0.851.

Thus Δw=0.1(−0.851)(1,−1)=(−0.0851,0.0851),Δb=−0.0851
Final parameters: w=(−0.0141,0.3761),b=−0.0141
Now check both patterns again.

6. End of epoch 2: verify outputs and error

Rule: recompute from the final weights, not from the stored per-pattern values.

Substitute: yA=−0.0141+0.3761−0.0141=0.3479; yB=−0.0141−0.3761−0.0141=−0.4043.

Result: thresholding at zero gives +1 for A and −1 for B.

Independent error check: E=12[(1−0.3479)2+(−1+0.4043)2]=0.39004645, below the initial E=1.

The dataset error falls across these two passes; individual online errors need not decrease after every single presentation.

Choosing the learning rate

The learning rate controls correction size. Too large can overshoot or diverge; too small is slow. The lesson relates its mean-stability guidance to the largest eigenvalue of the input correlation matrix:

R=1P∑p=1Px(p)(x(p))T,0<η<2λmax(R)

The displayed bound matches the update without a factor of 2, w←w+ηex. When a text places that factor of 2 in the gradient update, the stated bound is 0<η<1λmax.

These constants must stay paired with their update convention. They describe the lesson’s stability guidance; they do not promise that every individual online sample error falls monotonically.

Since computing R and its eigenvalues may be inconvenient, the lesson also gives practical guidance: begin small (for example η=0.1 or less) and reduce η if training error becomes unstable.

For a single neuron with n inputs, it gives the heuristic 0.1≤nη≤1. For the source’s n=100 input-pixel example:

0.1100≤η≤1100⟹0.001≤η≤0.01

For n=100, η=0.005 lies inside the suggested interval. This input-count rule is a heuristic, not the eigenvalue theorem.

The full quadratic-error derivation, correlation-matrix calculations, and detailed LMS worked trace continue in Widrow–Hoff derivation and LMS calculations.

What one ADALINE can and cannot represent

One ADALINE minimizes a squared-error objective but still has a linear decision boundary. Thresholding cannot bend that boundary, so one unit cannot directly solve XOR.

MADALINE adds hidden decisions

MADALINE combines several hidden linear decisions into a nonlinear overall decision. The harder training question is: when the output is wrong, which hidden unit should change?

For the course’s MR-I example, every unit uses the inclusive bipolar threshold:

f(u)={+1,u≥0−1,u<0

The output unit is fixed as a bipolar OR combiner with v1=v2=by=12.

Its net is yin=by+z1v1+z2v2, followed by the same threshold.

Only when both hidden outputs are −1 is yin=−12 and the network returns −1; any +1 hidden output makes yin ≥ ½ and the result +1.

MR-I: change hidden units under a fixed OR output

MR-I decision branches under the lesson’s fixed bipolar OR output.
MR-I output stateHidden-unit actionWhy
Already correctNo updateThe current hidden decisions already produce the target.
Target +1, output −1Move the hidden net closest to zero toward +1.One positive hidden output is enough for the fixed OR.
Target −1, output +1Move every hidden unit outputting +1 toward −1.Both hidden outputs must be −1, including units whose net is exactly zero.

MR-I keeps the OR output weights fixed and changes only hidden-unit inputs. Choose the branch from the target and the current output:

bjnew=bjold+α(1−zin,j),wijnew=wijold+α(1−zin,j)xi

For target −1 with current output +1, move every hidden unit currently outputting +1 toward a net of −1:

bjnew=bjold+α(−1−zin,j),wijnew=wijold+α(−1−zin,j)xi

MR-I zero case: its threshold assigns +1 at net 0, so the negative-target branch must update those units too. “Positive nets” in the prose must be read consistently with that activation.

MR-I teaching example: target +1 selects the closest net

MR-I target +1: update the nearest hidden net

Teaching example — added values: fixed bipolar OR combiner v1=v2=by=12; hidden weights/biases and α = 0.1 are stated in step 1. Activation is +1 for net ≥ 0 and −1 otherwise.

1. Compute hidden and output states

Teaching example — added values: x=(1,1), target t=+1, α=0.1.

Start Z₁ with (w11,w21,b1)=(0.2,0,−0.3) and Z₂ with (w12,w22,b2)=(0,0.1,−0.5). Rule: zin1=b1+x1w11+x2w21,zin2=b2+x1w12+x2w22. Substitute: nets are −0.1 and −0.4, so both hidden outputs are −1.

With fixed v1=v2=by=12, yin=0.5−0.5−0.5=−0.5, hence y=−1. The target is missed; MR-I must adjust a hidden unit.

2. Select the hidden unit closest to zero

Rule: for t=+1, MR-I updates only the hidden unit whose linear net is closest to zero. Compare: |zin1|=0.1<|zin2|=0.4; select Z₁.

The target-directed residual is 1−zin1=1−(−0.1)=1.1. Substitute the update: Δb1=0.1(1.1)=0.11; because x=(1,1), Δw11=Δw21=0.11
New parameters: (w11,w21,b1)=(0.31,0.11,−0.19); Z₂ is unchanged.

The new Z₁ net is 0.23, so its bipolar output changes to +1.

3. Recompute the fixed OR combiner and check

Rule: keep the output parameters fixed and recompute from the hidden bipolar outputs. Substitute: (z1,z2)=(+1,−1),yin=0.5+0.5−0.5=0.5.

Since the boundary is inclusive, y=+1. Result: the network now matches t=+1. Independent check: the two hidden outputs are not both −1, so the fixed bipolar OR combiner returns +1.

MR-I teaching example: target −1 also updates a zero-net unit

MR-I target −1: update every hidden output currently +1

Teaching example — added values: x = (1, −1), fixed v1=v2=by=12, α = 0.1. Initial hidden weights and biases are listed in step 1. Use the course threshold net ≥ 0 → +1.

1. The zero-boundary unit is active

Teaching example — added values: x=(1,−1), target t=−1, α=0.1.

Start Z₁ at (w11,w21,b1)=(0.1,0.1,0) and Z₂ at (w12,w22,b2)=(0.2,0,0). Substitute: zin1=0.1−0.1=0,zin2=0.2.

With the stated z=+1 when zin≥0, both units output +1. The fixed combiner gives yin=0.5+0.5+0.5=1.5, so y=+1 and the negative target is missed.

2. Move every currently +1 hidden unit toward −1

Rule: the target-directed residual for each active hidden unit is −1−zinj. Apply MR-I’s update to every unit that currently outputs +1; the inclusive threshold means this includes Z₁ at exactly zero.

For Z₁, residual −1 gives Δb1=−0.1,Δw1=(−0.1,0.1), so new parameters are (0,0.2,−0.1) and new net is −0.3.

For Z₂, residual −1−0.2=−1.2 gives Δb2=−0.12,Δw2=(−0.12,0.12); new parameters are (0.08,0.12,−0.12) and new net is −0.16.

3. Recompute the output and verify the target

Rule: threshold both updated hidden nets, then evaluate the unchanged combiner.

State: both nets are negative, so (z1,z2)=(−1,−1).

Substitute: yin=0.5−0.5−0.5=−0.5; therefore y=−1, matching t.

Both initially active units were updated, including the one at zero.

MR-II: test a hidden-output flip

MR-II tests hidden units near zero, starting with the closest. Flip one output, recompute the network and retain the trial only if error improves. On acceptance, delta-adjust that unit toward its new output. The lesson suggests [−0.25,0.25] as a near-zero interval.

The lesson gives a trial-flip heuristic rather than a complete architecture-independent error rule. The teaching example specifies its network and target-match test, and includes both a rejected and an accepted flip.

+1↔−1
MR-II supplemental teaching example: reject, accept, then update

MR-II: a rejected flip followed by an accepted one

Teaching example — supplemental trial network: two bipolar hidden units, one bipolar output thresholded at zero, explicit weights and biases in step 1.

The output error test is the source’s target-match test (y = t); the sample interval [−0.25,0.25] is the source’s example. The output combiner is deliberately not the MR-I fixed OR combiner.

1. Evaluate this fully specified MR-II trial network

Teaching example — added architecture and values: x=(1,−1), target t=+1, α=0.1; Z₁ has weights/bias (0.1,0,−0.15), Z₂ has (0,−0.1,−0.02).

Output weights/bias are v₁=0.1, v₂=−0.4, bᵧ=0. Substitute: zin1=0.1−0.15=−0.05,zin2=0.1−0.02=0.08, so hidden outputs are (−1,+1).

The output net is 0+0.1(−1)−0.4(+1)=−0.5; y=−1, so the target is missed. Both hidden nets are in the example interval [−0.25,0.25].

2. Try the nearest unit and reject the flip

Decision: |−0.05|<|0.08|, so try Z₁ first. Trial: flip its output −1→+1 while holding all weights fixed.

The output net becomes 0+0.1(+1)−0.4(+1)=−0.3; thresholding still gives −1. Intermediate state: target mismatch remains, so reject this trial and restore Z₁ output to −1.

No delta update follows a rejected trial.

3. Try Z₂ and accept the improved network response

Trial: next flip Z₂ output +1→−1, with Z₁ restored to −1.

Substitute: yin=0+0.1(−1)−0.4(−1)=0.3; the network output becomes +1, matching t.

Decision: accept the trial because the classification error changes from one mismatch to zero.

This trial result is local to the explicit combiner values above.

4. Delta-adjust the accepted unit and check its state

Rule: use the accepted hidden output −1 as the target in the linear delta adjustment.

Z₂’s pre-adjustment net was 0.08, so e2=−1−0.08=−1.08,Δw2=αe2x=(−0.108,0.108),Δb2=−0.108
New parameters: (w12,w22,b2)=(−0.108,0.008,−0.128); the recomputed hidden net is −0.108+0.008(−1)−0.128=−0.244, which still thresholds to −1. Final check: output net stays 0.3 and y=+1=t.

The source gives this trial heuristic, not a universal architecture or a complete general MR-II update specification.

Common mistakes

  • Training on a thresholded output: ADALINE’s error uses y = z before the optional class quantizer.
  • Reversing the error: the source uses e = t − y. The additive update depends on this sign.
  • Dropping the half-loss convention: Lesson 3 uses E = ½e² and the ηex update. Do not silently add the factor of 2 from a different squared-error convention.
  • Mixing a rate bound with the wrong update: pair 2/λmax(R) with w←w+ηex, or 1/λmax(R) with a factor-two update.
  • Reading MR-I “positive” as strictly greater than zero: the course activation includes zero in the +1 class; its negative-target update must cover that case.
  • Changing the MR-I output combiner: its v1=v2=by=12 weights stay fixed; the hidden layer carries the correction.
  • Treating the MR-II example as universal: the lesson gives a near-zero trial heuristic. The example’s network and mismatch test are teaching choices, not a rule for every architecture.

Exam focus

  • Write the order: weighted sum plus bias → linear response → target-minus-response error → additive weight and bias updates → optional class threshold.
  • State the half-squared loss and derive or apply Δwi=ηexi and Δb=ηe.
  • Explain why a correct class can still have nonzero ADALINE training error.
  • Rearrange 0.1≤nη≤1; for n=100, η lies from 0.001 to 0.01, with 0.005 as the source’s example choice.
  • For MR-I, name what is fixed, then distinguish the positive-target nearest-net case from the negative-target all-active-units case.
  • Apply the inclusive threshold consistently: net 0 produces +1 and is active for the MR-I negative-target update.
  • For MR-II, describe candidate selection, flip, output recomputation, accept/reject, and delta adjustment after acceptance. Do not present the heuristic as a full architecture-independent formula.

Why can an ADALINE output be classified correctly while its training error is still nonzero?

Check your answer

The class threshold discards the response magnitude. Training compares the continuous linear response with the target, so a response on the correct side of the boundary may still differ from the target.

With MR-I’s fixed combiner, what output results for hidden outputs (−1,+1)?

Check your answer

The output net is ½ + (−1)(½) + (+1)(½) = ½, so the inclusive threshold returns +1.

Under the stated MR-I threshold, does a hidden net of exactly zero count as +1 for the negative-target branch?

Check your answer

Yes. The course defines +1 for net ≥ 0, so zero is currently outputting +1 and belongs to the set of units to adjust toward −1.

In the MR-II viewer, why is the first flipped unit restored?

Check your answer

Its trial changes the output net from −0.5 to −0.3, which still thresholds to −1 and still misses target +1. The trial therefore does not improve the stated mismatch error.
