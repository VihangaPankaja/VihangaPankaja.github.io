Multilayer networks and backpropagation

Big picture

A multilayer perceptron (MLP) sends an input through an input layer, one or more hidden layers, and an output layer. Hidden units let the network form useful intermediate representations, so it can model nonlinear patterns that a single straight decision boundary cannot capture. During training, backpropagation works out how each parameter contributed to the output error; gradient descent then uses those gradients to adjust weights and biases.

The loop is: compute the output, compare it with the target, propagate gradient information backward through the layers, apply parameter corrections, and repeat until a stopping rule is met. After training, prediction needs only the forward computation.

MLPs: structure and the lecture examples

In a layer-by-layer description, each layer applies its weights and bias and then an activation. The general pattern is am+1 = fm+1(Wm+1am + bm+1), so the layer-3 bias is b3 while layer 2 uses b2. The Lesson 4 network illustration shows 4 inputs, two hidden layers of 4 units each, and 2 outputs.

The lecture motivates hidden layers with two examples. XOR has input–target pairs (0,0)→0, (0,1)→1, (1,0)→1, and (1,1)→0. Since these labels are not linearly separable, a single-layer perceptron cannot represent the required separation. The lecture’s possible 2–2–1 MLP uses each of two hidden units to create a boundary, then combines their outputs.

For function approximation, Lesson 4 uses a 1–2–1 network with log-sigmoid hidden activations and a linear output: a1 = logsig(W1p + b1) and a2 = purelin(W2a1 + b2). Its target is g(p) = 1 + sin((π/4)p) for −2 ≤ p ≤ 2. The hidden units make smooth step-like responses; the linear output combines them.

The same lesson briefly names convolutional networks (CNNs) and recurrent networks (RNNs) as other architectures. They are context here; the derivation below is for a feedforward MLP. The Lesson 4 continuation covers backpropagation variations and deeper-network material.

Forward pass and notation

For the one-hidden-layer derivation, xi is input i; vij connects input Xi to hidden unit Zj; and wjk connects hidden unit Zj to output Yk. Biases are v0j and w0k. The first index names the source unit and the second the destination.

zin,j=v0j+∑ixivij,zj=f(zin,j)
yin,k=w0k+∑jzjwjk,yk=f(yin,k)

The net input is the weighted sum plus bias. The activation function transforms that net input into the value sent to the next layer. In the backpropagation derivation, derivatives are evaluated at the net input.

1. Hidden unit 1

Use the hidden net-input rule. Substitute the original values: z1=(0.2)(1.0)+(0.7)(0.5)−0.1=0.45. Since this is positive, ReLU leaves it unchanged: h1=ReLU(0.45)=0.45.

2. Hidden unit 2

The second hidden unit receives the same inputs but its own weights and bias: z2=(−0.4)(1.0)+(0.6)(0.5)+0.2=0.10, so h2=ReLU(0.10)=0.10.

3. Output and sigmoid

Combine the hidden activations with the output weights: zo=(0.9)(0.45)+(−0.5)(0.10)+0.1=0.455. Then y=σ(0.455)=11+e−0.455≈0.6118, or 0.612 to three decimals.

4. Class decision

The stated threshold is 0.5. Because 0.6118>0.5, the predicted class is 1. This is inference only: no target is compared and no parameter is updated.

Activation slopes used by the lecture

The lecture’s stated activation criteria for backpropagation are continuity, differentiability, being monotonically non-decreasing, and being easy to differentiate. It highlights sigmoid forms because their slopes can be calculated from their outputs:

f(x)=11+e−x,f′(x)=f(x)(1−f(x)),0<f(x)<1
fbipolar(x)=21+e−x−1
fbipolar′(x)=12(1+fbipolar(x))(1−fbipolar(x))

The binary sigmoid ranges from 0 to 1; the bipolar form ranges from −1 to 1 and is closely related to tanh. These are the lecture’s criteria and examples. The worked backpropagation trace below uses binary sigmoid. The lecture’s ReLU calculation is forward-only; if training with ReLU, a derivative convention at zero must be specified.

Two loss conventions in Lesson 4

For a set of Q examples, the mean squared error is:

EMSE=1Q∑q=1Q(tq−aq)2

The chain-rule derivation uses a single-pattern half-sum over output units:

E=12∑k(tk−yk)2

These are related squared-error objectives but have different aggregation and scale. The factor 1/2 cancels the 2 from differentiating a square. Keep the single-pattern definition beside the deltas derived from it; do not silently substitute batch MSE into that numeric trace.

Output deltas and corrections

Gradient descent moves a parameter opposite its loss gradient: Δw = −α ∂E/∂w. For an output unit, the chain rule separates the target residual, the activation slope, and the incoming hidden activation. With the lecture’s target-minus-output convention:

δk=(tk−yk)f′(yin,k)
Δwjk=αδkzj,Δw0k=αδk

The output delta is the residual multiplied by the local slope. A bias has derivative 1 with respect to the net input, so its correction is αδk without an activation multiplier.

Hidden deltas: collect every downstream contribution

A hidden activation can affect several output units. Its error signal therefore adds the output deltas weighted by the old outgoing connections, then multiplies by the hidden activation slope:

δj=f′(zin,j)∑kδkwjk

Each term δkwjk is one output’s contribution to hidden unit j. The sum is taken before applying the hidden derivative. Use the output weights from the current forward pass; updating them first would change the gradient for the same pattern.

Δvij=αδjxi,Δv0j=αδj

The lecture’s positive-add corrections follow directly from pairing target-minus-output deltas with gradient descent. Update by old value + correction; do not combine this delta sign with an output-minus-target update rule.

One training pair, one simultaneous update

For each pattern, compute the forward values first, then output deltas, then hidden deltas. Compute every correction using that same old parameter state, and only then add all corrections. In a later epoch, the updated parameters feed a new forward pass.

Epoch 1 · forward pass and loss

Start from (v,v0,w,w0)=(0.2,−0.1,0.3,0.1). With x=1,t=1,α=0.5, the hidden net input and activation are zin=−0.1+(1)(0.2)=0.1,h=σ(0.1)=0.524979. The output is yin=0.1+(0.3)(0.524979)=0.257494,y=σ(0.257494)=0.564020. For the single-pattern half-sum objective, E=12(1−0.564020)2=0.0950392.

Epoch 1 · deltas from the old weights

For a sigmoid, f′(u)=f(u)(1−f(u)). The target-minus-output output delta is δo=(1−0.564020)(0.564020)(1−0.564020)=0.107208. The hidden delta uses the old output weight w=0.3: δh=(0.524979)(1−0.524979)(0.107208)(0.3)=0.00802054. All deltas are now fixed for this pattern; do not substitute the soon-to-change output weight.

Epoch 1 · corrections and simultaneous update

Add the positive corrections Δw=αδoh=0.5(0.107208)(0.524979)=0.0281410, Δw0=αδo=0.0536040, Δv=αδhx=0.5(0.00802054)(1)=0.00401027, and Δv0=αδh=0.00401027 to their old values together. The new state is (v,v0,w,w0)=(0.204010,−0.0959897,0.328141,0.153604). These updated parameters start epoch 2.

Epoch 2 · recompute the forward pass and loss

Use the full epoch-1 result. The hidden values are zin=−0.0959897+(1)(0.204010)=0.108021,h=σ(0.108021)=0.526979. Then yin=0.153604+(0.328141)(0.526979)=0.326527,y=σ(0.326527)=0.580914. The loss is E=12(1−0.580914)2=0.0878165, below epoch 1 for this one training pair.

Epoch 2 · deltas from epoch-2 old weights

The output delta is δo=(1−0.580914)(0.580914)(1−0.580914)=0.102028. Use this epoch’s old output weight w=0.328141 for the hidden delta: δh=(0.526979)(1−0.526979)(0.102028)(0.328141)=0.00834550. Every correction below uses these pre-update values.

Epoch 2 · corrections and final parameters

The corrections are Δw=0.5(0.102028)(0.526979)=0.0268832, Δw0=0.5(0.102028)=0.0510138, Δv=0.5(0.00834550)(1)=0.00417275, and Δv0=0.00417275. Add them simultaneously to obtain (v,v0,w,w0)=(0.208183,−0.0918170,0.355024,0.204618).

Independent final check

With the same input, target, and sigmoid network, the recomputed epoch-2 output 0.580914 is closer to target 1 than epoch 1 output 0.564020, and the half-squared error fell from 0.0950392 to 0.0878165. This checks the direction for this one pair; it does not prove dataset convergence or guarantee every epoch lowers every aggregate loss.

Initialization, stopping, and practical limits

The lecture recommends random, non-identical starting values. If same-layer hidden units start identically, they can produce identical activations and gradients and remain indistinguishable—the symmetry problem. For sigmoid or tanh units, large-magnitude net inputs place activations on flat parts of their curves, where derivatives are near zero and updates become small. Extremely tiny weights can also leave signals too weak. Initialization scale is a balance, not a rule that “smaller is always better.”

Nguyen–Widrow initialization rescales each hidden input-weight vector. With p hidden units and n inputs, the lecture gives β = 0.7p1/n: start with a random vector, normalize it to length 1, rescale it to length β, and choose the bias in [−β, β]. This is a way to spread initial hidden-unit sensitivity through the input region, especially for sigmoid activations.

Teaching example · Nguyen–Widrow rescaling

Example setup: Formula boxes scroll sideways; swipe or use their scroll bars to read each complete expression. p=4 hidden units, n=2 input units, one hidden-unit random vector (3,4). The procedure normalizes each hidden input-weight vector, rescales it to β, then selects a bias in [−β, β].

1. Compute the scale

For 4 hidden units and 2 inputs, β=0.7p1/n=0.7(4)1/2=1.4. This is the target length for each hidden input-weight vector.

2. Normalize, then rescale

For one illustrative initial vector (3,4), its norm is 32+42=5. The unit vector is (3/5,4/5)=(0.6,0.8); multiplying by β=1.4 gives (0.84,1.12), whose norm is 1.4.

3. Choose a bias in range

Choose any bias inside [−1.4,1.4]; for example b=0.2. This is one valid illustrative draw, not a value specified by the lecture.

Training may stop when error is small enough, a maximum epoch count is reached, or validation error begins to rise. The lecture lists slow training, sensitivity to initialization, sigmoid saturation, poor input/target representation, and overtraining that harms generalization as limitations.

Common mistakes

  • Confusing backpropagation with gradient descent: backpropagation computes gradients efficiently; gradient descent uses them to update parameters.
  • Mixing the target-minus-output delta with a subtractive correction. Here the correction is added: old parameter + αδ(input).
  • Using a newly updated output weight inside the hidden delta for the same pattern.
  • Mixing up net input and activation. The derivative is evaluated at the net input, though sigmoid derivatives can be expressed using the output.
  • Forgetting that a hidden delta sums contributions from all output units.
  • Comparing the batch MSE and the single-pattern half-sum without accounting for both averaging and the factor 1/2.
  • Treating the 0.5 classification threshold in Example 3 as a training rule; it only converts that example’s output into a class.

Exam focus

  1. Write hidden and output net inputs, then activations.
  2. State the loss convention and calculate each output delta.
  3. Calculate each hidden delta from output deltas and old outgoing weights.
  4. Find weight corrections using the connected unit’s activation; find bias corrections using the unit delta.
  5. Apply all corrections simultaneously, then recompute for the next pattern.
  6. Check the direction of the output and loss on the training pair, without claiming that one step proves convergence.

Practice questions

Why does one hidden-unit delta sum across output units?

Check your answer

Because its activation contributes to every output. Each path contributes δkwjk; sum those contributions, then multiply by the hidden activation derivative.

For the lecture convention, what values are used in the hidden delta and when are parameters updated?

Check your answer

Use the output deltas and the old outgoing weights from the same forward pass. Calculate all corrections first, then add them to the old parameters together.

What is the difference between dataset MSE and the single-pattern objective?

Check your answer

Dataset MSE averages squared errors across Q examples. The derivation uses one pattern and half the sum across output units; the factor 1/2 simplifies differentiation. Their scale and aggregation differ.

Why can identical initial hidden-unit weights be a problem?

Check your answer

Identical units can receive identical signals and gradients, so they keep learning the same feature instead of specializing. Random, distinct starts break that symmetry.
