Multilayer networks and backpropagation

Send activations forward, send error signals backward, then update all parameters from the same old state.

The chain rule assigns credit to hidden weights

  • Forward: calculate every net input and activation using the current weights.
  • Backward: output deltas use target error; hidden deltas collect all downstream contributions.
  • Update last: compute every delta before changing any weight. Prediction after training needs only the forward pass.

Train by repeating forward computation, loss calculation, backward deltas and a parameter update. After training, inference uses only forward computation.

MLPs: structure and the lecture examples

Each layer computes am+1=fm+1(Wm+1am+bm+1). Use that layer’s own bias. The lecture illustration has 4 inputs, hidden layers of 4 and 4 units, and 2 outputs.

XOR maps 00→0, 01→1, 10→1, 11→0. One straight boundary cannot separate these labels. The lecture’s 2–2–1 MLP combines two hidden boundaries.

For function approximation, Lesson 4 uses a 1–2–1 network with log-sigmoid hidden activations and a linear output: a1 = logsig(W1p + b1) and a2 = purelin(W2a1 + b2).

Its target is g(p) = 1 + sin((π/4)p) for −2 ≤ p ≤ 2. The hidden units make smooth step-like responses; the linear output combines them.

The same lesson briefly names convolutional networks (CNNs) and recurrent networks (RNNs) as other architectures. They are context here; the derivation below is for a feedforward MLP. The Lesson 4 continuation covers backpropagation variations and deeper-network material.

Forward pass and notation

Read a weight’s indices from source to destination:

  • vij: input Xᵢ → hidden Zⱼ.
  • wjk: hidden Zⱼ → output Yₖ.
  • v0j and w0k: the respective biases.
zin,j=v0j+∑ixivij,zj=f(zin,j)
yin,k=w0k+∑jzjwjk,yk=f(yin,k)

Add weights × incoming activations plus bias, then apply f. In the backward pass, evaluate f′ at that same net input.

1. Hidden unit 1

Use the hidden net-input rule. Substitute the original values: z1=(0.2)(1.0)+(0.7)(0.5)−0.1=0.45. Since this is positive, ReLU leaves it unchanged: h1=ReLU(0.45)=0.45.

2. Hidden unit 2

The second hidden unit receives the same inputs but its own weights and bias: z2=(−0.4)(1.0)+(0.6)(0.5)+0.2=0.10, so h2=ReLU(0.10)=0.10.

3. Output and sigmoid

Combine the hidden activations with the output weights: zo=(0.9)(0.45)+(−0.5)(0.10)+0.1=0.455. Then y=σ(0.455)=11+e−0.455≈0.6118, or 0.612 to three decimals.

4. Class decision

The stated threshold is 0.5. Because 0.6118>0.5, the predicted class is 1. This is inference only: no target is compared and no parameter is updated.

Activation slopes used by the lecture

The lecture’s stated activation criteria for backpropagation are continuity, differentiability, being monotonically non-decreasing, and being easy to differentiate. It highlights sigmoid forms because their slopes can be calculated from their outputs:

f(x)=11+e−x,f′(x)=f(x)(1−f(x)),0<f(x)<1
fbipolar(x)=21+e−x−1
fbipolar′(x)=12(1+fbipolar(x))(1−fbipolar(x))

The binary sigmoid ranges from 0 to 1; the bipolar form ranges from −1 to 1 and is closely related to tanh. These are the lecture’s criteria and examples. The worked backpropagation trace below uses binary sigmoid. The lecture’s ReLU calculation is forward-only; if training with ReLU, a derivative convention at zero must be specified.

Two loss conventions in Lesson 4

For a set of Q examples, the mean squared error is:

EMSE=1Q∑q=1Q(tq−aq)2

The chain-rule derivation uses a single-pattern half-sum over output units:

E=12∑k(tk−yk)2

The ½ cancels the derivative’s 2. Dataset MSE and single-pattern half-sum loss differ in scale and aggregation; the deltas below belong to the single-pattern objective.

Output deltas and corrections

Gradient descent uses Δw=−α∂E/∂w. The output chain rule splits this into target residual × activation slope × incoming activation. With target-minus-output deltas:

δk=(tk−yk)f′(yin,k)
Δwjk=αδkzj,Δw0k=αδk

An output delta is residual × local slope. A bias has constant input 1, so its correction is αδₖ.

Hidden deltas: collect every downstream contribution

A hidden unit can affect several outputs. Add all downstream contributions, then multiply by the hidden activation slope:

δj=f′(zin,j)∑kδkwjk

Use the outgoing weights from the current forward pass. Updating them before calculating hidden deltas would mix two parameter states.

Δvij=αδjxi,Δv0j=αδj

These target-minus-output deltas pair with additive corrections. Mixing them with an output-minus-target rule reverses the update sign.

One training pair, one simultaneous update

Calculate all deltas first. Apply all corrections second. Recompute the forward pass and deltas for the next training state.

Two epochs with explicit starting weights and biases

Supplemental teaching example · one-pair backpropagation over two epochs

Fixed givens: Formula boxes scroll sideways; swipe or use their scroll bars to read each complete expression. x=1,t=1,α=0.5; one sigmoid hidden unit and one sigmoid output. Initial parameters v=0.2,v0=−0.1,w=0.3,w0=0.1. Loss for each single pattern: E=12(t−y)2. Compute every delta and correction from the same old parameter state, then apply all four corrections together.

Epoch 1 · forward pass and loss

Start from (v,v0,w,w0)=(0.2,−0.1,0.3,0.1).

With x=1,t=1,α=0.5, the hidden net input and activation are zin=−0.1+(1)(0.2)=0.1,h=σ(0.1)=0.524979.

The output is yin=0.1+(0.3)(0.524979)=0.257494,y=σ(0.257494)=0.564020. For the single-pattern half-sum objective, E=12(1−0.564020)2=0.0950392.

Epoch 1 · deltas from the old weights

For a sigmoid, f′(u)=f(u)(1−f(u)). The target-minus-output output delta is δo=(1−0.564020)(0.564020)(1−0.564020)=0.107208.

The hidden delta uses the old output weight w=0.3: δh=(0.524979)(1−0.524979)(0.107208)(0.3)=0.00802054.

All deltas are now fixed for this pattern; do not substitute the soon-to-change output weight.

Epoch 1 · corrections and simultaneous update

Add the positive corrections Δw=αδoh=0.5(0.107208)(0.524979)=0.0281410, Δw0=αδo=0.0536040, Δv=αδhx=0.5(0.00802054)(1)=0.00401027, and Δv0=αδh=0.00401027 to their old values together.

The new state is (v,v0,w,w0)=(0.204010,−0.0959897,0.328141,0.153604). These updated parameters start epoch 2.

Epoch 2 · recompute the forward pass and loss

Use the full epoch-1 result. The hidden values are zin=−0.0959897+(1)(0.204010)=0.108021,h=σ(0.108021)=0.526979.

Then yin=0.153604+(0.328141)(0.526979)=0.326527,y=σ(0.326527)=0.580914.

The loss is E=12(1−0.580914)2=0.0878165, below epoch 1 for this one training pair.

Epoch 2 · deltas from epoch-2 old weights

The output delta is δo=(1−0.580914)(0.580914)(1−0.580914)=0.102028.

Use this epoch’s old output weight w=0.328141 for the hidden delta: δh=(0.526979)(1−0.526979)(0.102028)(0.328141)=0.00834550. Every correction below uses these pre-update values.

Epoch 2 · corrections and final parameters

The corrections are Δw=0.5(0.102028)(0.526979)=0.0268832, Δw0=0.5(0.102028)=0.0510138, Δv=0.5(0.00834550)(1)=0.00417275, and Δv0=0.00417275.

Add them simultaneously to obtain (v,v0,w,w0)=(0.208183,−0.0918170,0.355024,0.204618).

Independent final check

With the same input, target, and sigmoid network, the recomputed epoch-2 output 0.580914 is closer to target 1 than epoch 1 output 0.564020, and the half-squared error fell from 0.0950392 to 0.0878165. This checks the direction for this one pair; it does not prove dataset convergence or guarantee every epoch lowers every aggregate loss.

Initialization, stopping, and practical limits

Start hidden units with random, non-identical parameters to break symmetry. Identical units can produce identical gradients and stay identical.

Large sigmoid or tanh nets saturate, making derivatives small. Extremely tiny weights can also weaken signals. Initialization needs a suitable scale.

Nguyen–Widrow initialization rescales each hidden input-weight vector. With p hidden units and n inputs, the lecture gives β = 0.7p1/n: start with a random vector, normalize it to length 1, rescale it to length β, and choose the bias in [−β, β].

This is a way to spread initial hidden-unit sensitivity through the input region, especially for sigmoid activations.

Numerical rescaling example

Teaching example · Nguyen–Widrow rescaling

Example setup: Formula boxes scroll sideways; swipe or use their scroll bars to read each complete expression. p=4 hidden units, n=2 input units, one hidden-unit random vector (3,4). The procedure normalizes each hidden input-weight vector, rescales it to β, then selects a bias in [−β, β].

1. Compute the scale

For 4 hidden units and 2 inputs, β=0.7p1/n=0.7(4)1/2=1.4. This is the target length for each hidden input-weight vector.

2. Normalize, then rescale

For one illustrative initial vector (3,4), its norm is 32+42=5.

The unit vector is (3/5,4/5)=(0.6,0.8); multiplying by β=1.4 gives (0.84,1.12), whose norm is 1.4.

3. Choose a bias in range

Choose any bias inside [−1.4,1.4]; for example b=0.2. This is one valid illustrative draw, not a value specified by the lecture.

Stop when error is acceptable, the epoch limit is reached, or validation error begins to rise. Watch for slow training, poor initialization, saturation and overfitting.

Common mistakes

  • Confusing backpropagation with gradient descent: backpropagation computes gradients efficiently; gradient descent uses them to update parameters.
  • Mixing the target-minus-output delta with a subtractive correction. Here the correction is added: old parameter + αδ(input).
  • Using a newly updated output weight inside the hidden delta for the same pattern.
  • Mixing up net input and activation. The derivative is evaluated at the net input, though sigmoid derivatives can be expressed using the output.
  • Forgetting that a hidden delta sums contributions from all output units.
  • Comparing the batch MSE and the single-pattern half-sum without accounting for both averaging and the factor 1/2.
  • Treating the 0.5 classification threshold in Example 3 as a training rule; it only converts that example’s output into a class.

Exam focus

  1. Write hidden and output net inputs, then activations.
  2. State the loss convention and calculate each output delta.
  3. Calculate each hidden delta from output deltas and old outgoing weights.
  4. Find weight corrections using the connected unit’s activation; find bias corrections using the unit delta.
  5. Apply all corrections simultaneously, then recompute for the next pattern.
  6. Check the direction of the output and loss on the training pair, without claiming that one step proves convergence.

Practice questions

Why does one hidden-unit delta sum across output units?

Check your answer

Because its activation contributes to every output. Each path contributes δkwjk; sum those contributions, then multiply by the hidden activation derivative.

For the lecture convention, what values are used in the hidden delta and when are parameters updated?

Check your answer

Use the output deltas and the old outgoing weights from the same forward pass. Calculate all corrections first, then add them to the old parameters together.

What is the difference between dataset MSE and the single-pattern objective?

Check your answer

Dataset MSE averages squared errors across Q examples. The derivation uses one pattern and half the sum across output units; the factor 1/2 simplifies differentiation. Their scale and aggregation differ.

Why can identical initial hidden-unit weights be a problem?

Check your answer

Identical units can receive identical signals and gradients, so they keep learning the same feature instead of specializing. Random, distinct starts break that symmetry.
