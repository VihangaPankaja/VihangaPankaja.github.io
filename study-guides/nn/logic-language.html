The operator gives “if” its meaning

  • One variable: combine memberships at the same x. Two variables need ordered pairs (x,y).
  • Global implication: a weak antecedent can make the relation grade high. Local Mamdani contributions are limited by the antecedent.
  • Hedges change grades: “very” squares μ; “more or less” takes √μ. The universe elements stay the same.

Use classical logic for the binary prerequisite. Here, focus on fuzzy operator meanings, rule matrices and word modifiers.

From a crisp boundary to graded truth

On the source universe X=[0,50] °C, “hot” is crisp at 30 °C: below the threshold its characteristic grade is 0; from 30 °C upward it is 1.

The fuzzy version lets membership rise linearly between 20 °C and 30 °C, avoiding a sudden change at one boundary. A membership grade is a degree of compatibility with the word “hot,” not a probability that a temperature is hot.

χHot(x)={0,x<30∘C1,x≥30∘C
μHot(x)={0,x≤20∘Cx−2010,20∘C<x<30∘C1,x≥30∘C
Compare the source threshold at 29.9 °C and a teaching check at 25 °C

At 29.9 °C, χHot(29.9)=0 because 29.9<30; μHot(29.9)=(29.9−20)/10=0.99.

Fuzzy propositions and connectives

An atomic fuzzy proposition assigns one label to one variable, such as “temperature is hot.” Its truth grade is the membership grade. Compound propositions combine atomic grades using named connectives.

The standard choices here are NOT=1−μ, OR=max and AND=min. Other T-norms and S-norms are possible, so state the choice before calculating.

T(¬P~)=1−a,T(P~∨Q~)=max(a,b),T(P~∧Q~)=min(a,b)

Two sets on the same universe combine at the same element. Two different variables need a relation on a product universe: use x for the first and y for the second.

Global material implications can be high when the antecedent grade is low: a weak premise does not violate the conditional. Local Mamdani operators instead measure the rule’s contribution where it applies, so their output is bounded by the antecedent grade.

An ELSE rule activates a second branch with complement grade 1−a:

μR(x,y)=max(min(a,b),min(1−a,c))

Here the first branch contributes when the antecedent grade is a, while the ELSE branch contributes when its complement 1−a is high. For the complete rule firing, aggregation, and defuzzification pipelines, continue to Mamdani, Sugeno, Tsukamoto, and ANFIS.

Relational composition: infer a fuzzy output

An observation A′ on X composes with a rule relation R on X×Y to infer B′ on Y. The composition operator determines how each input grade contributes.

One input, one rule relation, three composition operators

Teaching example — added input: A′ on U={1,2,3,4} has grades (0, 0.8, 0.4, 0.2). Rule relation: use the source large→small Mamdani-minimum relation QMM on rows x=1…4 and columns y=1…3: [[0,0,0],[0.1,0.1,0.1],[0.5,0.5,0.1],[1,0.5,0.1]]. Outputs are reported in y=1,2,3 order.

Max–min: clip each relation entry, then take the maximum

Rule: μB′(y)=maxxmin(μA′(x),μR(x,y)). μB′(1)=max(min(0,0),min(0.8,0.1),min(0.4,0.5),min(0.2,1))=max(0,0.1,0.4,0.2)=0.4; μB′(2)=max(min(0,0),min(0.8,0.1),min(0.4,0.5),min(0.2,0.5))=max(0,0.1,0.4,0.2)=0.4; μB′(3)=max(min(0,0),min(0.8,0.1),min(0.4,0.1),min(0.2,0.1))=max(0,0.1,0.1,0.1)=0.1. Output: (0.4,0.4,0.1).

The maximum selects the strongest clipped contribution for each output value.

Max–product: multiply each pair, then take the maximum

Rule: μB′(y)=maxx[μA′(x)μR(x,y)]. μB′(1)=max(0·0,0.8·0.1,0.4·0.5,0.2·1)=max(0,0.08,0.20,0.20)=0.20; μB′(2)=max(0,0.08,0.20,0.10)=0.20; μB′(3)=max(0,0.08,0.04,0.02)=0.08. Output: (0.20,0.20,0.08).

Multiplication keeps each antecedent grade proportional to its relation grade.

Bounded sum–product: add all products and cap at one

Rule: μB′(y)=min(1,∑xμA′(x)μR(x,y)). μB′(1)=min(1,0+0.08+0.20+0.20)=0.48; μB′(2)=min(1,0+0.08+0.20+0.10)=0.38; μB′(3)=min(1,0+0.08+0.04+0.02)=0.14. Output: (0.48,0.38,0.14).

The cap guarantees every output grade remains in [0,1].

Check axes, ranges, and why the outputs differ

The input fuzzy set is on U={1,2,3,4} and all three inferred outputs are on V={1,2,3}. Each result lies in [0,1]. The same relation and input produce three different output sets because the aggregation rule differs: max–min clips, max–product scales, and bounded sum–product accumulates contributions. These are relation-composition calculations, not a complete controller pipeline.

Composition is generally many-to-one: minimum and maximum discard information, so composing the original antecedent with a fuzzy relation need not recover the exact consequent.

Max–min and max–product composition are associative and monotone, distribute over max-union, and satisfy (R∘S)⁻¹=S⁻¹∘R⁻¹. Here inverse means transpose, not matrix inverse.

Bounded sum-product is monotone and respects transposition. It is not generally associative or distributive over max-union: intermediate clipping at 1 can discard information.

For foundational relation matrices and their composition procedures, see relations and matrix composition; this page uses a relation specifically to compare implication meanings.

The following associativity and max-union identities use max–min or max–product composition.

(R∘S)∘T=R∘(S∘T),R∘(S∪T)=(R∘S)∪(R∘T),S⊆T⇒R∘S⊆R∘T
(R∘S)−1=S−1∘R−1
Supplemental teaching example: grouping changes bounded sum–product

These constructed relation matrices show why the cap matters. Use two elements in each universe, with rows and columns in order 1, 2. Here A maps X to Y, B maps Y to Z, and C maps Z to W. In this example only, every composition uses bounded sum–product, not max–product.

First compose A with B. The first row is zero. The only nonzero cells are in the second row:

(A∘B)21=min(1,0·0+0.5·0.5)=0.25
(A∘B)22=min(1,0·0+0.5·1)=0.5

Composing that intermediate matrix with C leaves just one nonzero output cell:

((A∘B)∘C)22=min(1,0.25·0.5+0.5·1)=0.625
(A∘B)∘C=[0000.625]

Now group B with C first. Its first row and first column are zero. The remaining cell reaches the cap before A is applied:

(B∘C)22=min(1,0.5·0.5+1·1)=min(1,1.25)=1
B∘C=[0001]
(A∘(B∘C))22=min(1,0·0+0.5·1)=0.5
A∘(B∘C)=[0000.5]

All other final cells are zero in both groupings. Since 0.625 differs from 0.5, bounded sum–product is not associative. In the second grouping, the intermediate cap discards 0.25 before multiplication by the 0.5 entry of A. This counterexample concerns associativity; it does not change the max–min and max–product identities above.

Linguistic variables: words with quantitative meaning

A linguistic variable is the four-tuple (X,T,U,M):

  • X names the variable.
  • T lists its word-valued terms.
  • U is the numerical universe.
  • M assigns a membership function to each term.

For Age: X=Age, T={young,old}, U=[0,100] years.

μyoung(y)={1,y≤25[1+(y−255)2]−1,y>25y∈[0,100]
μold(y)=1−[1+(y−505)2]−1,50≤y≤100

The graph in the lecture shows young staying at 1 through age 25 and then declining, while old rises from 0 at age 50. The old function is only stated on [50,100]; no value is assigned here below 50 or above 100. This preserves the source’s defined range instead of silently extrapolating it.

Hedges change membership grades

A hedge changes membership grades, leaving elements in place. “Very” concentrates by squaring; “more or less” dilates by taking a square root. The lecture also defines plus, minus and intensification.

Intensification fixes 0.5, lowers grades below it and raises grades above it. “Very very” means (μ²)²=μ⁴. Neither operation changes the universe values.

Precedence for compound linguistic expressions

Use explicit grouping. Without it: hedges and NOT bind before AND; AND binds before OR. Evaluate nested hedges inside out: “plus very minus small” means plus(very(minus(small))).

Common mistakes

  • Treating a membership grade as a probability. It describes compatibility with a fuzzy term in the chosen model.
  • Applying pointwise max/min to propositions on different universes. A rule between different variables is a relation on their Cartesian product.
  • Treating fuzzy implication as one universal formula. Name the global or local operator and state its formula.
  • Using a global implication as though it were a local rule contribution. Global relations can be high when the antecedent grade is low; Mamdani min/product are bounded by it.
  • Reading inclusive OR as XOR, or material implication as a∨b. Binary implication uses ¬a∨b.
  • Swapping relation axes. The first index is the antecedent x; the second is consequent y.
  • Applying nested hedges left-to-right, or interpreting “very very” as μ² rather than μ⁴.
  • Assigning an old-age membership outside the interval supplied for its formula.
