Probabilistic neural networks

A memory-based classifier that turns stored examples into Gaussian class-density estimates.

Big picture

A probabilistic neural network (PNN) is a feedforward classifier that estimates a probability density for each class from labeled examples. It uses nonparametric density estimation: each stored example contributes a local Gaussian bump, and the class layer averages those contributions. Classification compares the resulting class scores. This is the kernel-density idea implemented as a four-layer network.

Four layers, one stored example per pattern unit

The architecture makes the computation visible: the input is compared with every stored exemplar; each pattern unit sends its Gaussian response to the summation unit for that exemplar’s class; the output layer compares the class scores. If a new labeled example arrives, training adds a pattern unit, stores its feature vector, and connects it to the matching class. There is no sequence of weight corrections, epochs, or bias updates.

From exemplar distance to class density

Let x be the input feature vector and xkj the j-th stored example from class Ck. The pattern unit evaluates an isotropic Gaussian kernel. Here d is the number of features, σ is the shared smoothing bandwidth, and the squared Euclidean distance measures how far the query is from that exemplar.

ϕkj(x)=1(2π)d/2σdexp(−‖x−xkj‖22σ2)

Nearby examples produce larger responses; distant examples produce smaller ones. The summation unit averages all responses belonging to its class, using that class’s own sample count Nk.

f^k(x)=1Nk∑j=1Nkϕkj(x)

Because this is an average, a class does not receive a larger density merely because it has more stored exemplars. A prior probability is a separate factor applied during the decision.

Decision: density, prior, and misclassification cost

With equal priors and equal misclassification costs, choose the class with the largest estimated density:

y^=argmaxkf^k(x)

For two classes, the lecture gives the comparison below. The cost convention matters: CA is the loss for deciding B when the true class is A (a missed A); CB is the loss for deciding A when the true class is B (a false A). Correct decisions have zero loss.

choose A if hACAf^A(x)>hBCBf^B(x)

This form follows from comparing the two possible conditional risks. The risk of deciding A is CBP(B∣x), while the risk of deciding B is CAP(A∣x). Substituting Bayes’ rule and canceling the shared evidence term gives the displayed inequality. Thus, under this explicit crossed misclassification-cost convention, the lecture’s rule is valid. For a general multiclass loss matrix, choose the action with the smallest conditional expected loss; do not treat one scalar loss per class as a universal rule.

Teaching example: classify a one-dimensional query

The worked values below illustrate the source’s kernel, class-specific averaging, and equal-prior/equal-cost decision.

Step-by-step distances, kernels, averages, and decision

PNN classification: distances to class decision

Teaching example inputs

  • Query: x = 1; dimension: d = 1; bandwidth: σ = 1.
  • Class A stores exemplars 0 and 2; class B stores exemplar 4.
  • Equal priors and equal misclassification costs; common Gaussian normalizer: 1/√(2π) ≈ 0.3989423.
  • For each exemplar, compute its squared distance, then its kernel response. Average responses within each class.

1. Start from the labeled exemplars

The pattern layer has two A units and one B unit: A:{0, 2}; B:{4}. These stored values stay fixed during classification. The query is x = 1.

2. Compute squared distances

Use (x − xkj)². For A: (1 − 0)² = 1 and (1 − 2)² = 1. For B: (1 − 4)² = 9. Both A exemplars are closer to the query.

3. Evaluate the Gaussian pattern responses

Substitute each squared distance into the kernel with σ = 1:

Class / exemplar Squared distance Kernel response
A / 0 1 0.3989423 exp(−1/2) = 0.2419707
A / 2 1 0.3989423 exp(−1/2) = 0.2419707
B / 4 9 0.3989423 exp(−9/2) = 0.00443185

The farther B exemplar has a much smaller response because the Gaussian decays with squared distance.

4. Average responses inside each class

Divide by the number of stored examples in that class:

  • A: (0.2419707 + 0.2419707) / 2 = 0.2419707.
  • B: 0.00443185 / 1 = 0.00443185.

The divisor is class-specific: NA = 2 and NB = 1. This is a class average, not a raw total.

5. Decide and independently check

Equal priors and costs mean compare the densities directly. Since 0.2419707 > 0.00443185, predict class A.

Independent check: the query is one unit from both A exemplars and three units from B’s exemplar, so with the same Gaussian bandwidth and equal class weighting, A’s mean response must be larger. The computed decision agrees.

Bandwidth and practical trade-offs

The bandwidth σ controls the width of every Gaussian bump. A small σ makes each example’s influence narrow, so the estimate follows individual samples closely and can overfit. A large σ spreads influence farther, smoothing the estimate and potentially obscuring class structure. With enough data and a suitable smoothing choice, the density estimate can approach the true class density; this is an asymptotic property, not a guarantee for every finite data set.

Training is fast because adding a sample mainly stores it and wires a pattern unit. The same design means memory grows with the training set, and a prediction evaluates stored examples, so inference work grows with the number of samples (and feature dimension for each distance). Gaussian responses also decrease for far-away exemplars, limiting their individual influence.

Common mistakes

  • Summing instead of averaging: divide each class total by its own Nk.
  • Calling a density a posterior: f^k(x) estimates the class-conditional density. Priors are separate; posterior probabilities require normalization across classes.
  • Using distance without the kernel: the pattern response includes both the Gaussian exponential and its normalizing factor.
  • Reversing the cost meanings: in the two-class inequality, CA penalizes missing a true A, while CB penalizes falsely deciding A for a true B.
  • Describing PNN training as iterative optimization: the method stores each labeled example; the lecture’s procedure has no epochs or gradient updates.
  • Ignoring σ: very narrow kernels can overfit; very broad kernels can oversmooth.

Exam focus

  • Name the layers in order: input, pattern, summation, output/decision.
  • For a pattern unit, compute squared Euclidean distance and substitute it into the Gaussian kernel.
  • Average the pattern responses within each class using its own Nk.
  • With equal priors and costs, select the maximum-density class.
  • For the two-class cost rule, state which error each class cost penalizes before applying the inequality.
  • Explain the trade-off: quick sample insertion and density interpretation, with storage/inference costs and bandwidth sensitivity.

Practice

If a query is equally distant from every stored exemplar and σ is shared, what determines the pattern-response ranking?

Check your answer

All pattern units have the same Gaussian response because the kernel depends on the same squared distance, dimension, and bandwidth. Class averages will therefore tie unless class-specific priors or costs change the decision.

Class A has 3 stored examples and class B has 6. What denominator is used for each class density estimate?

Check your answer

Use 3 for A and 6 for B: each estimated density is the average of that class’s pattern responses, divided by its own Nk.

A PNN receives one newly labeled training example. What changes?

Check your answer

Add one pattern unit that stores the new feature vector and connect it to its class summation unit. No epoch or gradient update is required.

In the two-class rule, what does CB mean under the stated convention?

Check your answer

It is the loss for deciding A when the true class is B: a false-A decision. CA is the loss for deciding B when the true class is A.

What happens when σ is made much larger?

Check your answer

Each Gaussian bump becomes broader. The estimated density becomes smoother, but may blur class structure (oversmoothing).

Primary reference for the two-class loss convention

Specht’s original PNN paper defines the two-category Bayes decision rule using priors, class densities, and the losses associated with each possible misclassification, with zero loss for correct decisions: D. F. Specht, “Probabilistic Neural Networks” (1990), p. 110, equation (1).
