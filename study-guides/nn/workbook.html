Calculation 01

Calculate a neuron output

Weights combine the inputs. The activation turns that sum into the output.

Given

x = (2, −1), w = (0.4, 0.6), b = 0.1. Use either σ(a) = 1/(1 + exp(−a)) or the binary rule y = 1 when a ≥ 0, otherwise 0.

Method: Multiply → add the bias → apply the stated activation.

2 × 0.4
0.8−1 × 0.6
−0.6Add bias 0.1
net 0.3Apply sigmoid
0.574443
Follow the worked solution 3 explained steps

1. Multiply each input by its own weight

0.4 × 2 = 0.8, and 0.6 × (−1) = −0.6. Keep the negative sign on the second input.

2. Add the bias once

a = 0.8 − 0.6 + 0.1 = 0.3

The bias is a separate constant, not another copy of each input.

3. Choose the activation asked for

Sigmoid: y = 1/(1 + exp(−0.3)) = 0.574443. Binary threshold: 0.3 ≥ 0, so y = 1.

These are two activation choices for the same net input. Do not threshold first when a sigmoid value is requested.

Check: A positive sigmoid net gives a value above 0.5. The binary answer is a class, not a probability.

Now try it

Keep x and w fixed. Change only b to −0.5. Find the net, sigmoid output and binary output.

Check the steps and answer
  1. Weighted sum = 0.8 − 0.6 = 0.2.
  2. Add bias: a = 0.2 − 0.5 = −0.3.
  3. σ(−0.3) = 0.425557; the binary output is 0.

Calculation 02

Correct a binary perceptron mistake

A mistaken class changes the boundary. Write the zero-threshold rule before doing arithmetic.

Given

x = (1, 1), target t = 1, w = (−0.2, 0.1), b = 0, η = 0.5. Binary output is 1 at net ≥ 0. Use e = t − y and add ηex to w, ηe to b.

Method: Predict with old parameters → find the class error → update → predict again.

Follow the worked solution 4 explained steps

1. Predict from the old boundary

a = −0.2 × 1 + 0.1 × 1 + 0 = −0.1. It is negative, so y = 0. Target 1 means this is a mistake.

2. Find one correction per parameter

e = 1 − 0 = 1. Δw₁ = 0.5 × 1 × 1 = 0.5; Δw₂ = 0.5; Δb = 0.5.

Bias uses a constant input of 1.

3. Apply all corrections

w′ = (−0.2 + 0.5, 0.1 + 0.5) = (0.3, 0.6); b′ = 0.5.

4. Recheck this pattern

a′ = 0.3 + 0.6 + 0.5 = 1.4, so y′ = 1. This pattern is now correct. Test every training pattern before declaring convergence.

Check: The binary rule here differs from the lecture’s bipolar mistake-only trace. Do not mix their update magnitudes or net-zero conventions.

Now try it

Start from the updated parameters above. Present x = (1, 0), t = 0 with the same η. Find the next parameters.

Check the steps and answer
  1. Old net = 0.3 + 0 + 0.5 = 0.8; y = 1, so e = −1.
  2. Δw = (−0.5, 0), Δb = −0.5.
  3. w″ = (−0.2, 0.6), b″ = 0.
  4. New net = −0.2, so this pattern now gives class 0.

Calculation 03

Update ADALINE even when the class is right

ADALINE learns from its continuous linear response, not from its thresholded class.

Given

x = (1, 2), t = 1, w = (0.1, 0.1), b = 0, η = 0.1. Use E = ½(t − a)² and a = wᵀx + b.

Method: Linear response → linear error → corrections → new loss.

Follow the worked solution 4 explained steps

1. Calculate the training response

a = 0.1 × 1 + 0.1 × 2 = 0.3. Its sign already gives class +1, but the training response is still only 0.3.

2. Use the linear error

e = 1 − 0.3 = 0.7; E = ½ × 0.7² = 0.245.

Using the class error 1 − 1 would incorrectly stop learning.

3. Update weights and bias

Δw = 0.1 × 0.7 × (1, 2) = (0.07, 0.14); Δb = 0.07.

w′ = (0.17, 0.24), b′ = 0.07.

4. Check the new linear loss

a′ = 0.17 + 0.24 × 2 + 0.07 = 0.72.

e′ = 0.28; E′ = ½ × 0.28² = 0.0392. It is lower for this pattern. A large rate need not reduce the loss.

Check: This half-squared loss gives Δw = ηex. For unhalved squared loss the gradient has an extra factor of two.

Now try it

Restart at w = (0.1, 0.1), b = 0. Use x = (2, 1), t = −1 and η = 0.1. Find the updated parameters and new response.

Check the steps and answer
  1. a = 0.3, so e = −1 − 0.3 = −1.3.
  2. Δw = (−0.26, −0.13), Δb = −0.13.
  3. w′ = (−0.16, −0.03), b′ = −0.13.
  4. a′ = −0.32 − 0.03 − 0.13 = −0.48; new half-loss = ½(−0.52)² = 0.1352.

Supplemental teaching example. Method: Lesson 3, PDF pp. 2–4. The numbers are chosen for this workbook, not quoted from a lecture question.

Calculation 04

Follow LMS through one complete epoch

Online learning updates after each sample. The next sample uses the new parameters.

Given

Two equally likely training pairs: (x, t) = (−1, −1), (1, 1), in that order. Start w = b = 0. Unhalved loss F = E[(t − wx − b)²]; α = 0.1; Δw = 2αex, Δb = 2αe.

Method: Augment the bias → fix the loss convention → update one sample at a time.

Follow the worked solution 4 explained steps

1. Write the augmented model

z = (x, 1), θ = (w, b), and a = θᵀz. Here R = E[zzᵀ] = I and h = E[tz] = (1, 0).

Thus F = (1 − w)² + b². Its minimum is θ* = (1, 0).

2. Present the first pair

x = −1, t = −1. Net a = 0; e = −1.

Δw = 2 × 0.1 × (−1) × (−1) = 0.2; Δb = −0.2. Now w = 0.2, b = −0.2.

3. Use that new state for the second pair

x = 1, t = 1. Net a = 0.2 − 0.2 = 0; e = 1.

Δw = 0.2; Δb = 0.2. End of epoch: w = 0.4, b = 0.

4. Check the objective and rate convention

F fell from 1 to (1 − 0.4)² + 0² = 0.36.

For this expected quadratic, R has largest eigenvalue 1, so 0 < α < 1 is the fixed-step steepest-descent bound. That expected-objective bound is not a promise that every online sample reduces every other sample’s error.

Using E = ½e² with η = 0.2 gives the same sample corrections.

Check: R includes the bias input. The factor of two belongs to the chosen loss, not to the name “LMS”.

Now try it

At θ = (0, 0), calculate one batch-mean gradient step with α = 0.1 on F. What if you use the batch sum instead?

Check the steps and answer
  1. At the frozen start, each sample gives gradient (−2, ±2).
  2. The mean gradient is (−2, 0); θ′ = θ − 0.1∇F = (0.2, 0).
  3. The sum gradient is (−4, 0), so the same numeric rate gives (0.4, 0).
  4. To compare mean and sum fairly, scale the rate by the batch size. Recompute online gradients after each update.

Supplemental teaching example. Method: Widrow Hoff Learning Rule, PDF pp. 1–5. The numbers are chosen for this workbook, not quoted from a lecture question.

Calculation 05

Backpropagate from two outputs

A hidden neuron affects every output it feeds. Add all those contributions before updating it.

Given

x = 1; hidden input weight v = 0.2 and bias bₕ = 0. Output weights w₁ = 0.4, w₂ = −0.3; output biases b₁ = b₂ = 0. All activations are sigmoid. Targets (t₁, t₂) = (1, 0); η = 0.5; E = ½Σ(tₖ − yₖ)².

Method: Forward pass → output deltas → hidden delta → simultaneous updates → loss check.

Follow the worked solution 6 explained steps

1. Compute the forward pass

Hidden: z = σ(0.2 × 1 + 0) = 0.549834.

Outputs: y₁ = σ(0.4z) = 0.554763; y₂ = σ(−0.3z) = 0.458856.

The hidden unit has no target label. Its error signal comes from the next layer.

2. Calculate both output deltas

δₖ = (tₖ − yₖ)yₖ(1 − yₖ).

δ₁ = (1 − 0.554763) × 0.554763 × 0.445237 = 0.109974.

δ₂ = (0 − 0.458856) × 0.458856 × 0.541144 = −0.113937.

3. Collect both downstream paths

Using the old output weights: w₁δ₁ = 0.043990, w₂δ₂ = 0.034181.

δₕ = z(1 − z)(w₁δ₁ + w₂δ₂) = 0.019349.

Both contributions are positive here because w₂ and δ₂ are both negative. Use the sum before multiplying by the hidden activation slope.

4. Update the hidden parameters

Δv = ηδₕx = 0.5 × 0.01934856 × 1 = 0.00967428. Bias has constant input 1, so Δbₕ is the same.

v′ = 0.209674; bₕ′ = 0.009674.

5. Update both output parameters from the same old state

Δwₖ = ηδₖz; Δbₖ = ηδₖ.

w₁′ = 0.430234; b₁′ = 0.054987.

w₂′ = −0.331323; b₂′ = −0.056969.

Do not use these new weights to go back and change the already-computed hidden delta.

6. Run a fresh forward pass to check

Using full-precision values, old E = 0.204392, new E = 0.188064. This step reduces the sum of the two half-squared errors.

Use unrounded intermediate values for the update. The displayed six-decimal values are for reading.

Check: Deltas here are negative loss derivatives with respect to each net input. That is why the correction uses a plus sign. With raw loss gradients, use a minus sign.

Now try it

For another hidden neuron, z = 0.5, downstream weights are (0.4, 0.5) and output deltas are (0.1, −0.2). With x = 1, v = 0.2 and η = 0.5, find δₕ and v′.

Check the steps and answer
  1. Sum both paths: 0.4 × 0.1 + 0.5 × (−0.2) = −0.06.
  2. Hidden sigmoid slope = 0.5 × 0.5 = 0.25.
  3. δₕ = 0.25 × (−0.06) = −0.015.
  4. v′ = 0.2 + 0.5 × (−0.015) × 1 = 0.1925. Using only the first output would give the wrong sign.

Supplemental teaching example. Method: Lesson 4, PDF pp. 6–13. The numbers are chosen for this workbook, not quoted from a lecture question.

Calculation 06

Keep momentum and gradients separate

Momentum remembers the previous parameter change, not the previous parameter value.

Given

Current w = 0, previous change Δw = 0.1, learning rate η = 0.2, momentum μ = 0.5. Two raw loss gradients arrive: g₁ = −0.4, then g₂ = 0.2. Use Δw(new) = −ηg + μΔw(previous).

Method: Current gradient contribution + carried change → store the new change.

Follow the worked solution 3 explained steps

1. Split the first change into two parts

Gradient part = −0.2 × (−0.4) = 0.08.

Carried part = 0.5 × 0.1 = 0.05.

2. Apply and remember the first change

Δw₁ = 0.08 + 0.05 = 0.13. Therefore w₁ = 0 + 0.13 = 0.13. Store 0.13 as the previous change.

3. Process the reversed gradient

Gradient part = −0.2 × 0.2 = −0.04. Carried part = 0.5 × 0.13 = 0.065.

Δw₂ = −0.04 + 0.065 = 0.025, so w₂ = 0.155.

The weight still rises because the carried change outweighs the new downhill-gradient term. Momentum does not guarantee a lower loss on every step.

Check: The supplied gradients are raw ∂E/∂w. If using a backprop delta, its sign convention must be accounted for.

Now try it

Now use delta-bar-delta instead: w = 0.5, old α = 0.1, previous smoothed gradient = −0.2, current g = 0.4, θ = 0.9, κ = 0.02, φ = 0.5. Find the new rate, weight and smoothed gradient.

Check the steps and answer
  1. Compare the old smoothed gradient with current g: −0.2 × 0.4 = −0.08 < 0.
  2. Reduce the rate: α′ = (1 − φ)α = 0.5 × 0.1 = 0.05.
  3. Use that new rate: w′ = 0.5 − 0.05 × 0.4 = 0.48.
  4. New smoothed gradient = (1 − 0.9) × 0.4 + 0.9 × (−0.2) = −0.14. The comparison used the previous average, not this new one.

Supplemental teaching example. Method: Lesson 4 ctd, PDF pp. 1–3. The numbers are chosen for this workbook, not quoted from a lecture question.

Calculation 07

Average PNN evidence inside each class

One exact neighbour does not automatically win. The class score averages every stored example in that class.

Given

Query x = 0, σ = 1, one feature. Class A stores {−1, 1}; class B stores {0, 3}. First use equal priors and costs. Kernel φ(d) = exp(−d²/2)/√(2π).

Method: Squared distances → Gaussian responses → class-specific averages → decision.

Follow the worked solution 4 explained steps

1. Compute every squared distance

A: (0 − (−1))² = 1 and (0 − 1)² = 1.

B: (0 − 0)² = 0 and (0 − 3)² = 9.

2. Evaluate the relative kernels

The shared normalizer is c = 1/√(2π) = 0.39894228.

A responses before multiplying by c: exp(−½) = 0.606531 for each exemplar.

B responses: exp(0) = 1 and exp(−9/2) = 0.011109.

3. Average within each class

A: (0.60653066 + 0.60653066)/2 = 0.60653066; density = 0.241971.

B: (1 + 0.01110900)/2 = 0.50555450; density = 0.201687.

The common positive c may be cancelled for this ranking because feature dimension and bandwidth are shared. Include it when reporting actual densities.

4. Compare the class scores

Equal priors and costs give class A, even though B has an exemplar at the exact query. B’s distant exemplar lowers its class average.

These are densities, not normalized posterior probabilities.

Check: A class’s denominator is its own sample count. Shared kernel constants may cancel in a ranking, but priors do not.

Now try it

Keep the same densities and equal costs. Change the priors to P(A) = 0.3 and P(B) = 0.7. Which class wins?

Check the steps and answer
  1. A score = 0.3 × 0.24197072 = 0.072591.
  2. B score = 0.7 × 0.20168706 = 0.141181.
  3. Choose B. The class prior changes the decision even though A has the larger class-conditional density.

Supplemental teaching example. Method: Lesson 5, PDF pp. 2–3. The numbers are chosen for this workbook, not quoted from a lecture question.

Calculation 08

Calculate fuzzy operations element by element

A grade belongs to an element of a stated universe. Combine grades at the same element.

Given

Ordered universe U = {u₁, u₂, u₃}. A = (0.2, 0.7, 1), B = (0.6, 0.4, 0.5). Standard union = max, intersection = min, complement = 1 − μ.

Method: Keep element order → compare matching positions → write the resulting grade vector.

Follow the worked solution 3 explained steps

1. Calculate union

At u₁: max(0.2, 0.6) = 0.6. At u₂: max(0.7, 0.4) = 0.7. At u₃: max(1, 0.5) = 1.

A ∪ B = (0.6, 0.7, 1).

2. Calculate intersection

min(0.2, 0.6) = 0.2; min(0.7, 0.4) = 0.4; min(1, 0.5) = 0.5.

A ∩ B = (0.2, 0.4, 0.5).

3. Calculate the complement of A

1 − A = (1 − 0.2, 1 − 0.7, 1 − 1) = (0.8, 0.3, 0).

Every result is still a grade in [0, 1]. There is no requirement for a grade vector to sum to 1.

Check: Membership expresses fit to a label. It is not the probability of a randomly selected element.

Now try it

Find “very A” using μ². Then find the weak and strong 0.7-cuts of the original A.

Check the steps and answer
  1. Square each grade: very A = (0.04, 0.49, 1).
  2. Weak cut uses μ ≥ 0.7: {u₂, u₃}.
  3. Strong cut uses μ > 0.7: {u₃}.
  4. Cuts contain elements, not their membership grades.

Supplemental teaching example. Method: Fuzzy Lessons 1,2,3, PDF pp. 4–5 and 13–15. The numbers are chosen for this workbook, not quoted from a lecture question.

Calculation 09

Follow every route in a relation composition

A row chooses the starting element, a column chooses the destination, and the middle index lists alternative routes.

Given

R: X → Y has rows (0.2, 0.8), (0.6, 0.4). S: Y → Z has rows (0.9, 0.3), (0.5, 0.7). Both middle universes have two elements. Use max–min composition.

Method: For each output cell, take min along each two-link route, then max across routes.

Via y₁

0.2 → 0.9

min = 0.2
Via y₂

0.8 → 0.5

min = 0.5

Keep the stronger route: T₁₁ = 0.5

Follow the worked solution 4 explained steps

1. Choose row 1 and column 1

R row 1 = (0.2, 0.8); S column 1 = (0.9, 0.5).

There are two possible middle elements. Do not multiply whole rows or take a maximum before evaluating each route.

2. Evaluate the two routes

Through y₁: min(0.2, 0.9) = 0.2.

Through y₂: min(0.8, 0.5) = 0.5.

T₁₁ = max(0.2, 0.5) = 0.5. The strongest route goes through y₂.

3. Repeat for the other three cells

T₁₂ = max(min(0.2, 0.3), min(0.8, 0.7)) = 0.7.

T₂₁ = max(min(0.6, 0.9), min(0.4, 0.5)) = 0.6.

T₂₂ = max(min(0.6, 0.3), min(0.4, 0.7)) = 0.4.

4. Read the resulting matrix

The output rows are X and columns are Z:

0.50.70.60.4

The shared Y universe is summed over in ordinary matrix multiplication, but max–min uses a maximum of minima instead.

Check: Dimensions alone are not enough: the two middle indices must describe the same ordered universe.

Now try it

Change to max–product composition. Calculate T₁₁ and T₂₂.

Check the steps and answer
  1. T₁₁ routes: 0.2 × 0.9 = 0.18 and 0.8 × 0.5 = 0.4.
  2. Take max: T₁₁ = 0.4.
  3. T₂₂ routes: 0.6 × 0.3 = 0.18 and 0.4 × 0.7 = 0.28.
  4. Take max: T₂₂ = 0.28. The final outer operation stays max.

Calculation 10

Separate a cut from a centroid

A cut returns a set of input values. A centroid returns one scalar output.

Given

Triangle with vertices (0, 0), (2, 1), (6, 0). Thus μ(x) = x/2 on [0, 2], (6 − x)/4 on [2, 6], and 0 outside. Find the weak 0.5-cut and the continuous centroid.

Method: Solve the membership inequalities for the cut; use first moment / area for the centroid.

Follow the worked solution 4 explained steps

1. Find the two half-height crossings

Left: x/2 = 0.5 gives x = 1.

Right: (6 − x)/4 = 0.5 gives x = 4.

2. State what the cut contains

The weak cut keeps μ(x) ≥ 0.5, giving [1, 4]. The strong cut uses > and gives (1, 4).

It does not return the single number 0.5.

3. Split the area at the peak

Left triangle area = ½ × 2 × 1 = 1; its x-centroid is (0 + 2 + 2)/3 = 4/3.

Right triangle area = ½ × 4 × 1 = 2; its x-centroid is (2 + 2 + 6)/3 = 10/3.

4. Divide first moment by total area

First moment = 1 × (4/3) + 2 × (10/3) = 8.

Total area = 3. Continuous centroid = 8/3 ≈ 2.666667.

The right tail makes this larger than the peak location 2. A discrete sum over a few sampled points would be a different specified model.

Check: Do not substitute “location of maximum membership” for centroid. Also distinguish scaling the whole shape from clipping its top.

Now try it

Multiply every membership grade by 0.5. What happens to the continuous centroid?

Check the steps and answer
  1. Area scales from 3 to 1.5.
  2. First moment scales from 8 to 4.
  3. Centroid = 4/1.5 = 8/3, unchanged.
  4. This is uniform scaling. Clipping at 0.5 changes the shape and need not preserve the centroid.

Supplemental teaching example. Method: Fuzzy Lessons 1,2,3, PDF pp. 13–17. The numbers are chosen for this workbook, not quoted from a lecture question.

Calculation 11

Name the implication before calculating it

Crisp implication has a truth table. Fuzzy implication needs a chosen numerical operator.

Given

First p = true, q = false. Then use fuzzy grades a = 0.4, b = 0.8. Dienes–Rescher Iᴅ = max(1 − a, b). Zadeh Iᴢ = max(min(a, b), 1 − a).

Method: Crisp: find the counterexample row. Fuzzy: substitute into the stated operator.

Follow the worked solution 4 explained steps

1. Check the crisp statement and its converse

p → q is false because its premise is true and conclusion false.

The converse q → p is true here. Therefore a statement and its converse are not generally equivalent.

2. Evaluate Dienes–Rescher

1 − a = 0.6. Therefore Iᴅ = max(0.6, 0.8) = 0.8.

3. Evaluate Zadeh separately

min(a, b) = min(0.4, 0.8) = 0.4.

Iᴢ = max(0.4, 0.6) = 0.6. The same input grades give a different fuzzy implication.

4. Check the crisp counterexample numerically

At a = 1, b = 0, both expressions give 0. Matching on crisp truth values does not make two fuzzy operators identical on partial grades.

Check: A Mamdani minimum is a local rule relation. It is not a global implication with the same crisp truth table.

Now try it

For a = 0.7, b = 0.2, compute Dienes–Rescher, Zadeh and Mamdani minimum.

Check the steps and answer
  1. Complement 1 − a = 0.3.
  2. Dienes–Rescher = max(0.3, 0.2) = 0.3.
  3. Zadeh = max(min(0.7, 0.2), 0.3) = 0.3.
  4. Mamdani minimum = min(0.7, 0.2) = 0.2. Two operators can agree for one input pair without agreeing everywhere.

Supplemental teaching example. Method: Logic and Fuzzy Systems, PDF pp. 3–4 and 11–12. The numbers are chosen for this workbook, not quoted from a lecture question.

Calculation 12

Fire, evaluate, then normalize the rules

Sugeno evaluates a crisp consequent function. Tsukamoto inverts a monotonic consequent. Keep those two operations separate.

Given

Inputs x = 2, y = 1. Rule 1 antecedent grades are (0.6, 0.8), rule 2 grades (0.3, 0.5); use AND = min. Sugeno consequents: f₁ = 2x + y, f₂ = 3x + 2y.

Method: Firing strengths → consequent values → weighted sum / total firing.

Follow the worked solution 4 explained steps

1. Find each rule’s firing strength

α₁ = min(0.6, 0.8) = 0.6. α₂ = min(0.3, 0.5) = 0.3.

These antecedent grades are given; no membership functions need to be invented.

2. Evaluate the Sugeno functions

f₁(2, 1) = 2 × 2 + 1 = 5.

f₂(2, 1) = 3 × 2 + 2 × 1 = 8.

3. Normalize the weighted output

z = (0.6 × 5 + 0.3 × 8)/(0.6 + 0.3) = 5.4/0.9 = 6.

Normalized weights are 2/3 and 1/3. The answer lies between 5 and 8, closer to the more strongly firing rule’s value 5.

4. Compare a separately specified Tsukamoto system

Keep the same firing strengths, but now rule 1 has μ₁(z) = z/10 on [0, 10], and rule 2 has μ₂(z) = (20 − z)/20 on [0, 20].

Invert: z₁ = 10α₁ = 6; z₂ = 20 − 20α₂ = 14.

Weighted output = (0.6 × 6 + 0.3 × 14)/0.9 = 26/3 ≈ 8.666667. This is a different consequent model, not a second answer for the original Sugeno system.

Check: A weighted average needs positive total firing. A Mamdani aggregate instead needs its own fuzzy-output construction and defuzzification.

Now try it

In the Sugeno system, switch AND to product using the same antecedent grades. Calculate the new output. What if neither rule fires?

Check the steps and answer
  1. α₁ = 0.6 × 0.8 = 0.48; α₂ = 0.3 × 0.5 = 0.15.
  2. Weighted numerator = 0.48 × 5 + 0.15 × 8 = 3.6.
  3. Total firing = 0.63; output = 3.6/0.63 = 40/7 ≈ 5.714286.
  4. If both strengths are zero, the formula is 0/0 and undefined. A fallback policy must be specified separately.

Supplemental teaching example. Method: Logic and Fuzzy Systems, PDF pp. 25–27. The numbers are chosen for this workbook, not quoted from a lecture question.
