Classical logic and crisp rule relations

A guided route from binary propositions and proof patterns to crisp IF/ELSE relations and inference.

Big picture

Classical logic gives each proposition a binary truth value: true or false. Once a proposition is viewed as the set of cases where it is true, logical operations become familiar set operations. The same idea extends to rules connecting different domains: a rule becomes a relation on a Cartesian product, and a new input set can be composed with that relation to infer possible outputs.

Propositions and truth sets

A proposition is a declarative statement that has one definite truth value for each instance in its universe of discourse. We use 1 for true and 0 for false. Its truth set contains the instances that make it true; its falsity set is the exact complement within the universe.

T:U→{0,1},T(u)=1 means true and T(u)=0 means false
T(P)={u∈U:P(u) is true},F(P)=T(P)―=U⧵T(P)

The two sets partition U: every instance is in exactly one of them. In the lecture’s boundary convention, the whole universe is true and the empty set is false. Two propositions are mutually exclusive when their truth sets do not overlap. For membership propositions P: x ∈ A and Q: x ∈ B, this means a true P forces Q false, and a true Q forces P false.

T(P)∪F(P)=U,T(P)∩F(P)=∅
T(U)=1,T(∅)=0
T(P)∩T(Q)=∅⟺P⇒Q― and Q⇒P―

Connectives and their truth tables

For propositions P and Q on the same universe, negation reverses truth, inclusive OR is true when at least one proposition is true, and AND is true only when both are true. In set language, these correspond to complement, union, and intersection. Inclusive OR includes the case where both propositions are true.

Implication P ⇒ Q reads “if P, then Q.” P is the antecedent (hypothesis); Q is the consequent (conclusion). It is false only when P is true and Q is false. If P is false, the implication is true regardless of Q: the condition did not occur, so it did not break the rule. This is called vacuous truth.

Equivalence P ⇔ Q means “P if and only if Q.” It holds when both propositions have the same truth value, or equivalently when P ⇒ Q and Q ⇒ P. For set-membership propositions, implication fails on A ∖ B and is true on its complement.

T(P⇒Q)=T(P―∨Q)=max{1−T(P),T(Q)}
P⇒Q≡A―∪B,false exactly on A⧵B

Exclusive OR (XOR) means exactly one proposition is true. The lecture’s travel example is “by plane or boat,” but not both; its earlier menu example is “soup or salad” when choosing both is excluded. XNOR is the negation of XOR, so it agrees with logical equivalence.

P⊕Q=(P∧Q―)∨(P―∧Q),P⊙Q=P⊕Q―

Conditional, converse, inverse, and contrapositive

Starting from the conditional P ⇒ Q, reversing the direction gives the converse. Negating both parts gives the inverse; reversing and negating gives the contrapositive. The conditional is equivalent to its contrapositive, while the converse is equivalent to the inverse. The converse does not generally follow from the original conditional.

Teaching example: “If a number is divisible by 4, then it is even” has the contrapositive “if a number is not even, then it is not divisible by 4.” The converse “if a number is even, then it is divisible by 4” is false: 6 is even but is not divisible by 4. This illustrates why reversing a conditional alone is not a valid equivalence.

Tautologies, contradictions, and equivalence

A tautology is true under every assignment of truth values. A contradiction is false under every assignment. The complement laws show one of each: every instance is either in A or outside A, and no instance can be both.

A―∪A=U(tautology),A∩A―=∅(contradiction)

Two propositions are logically equivalent when their truth sets are identical. The lecture’s integer example compares “x is even” with “x² is even.” If x = 2k, then x² = 4k² = 2(2k²), so x² is even. Conversely, if x is odd, x = 2k + 1 and x² = 4k² + 4k + 1 = 2(2k² + 2k) + 1, which is odd. Thus x² is even exactly when x is even; the propositions have the same truth set over the integers.

P: x∈ℤ is even,Q: x2 is even,T(P)=T(Q)

The duality principle from the lecture says that a valid identity involving only AND, OR, and the constants 0 and 1 has a valid dual after swapping AND with OR and 0 with 1 (and complementing set symbols where that notation is used).

Modus ponens and modus tollens

Modus ponens applies a rule when its antecedent is known to be true: from P and P ⇒ Q, conclude Q. Modus tollens reasons from a false consequent: from ¬Q and P ⇒ Q, conclude ¬P. Each is a tautological inference pattern, not a guess about cause and effect.

(P∧(P⇒Q))⇒Q(modus ponens)
(Q―∧(P⇒Q))⇒P―(modus tollens)
Teaching example: modus ponens

Rule: If the access card is valid (P), then the door unlocks (Q).
Given: The card is valid (P).
Apply modus ponens: P and P ⇒ Q are both true, so conclude Q: the door unlocks.
Check: This uses the rule in its forward direction; it does not infer that the card is valid merely because the door unlocked.

Teaching example: modus tollens

Rule: If the alarm is enabled (P), then its indicator is lit (Q).
Given: The indicator is not lit (¬Q).
Apply modus tollens: A true P would require Q, but Q is false, so conclude ¬P: the alarm is not enabled.
Check: The inference uses the negated consequent. “The indicator is lit, therefore the alarm is enabled” would be the converse and is not licensed by this rule.

The lecture verifies modus tollens with all four A,B assignments. First calculate the rule and ¬B, then combine them into the premise. That premise is true only when both ¬B and A ⇒ B hold; in that row, ¬A is true. Therefore the final implication is true in every row.

(B―∧(A⇒B))⇒A― is true for all four rows

Proof by contradiction

To verify an argument with hypotheses P₁,…,Pₙ and conclusion Q, the lecture first asks whether (P₁ ∧ … ∧ Pₙ) ⇒ Q is a tautology. A direct truth-table check can be organized as: formulate the full claim, decompose it into atomic propositions, translate it into connectives, then evaluate whether the implication is always true. For an indirect proof, assume all hypotheses and also ¬Q. If those assumptions lead to an impossibility, the counterexample cannot exist and the implication is valid.

((P1∧⋯∧Pn)⇒Q) is valid⟺P1∧⋯∧Pn∧Q― is impossible
Teaching example: rule out the counterexample step by step

Teaching example: prove an implication by contradiction

Claim to prove: If an integer n is even, then n² is even.
Definitions: n is even when n = 2k for some integer k; an even number is not odd.
Contradiction method: assume the hypothesis and the negation of the conclusion together.

1. State the implication

Let P mean “n is even” and Q mean “n² is even.” The target is P ⇒ Q. The lecture’s test is to check whether the implication is always true.

2. Assume a counterexample

Assume P and ¬Q: n is even but n² is odd. By the definition of even, write n = 2k for some integer k. This is the only assumption added for the indirect proof.

3. Substitute and simplify

Substitute n = 2k into the square: n² = (2k)² = 4k² = 2(2k²). Since 2k² is an integer, n² has the form 2m and is even. This contradicts the assumption that n² is odd.

4. Conclude and check

The assumptions P ∧ ¬Q cannot both hold, so the counterexample is impossible and P ⇒ Q is true. Independent check: every even n has square 4k², which is divisible by 2. The contradiction proof agrees with the direct divisibility check.

Crisp rule relations on two universes

A proposition about membership in A and a consequent about membership in B may refer to different universes. The rule then relates an x from X to a y from Y, so its truth region is a subset of the product X × Y. For IF A THEN B, pairs in A must land in B; when x lies outside A, the conditional is vacuously true for every y. That second region is the complement branch Ā × Y.

Rif=(A×B)∪(A―×Y)⊆X×Y

An ELSE rule sends the outside-A branch to C rather than leaving y unrestricted. The bars are essential: the branch condition and its product region are both the complement of A. The lecture’s rule-form line writes P in both implications, while its branch description and product-space formula use the complement for ELSE. Read the intended branches as P ⇒ Q and ¬P ⇒ S; otherwise both consequences would fire from the same condition. If B and C are disjoint, the two consequent regions are visibly separate, as in the lecture’s product-space sketch.

Rif/else=(A×B)∪(A―×C)

These relations capture different geometries. Plain implication excludes only the counterexample region A × (Y ∖ B); the rest of X × Y is allowed. IF/ELSE assigns the A rows to B and the Ā rows to C, so its relation is the union of two branch regions. It is not (A × B) ∪ (A × C).

Crisp inference by relational composition

Given a new antecedent A′, compose its characteristic row with the rule relation. For every output y, take min across the input and relation memberships for each x, then max across x. With crisp 0/1 values, min is AND and max is OR. The result B′ is a set on Y, not X. This is the Boolean form of the lecture’s max–min composition.

χB′(y)=maxx∈Xmin{χA′(x),χR(x,y)},B′=A′∘R
Teaching example: calculate both crisp ELSE outputs

Teaching example: crisp IF/ELSE inference by composition

Universes: X = {x₁, x₂, x₃}; Y = {y₁, y₂}. Antecedent set: A = {x₁, x₂}, so Ā = {x₃}. Consequents: B = {y₂}, C = {y₁}. Rule: IF A THEN B ELSE C, so R = (A × B) ∪ (Ā × C). For crisp grades, max is OR and min is AND.

Compute χB′(y) = maxx∈X min(χA′(x), χR(x,y)) in output order y₁, y₂. The output is a subset of Y.

1. Calculate χB′(y₁)

Current output: χB′(y₁). Use the input grades and the y₁ column of R. For each x, AND the input and relation values with min, then OR the paths with max.

Path calculations:

x χA′(x) χR(x, y) min on path
x₁ 0 0 min(0, 0) = 0
x₂ 1 0 min(1, 0) = 0
x₃ 1 1 min(1, 1) = 1

Substitute: max(0, 0, 1) = 1. This is the value for the current y; now process the other output column.

Output so far in Y order [y₁, y₂]: [1, ·].

2. Calculate χB′(y₂)

Current output: χB′(y₂). Use the input grades and the y₂ column of R. For each x, AND the input and relation values with min, then OR the paths with max.

Path calculations:

x χA′(x) χR(x, y) min on path
x₁ 0 1 min(0, 1) = 0
x₂ 1 1 min(1, 1) = 1
x₃ 1 0 min(1, 0) = 0

Substitute: max(0, 1, 0) = 1. This is the value for the current y; now process the other output column.

Output so far in Y order [y₁, y₂]: [1, 1].

Final result: B′ = {y₁, y₂}. Independent check: x₂ is in A and supports y₂; x₃ is outside A and supports y₁ through the ELSE branch. Thus both outputs appear, exactly matching B ∪ C for this mixed input.

When A′ is wholly inside A, only the B branch is active. When A′ is wholly inside Ā, only C is produced. When A′ intersects both A and Ā, the relation can return B ∪ C. The walkthrough uses the mixed case so each branch contributes one output.

Common mistakes

  • Inclusive OR allows both propositions to be true; XOR does not.
  • Material implication is false only for a true antecedent and a false consequent. A false antecedent makes it vacuously true.
  • Do not treat the converse as equivalent to the conditional. Only the conditional and contrapositive are guaranteed equivalent.
  • Modus tollens needs ¬Q together with P ⇒ Q; merely observing Q does not prove P.
  • Use the universe-relative complement Ā in the implication relation. The ordinary rule includes Ā × Y; the ELSE rule uses Ā × C.
  • For relation inference, keep rows indexed by X and outputs indexed by Y. Compute every output column by ANDing each path and ORing the paths.

Exam focus

  • Define truth and falsity sets and show that they partition U.
  • Reproduce the four-row tables for negation, inclusive OR, AND, implication, equivalence, XOR, and XNOR.
  • Explain the false-antecedent case and identify the single false row of P ⇒ Q.
  • Write the converse, inverse, and contrapositive with both complement bars in place.
  • Recognize tautologies, contradictions, modus ponens, modus tollens, and the counterexample test for proof by contradiction.
  • For crisp rules across X and Y, write the correct product regions and compute B′ one output at a time.

Practice questions

1. If P is false and Q is true, what is P ⇒ Q, and why?

Check your answer

It is true. An implication is violated only when P is true and Q is false; a false antecedent makes it vacuously true.

2. Write the converse, inverse, and contrapositive of P ⇒ Q. Which one is equivalent to the original?

Check your answer

Converse: Q ⇒ P. Inverse: ¬P ⇒ ¬Q. Contrapositive: ¬Q ⇒ ¬P. The contrapositive is equivalent to the original; the converse is equivalent to the inverse.

3. In the integers, are “x is even” and “x² is even” equivalent? Give a short check.

Check your answer

Yes. If x = 2k, then x² = 2(2k²) is even. If x is odd, x = 2k+1 and x² = 2(2k²+2k)+1 is odd. Thus x² is even exactly when x is even.

4. From “if P then Q” and ¬Q, what can be concluded? Name the rule.

Check your answer

Conclude ¬P by modus tollens.

5. For IF A THEN B on X × Y, what pairs form the vacuously true branch?

Check your answer

Ā × Y: every pair whose x is outside A, with any y in Y.

6. For IF A THEN B ELSE C, what region corresponds to the ELSE branch?

Check your answer

Ā × C. The antecedent complement selects the ELSE case, and the consequent is restricted to C.

7. In Boolean relation composition, how do you compute one output membership χB′(y)?

Check your answer

For each x, compute min(χA′(x), χR(x,y)); then take the maximum over all x. With 0/1 values this is OR over the ANDed paths.
