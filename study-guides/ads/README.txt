ADS FIELD NOTES

Open index.html in a modern browser. No server or internet is required.
Keep the HTML files and pages-data.js together so navigation works.

34 pages: 29 data structures, comparisons, an operation glossary,
external sorting, amortized analysis, and the starting page.

Use the left/right arrows, Play/Pause and Reset for graphical steps.
Each data structure has a fresh construction from a list.
Arrow keys work when a step viewer control has focus.
Topics opens navigation on a narrow screen.
Desktop comparison tables fit the page; wider diagrams can be panned locally.

Theme defaults to System. Open the theme menu to choose System, Light or Dark.
Changing the theme keeps your reading position. The menu supports arrow keys and Escape.
Diagrams follow the selected theme. A light outline represents black nodes
in red-black trees in dark mode, while red nodes retain a red outline.
Changing topics keeps the navigation, its filter and its scroll position.

SVG graphics are embedded in each HTML page. The assets folder also contains
standalone SVG exports which follow the system color theme.
