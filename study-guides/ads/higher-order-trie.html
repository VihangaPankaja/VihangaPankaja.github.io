Higher-order trie

Use a digit or a group of digits per branch. Larger fanout reduces height but leaves more pointer slots to store.

RuleOperations and complexityCaveats and exam focusCompressed order-10 trie: a larger checked constructionMethod decisions and costsCommon mistakesExam focus

Rule

An order-r trie has one child choice per symbol in an r-symbol alphabet. The lecture uses decimal NID strings, with ten branches per node. A compressed version records char#, the digit position being inspected, and #ptr, the number of nonnull pointers.

Fresh compressed decimal build from three NIDs

1 · Insert 012345678

With one key there is no decision node yet, so the item itself is the root candidate. Keep 012345678 as a nine-character string: parsing it as an integer would erase the leading zero and change every later digit position.

2 · Insert 015234567

Compare the candidate and incoming key from the first digit: positions 1 and 2 agree, while position 3 is 2 versus 5. The new char#3 node therefore has #ptr=2; stop at these two distinct leaves, with every earlier digit represented by their shared prefix.

3 · Insert 015231671

Both 015… keys choose digit 5 at char#3, then first differ at digit 6 (1 versus 4). Splice char#6 below that slot and set its #ptr to 2; digit 2 at char#3 still reaches 012345678 unchanged.

Insert an earlier difference, then delete

1 · Insert 079864231

The candidate under the old 01… subtree shares digit 1 but differs from it at digit 2 (7 versus 1), before char#3. Create char#2 above the old root: its digit-1 slot retains that entire subtree and digit-7 reaches 079864231; #ptr is 2.

2 · Search 015231671

Search uses the stored positions in order: digit 2 selects 1, digit 3 selects 5, and digit 6 selects 1. These decisions identify a leaf candidate, not proof of equality; compare all nine characters before returning success, especially the skipped digits 4 and 5.

3 · Delete 079864231

After confirming the exact leaf 079864231, remove its digit-7 slot so char#2 changes #ptr from 2 to 1. A one-child branch has no remaining choice to make, so bypass it and reconnect its sole 01… subtree directly to the former parent or root.

Operations and complexity

With W symbols and O(1) child indexing, search/insert/delete use O(W) key work. A fresh insertion build takes O(totalinputlength), plus the cost of allocating and initializing branch arrays. Dense order-r nodes can cost O(r) to initialize and store. Meld can insert every donor key.

Nine decimal digits need at most nine digit decisions plus one whole-key comparison in the lecture's order-10 representation. Consuming two digits gives up to 100 choices and at most five decisions, but the last group and leading zeros need a fixed convention. The compressed form avoids unary paths, not unused slots in each dense array.

Caveats and exam focus

More fanout can lower memory accesses while raising memory footprint. Append # when one key is a proper prefix of another, or explicitly record terminations. A prefix query must check skipped digits before listing descendants. Expected height near log_r n depends on the key distribution.

What is the difference between char# and #ptr?

char# chooses which digit to inspect. #ptr counts the nonempty child slots and helps decide when deletion should collapse a branch.

Search checks skipped digits and the full candidate

At a branch, only the indexed digit is tested. Digits between branch positions have not been checked by that path. The compressed trie’s leaf is therefore a candidate; exact search compares the whole key. A trie with edge information stores a pointer to a representative leaf at a branch and uses it to check the skipped characters while descending.

Delete and collapse each one-child branch

The lecture’s deletion trace is local: verify the leaf, clear its pointer, decrement the parent’s #ptr, then collapse a branch as soon as only one child remains. Continue upward because the parent may itself become unary. #ptr counts populated child pointers, not leaves below the node.

Variable-length keys need a terminator

The lecture’s fixed-width NIDs cannot be prefixes of one another. With variable-length keys, 0123 and 012345678 agree over the shorter key, so a search that only follows digit branches can confuse an exact key with a longer descendant. Append a reserved end marker such as # to every key. It is a symbol outside 0–9, has a real child slot, and distinguishes termination from continuation.

Method decisions and costs

Here W is key length, r is alphabet order, n is stored keys, and m is donor keys. Bounds assume constant-time access to an indexed child and unit-cost digit comparison; dense-array initialization/storage adds work proportional to r per branch.

Method Decision Stop condition Edge cases and cost
Build by insertion Insert each key using the first differing symbol and splice at its ordered char# position. Every input key has an exact leaf; a one-key trie is just that leaf. Worst-case O(nW) key work plus branch allocation/initialization; duplicates update the record rather than add a leaf.
Search Follow each node’s selected digit slot, then verify the complete candidate key. Missing slot means absent; equal full key means found. Worst-case O(W); skipped positions require comparison. An edge-information representative pointer checks them during descent.
Insert/update Search for a candidate; replace its record on equality, otherwise find the first differing digit and splice a two-child node. Stop at duplicate update or after installing the branch. Worst-case O(W) key work; a new branch begins with #ptr=2, and earlier char# nodes stay above it.
Delete Find and verify the key; clear its leaf pointer and decrement each affected #ptr. Stop when an ancestor still has at least two children, or continue to root while unary nodes collapse. Worst-case O(W); absent key changes nothing, sole root leaf becomes empty, and collapsing the root promotes its sole child.
Meld Insert each donor key into the receiver; resolve duplicate keys by the dictionary’s record-update policy. Donor exhausted. O(mW) key work worst case, plus allocations; no constant-time root splice is implied.
Group multiple digits (100-way) Index two decimal digits together when keys and grouping convention permit. Consume groups until a leaf candidate, then verify the key. Lecture example reduces nine digits to at most five decisions; worst-case key work remains O(W), with up to 100 slots and a defined last-group/leading-zero rule required.
Prefix / variable-length search Use edge information for skipped symbols and reserve # (or explicit terminal metadata) to distinguish a key from its extension. Exact search reaches the terminator; prefix reporting reaches a verified prefix locus. Checking skipped characters is essential. # must not collide with the alphabet; a prefix query reports descendants, while exact membership does not.

The lecture’s expected height near log_r n is distribution-dependent, not a worst-case guarantee. An uncompressed order-10 trie examines at most nine NID digits plus one whole-key comparison. The compressed version skips unary paths but still may allocate ten child slots per branch. A 100-way node lowers decisions while increasing the pointer footprint. The lecture’s edge-information pointer is the course method for checking omitted characters; broader prefix-index schemes are supplemental and should not be substituted for that stated method.

Common mistakes

  • Treating NIDs as integers loses leading zeroes and corrupts every later char# position.
  • Treating char# as the digit value is wrong: it stores a one-based position; the outgoing edge identifies the digit value.
  • Treating #ptr as the number of descendant records leads to incorrect deletion. Recompute it from nonnull child slots after each pointer removal.
  • Accepting a routed leaf without comparing the full key admits false matches when differing digits were skipped.
  • Collapsing a one-child branch without reconnecting its exact parent slot can change later routing; after each cut, walk upward and recheck the parent count.
  • A node with a stored prefix and descendants needs a terminator or explicit terminal marker; a prefix query and an exact search have different stopping rules.

Exam focus

State the inspected symbol position (char#), the edge digit, and the nonnull-child count (#ptr) separately. For insertion, show the candidate, first differing position, splice point, and resulting two populated slots. For search, list every inspected digit and the final whole-key comparison. For deletion, show each pointer count before and after removal and every unary-node promotion. State the alphabet, key width, and grouping convention before giving the order-10 or 100-way height estimate.
